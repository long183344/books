## 二次扩充：新增 2.5 关键术语与操作详解
- 用户要求把案例里没展开的「黑话+动作」讲透：跳线、CMOS 放电、短接 PWR、外频改回133MHz、关 C-State。
- 在文档中新增 `## 2.5 关键术语与操作详解` 小节，每个含「是什么 + 为什么要动 + 怎么操作 + 注意事项 + 现代对应」：
  - 澄清关键误区：CMOS 放电 ≠ 放静电(ESD)，前者是切断 BIOS 设置供电复位，后者是有害击穿。
  - 跳线：可拔插金属帽连通两根针=手动硬开关；含拔/移/扣操作与 CLR_CMOS/FSB_SEL 用途。
  - CMOS 放电：三种方法（取电池 / CLR_CMOS 跳线 / 按钮），含断电等待、Load Defaults 流程与能解决/不能解决的边界。
  - 短接 PWR：前面板 PWR_SW 两根针瞬间接通模拟开机键，用于区分机箱键坏 vs 主板坏；强调只碰 PWR_SW、点一下就拿开。
  - 外频：实际频率=外频×倍频；案例01 133×19≈2.5G，被改100→1.9G 不稳；BIOS 与跳线两种改法 + 现代对应 BCLK/XMP。
  - C-State：C0~C10 睡眠深度表；深度状态拖内存/北桥睡导致弱内存唤醒失败→idle 死机；Intel/AMD BIOS 关闭路径 + 与 SpeedStep 辨析。
