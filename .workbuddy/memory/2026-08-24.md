### 关键技术点
1. **`create_matrix(Rows, Cols, Value, MatrixID)` 是矩阵构造起点**；HALCON 无 `identity_matrix`，要单位矩阵必须 `create_matrix` + `set_diagonal_matrix`。
2. **Matrix 族 HDevelop 签名格式独特**：`op (: : Args : Retvals)`，第一个空位是 input 图标（HALCON Matrix 无图形输入故空）、第二个空位是 output 图标（多返回时空）、冒号分隔参数。
3. **`_mod` 版原地修改**：Arithmetic 族 12 个操作均有 `_mod` 版本——节省 50% 内存但覆盖入参矩阵。生产环境/批量运算优选。
4. **三大线性代数算子**：
   - `solve_matrix(A, 'LU'|'symmetric', B, X)` 解 A·X = B（LU 最快、symmetric 对称时再快）
   - `svd_matrix(A, 'reduced', 'both', U, S, V)` SVD 分解（PCA/伪逆的基石）
   - `invert_matrix(A, MatrixType, Epsilon, AInv)` 求逆（需先 `determinant_matrix` 检查非奇异）
5. **状态视图**：Access 8 是读写基座、Arithmetic 27 是运算主体、Creation/Features 是构造与查询、Decomposition/Eigenvalues 是高级分解、File 是持久化。

### 章节全貌

  - Gray Values 18（结构元素 2 + 4 形态 × 3 SE 12 + 派生 4）
  - Region 25（基础 4 + 腐蚀/膨胀 8 + 开/闭 6 + 派生 7）

- 总章 82-43 差异原因：toc_morphology_grayvalues.html 误归了一个 ch14 的 create_data_code_2d_model.html

### 关键技术点
1. **同一套 SE 数学切两个输入域**：
   - GrayValues：SE 在图像灰度上滑动，对邻域 min/max → 平滑/去噪/TopHat
   - Region：SE 在二值区域上滑动，命中像素纳入结果 → 去毛刺/补孔/hit-or-miss
2. **4 基本算 × N SE 变体 × 4 派生算**：腐蚀/膨胀/开/闭 = 4 基本算；3 SE 形状（无/rect/shape）= 12 ops 子族；派生 = tophat/bothat/range/hit-or-miss
3. **GrayValues SE 选择**：
   - 通用版（`gray_*`）= 任意 SE 对象，最灵活
   - `_rect` 版 = 矩形 SE 高宽参数，速度最快（推荐 90% 场景）
   - `_shape` 版 = 任意形状（八角/菱形等）
4. **Region 4 种 SE**（腐蚀/膨胀各 8 个）：
   - 通用版（`erosion1`/`dilation1`）= 任意 SE
   - 双点 SE 版（`erosion2`/`dilation2`）= 用于 OCR 字符断行
   - 圆形 SE（`erosion_circle`）
   - 矩形 SE（`erosion_rectangle1`）
5. **hit_or_miss 用 2 个 SE 同时配置前景+背景**——HALCON 唯一支持"找特定形状"的算子（OCR 角点、十字、T 接）
6. **minkowski_add1/sub1 = SE 旋转 180°**——前者求凸包，后者对称腐蚀；add2/sub2 = 不旋转
