## 与硬件分类的衔接点

写出快的代码需要知道机器怎么跑：

- 数据布局 → 缓存行（64B）、伪共享 → [CPU 架构与工作原理](../01-计算机硬件/CPU/01-CPU架构与工作原理.md)
- 分支消除 / 无分支编程 → 分支预测器
- 向量化 → SIMD 指令集（AVX-512 / AVX10）
- 内存带宽敏感型程序 → 内存通道与频率 → [内存插槽笔记](../01-计算机硬件/插槽与接口/02-内存插槽-DIMM与CAMM2.md)
