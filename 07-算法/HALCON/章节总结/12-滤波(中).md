# 第 12 章 · Filters · 中卷 —— 边缘 / 增强 / 修补 / 几何变换 / 频域 / 直线 / 匹配

> **章节定位**：本卷承接上卷（像素级独立计算）迈入 **"邻域 / 空间重采样 / 频域 / 线条 / 模板匹配"** 的层。所有算子开始依赖 1×N 像素邻域、几何映射或图像域变换。
> 上卷 = 像素级（41 ops）；**本卷 = 邻域 + 空间 + 频域 + 直线 + 匹配（87 ops）**；下卷 = 平滑 + 噪声 + 特征点 + 光流 + 纹理 + Wiener（59 ops）。

本卷算子数：**87 个**
- Edges 23 + Enhancement 7 + Inpainting 6 + Geometric Transformations 12 = 48
- **FFT 31 + Lines 4 + Match 4 = 39（新增）**

## 1. 中卷七族一览

| 族 | 中文 | 算子数 | 核心抽象 | 典型用法 |
|---|---|---|---|---|
| **Edges** | 边缘检测 | 23 | 像素梯度算子、Sobel/Prewitt/Canny/LoG/DoG | 工件边缘提取、缺陷边界、亚像素定位 |
| **Enhancement** | 图像增强 | 7 | 直方图均衡、对比度、各向异性扩散 | 弱对比度增强、HDR 平滑、纹理保边 |
| **Inpainting** | 图像修补 | 6 | 区域 → 邻域插值，5 种插值模型 + 1 纹理合成 | 旧照片修复、OCR 字符补全 |
| **Geometric Transforms** | 几何变换 | 12 | 仿射 / 投影 / 镜像 / 极坐标 / 向量场 | 倾斜校正、极坐标展开、镜头畸变校正 |
| **FFT** | 频域滤波 | **31** | 前向/反向 FFT、滤波器核生成、功率谱、相位相关 | 亚像素位移估计、模板匹配加速、频域高斯/带通 |
| **Lines** | 直线检测 | **4** | 线状结构提取（Gauss/Facet/Color） | 票据线扫描、条形码定位、光纤端面 |
| **Match** | 模板匹配 | **4** | 穷举 NCC/SAD/SSD + 多网格 + 高斯金字塔 | 工件定位、印刷质量检测 |

> **共同点**：七族都开始读邻域、做空间变换，或切换到频域 —— 算子内部都会有 **Sigma/Size/Mode** 等"邻域尺寸 + 模式"参数。
> 与上卷的 **Mult/Add**（点级缩放/偏置）相比，本卷的 **核心参数是"邻域半径 / 频域半径 / 模板尺寸"**。

## 2. Edges（23）—— 边缘检测总览

> HALCON 把边缘算子按"是否带方向/是否亚像素/灰度or彩色"分门别类。
> - **3×3 / 5×5 卷积** 直接给幅值：Sobel / Prewitt / Roberts / Kirsch / Robinson / Frei
> - **二阶导** 给过零点：Laplace / LoG / DoG
> - **Canny 类**：高斯 → 梯度 → 非极大抑制 → 双阈值 + 滞后连接
> - **彩色版**：3 通道联合求幅值/方向
> - **辅助**：边缘闭合、查询滤波器

### 2.1 3×3 卷积边缘算子（12 = 6 套 × 2）

| 算子 | 输出 | 卷积核特点 |
|---|---|---|
| `sobel_amp` / `sobel_dir` | 幅值 / 幅值+方向 | Sobel（含可调 Size，仅 `sobel_dir` 含平滑 Sigma） |
| `prewitt_amp` / `prewitt_dir` | 幅值 / 幅值+方向 | Prewitt |
| `kirsch_amp` / `kirsch_dir` | 幅值 / 幅值+方向 | Kirsch（8 方向加权） |
| `robinson_amp` / `robinson_dir` | 幅值 / 幅值+方向 | Robinson（3 套掩码） |
| `frei_amp` / `frei_dir` | 幅值 / 幅值+方向 | Frei（类同 Kirsch，归一化更平） |
| `roberts` | 幅值 | 2×2 Roberts 对角差 |

### 2.2 二阶导边缘

| 算子 | 输出 | 模型 |
|---|---|---|
| `laplace` | 二阶导幅值 | 4/8 邻域 Laplace，可配 MaskSize/FiterMask |
| `laplace_of_gauss` | LoG | 高斯 σ → 二阶导 → 寻过零点（亚像素） |
| `diff_of_gauss` | DoG | σ 与 σ·SigFactor 两次高斯之差 |
| `derivate_gauss` | 任意阶导 | 与 LoG 不同，返回 1 阶 / 2 阶 / 偏导分量 |

### 2.3 Canny 边缘

| 算子 | 输出 | 流程 |
|---|---|---|
| `edges_image` / `edges_color` | Canny 幅值 + 方向（pixel） | 高斯 → 梯度 → NMS → 双阈值 |
| `edges_sub_pix` / `edges_color_sub_pix` | Canny 亚像素 XLD | 在 pixel 基础上去除整数网格约束，输出边缘 XLD 轮廓 |

> **4 类核心参数**：`Filter`（'lanser2'/'canny'/'sobel'/'deriche2' 等）、`Alpha`（平滑强度）、`NMS`（'none'/'nms'/'inms'）、`Low/High`（滞后阈值）。

### 2.4 边缘辅助

| 算子 | 功能 |
|---|---|
| `close_edges` | 在梯度方向上延拓闭合缺口边缘 |
| `close_edges_length` | 按指定长度阈值在梯度方向追踪闭合 |
| `info_edges` | 查询各 edge 算子的支持参数（Filter 名表 + 适用 Mode） |

### 2.5 高频派单：全 23 个 edges_* 算子的中枢表（见 10.1）

## 3. Enhancement（7）—— 图像增强算子

> 与 Ch11 Enhancement 共用名字，但本卷专注于**与滤波联动的增强**：
> - **直方图**：`equ_histo_image`（全局均衡）、`scale_image_max`（局部归一）
> - **微分锐化**：`emphasize`（unsharp masking）、`shock_filter`（沿等照度线锐化）
> - **保边平滑 / 恢复**：`coherence_enhancing_diff`（CED）、`mean_curvature_flow`（MCF）
> - **同态**：`illuminate`（照度补偿 = log → 滤波 → exp）

### 3.1 关键参数
- **CED**：Sigma（结构张量平滑）、Rho（扩散强度）、Theta（步长）、Iterations
- **MCF**：Sigma（正则化）、Theta、Iterations
- **Shock filter**：Mode（'center'/'edge_shock'）、Iterations、Sigma
- **emphasize**：Factor > 1 锐化，< 1 模糊，= 0 不变

### 3.2 增强流水线：低对比度 OCR 案例
1. `equ_histo_image` 拉到 0-255
2. `emphasize(..., 9, 9, 0.7)` 锐化
3. `shock_filter(..., 1.0, 5, 'edge_shock', 1.0)` 沿字符边缘锐化
4. 进入 Ch20 OCR 流程

## 4. Inpainting（6）—— 5 种插值模型 + 1 纹理合成

> 区域修补（Image Inpainting）。统一接 `Mask: Region` 参数 —— **Region 代表"要补的洞"**，与 Ch13 Morphology 的"图章"语义相反。

| 算子 | 模型 | 适用 |
|---|---|---|
| `harmonic_interpolation` | Laplace 调和（最简） | 大块纯色背景的小洞 |
| `inpainting_aniso` | 各向异性扩散（沿等照度线） | 保留梯度方向的细线修补 |
| `inpainting_ced` | CED 各向异性 | 与 enhancement 中的 CED 同源 |
| `inpainting_ct` | Coherence Transport 连贯传输 | 平滑过渡，强线条穿透 |
| `inpainting_mcf` | 平均曲率流 | 自然纹理背景中等大小洞 |
| `inpainting_texture` | 纹理合成采样 | 砖墙/木头/织物等强纹理区域 |

## 5. Geometric Transformations（12）—— 空间重采样

### 5.1 4 类基本几何变换

| 算子 | DoF | 矩阵 |
|---|---|---|
| `affine_trans_image` / `affine_trans_image_size` | 6 | 3×3 仿射（缩放/平移/旋转/剪切） |
| `projective_trans_image` / `projective_trans_image_size` | 8 | 3×3 透视（透视校正） |
| `rotate_image` | 1 | 围绕图像中心 Phi 弧度 |
| `mirror_image` | 3 模式 | 'row'（水平）/ 'column'（垂直）/ 'diagonal'（对角） |
| `zoom_image_factor` / `zoom_image_size` | 各向同性 | 倍数 / 目标尺寸 |
| `map_image` | 2D 向量场 | 与 `convert_map_type` 配合转换场/矩阵 |

### 5.2 极坐标变换

| 算子 | 作用 |
|---|---|
| `polar_trans_image_ext` | 笛卡尔 → 极坐标（用户给圆心 + 角/径范围） |
| `polar_trans_image_inv` | 极坐标 → 笛卡尔 |

### 5.3 向量场畸变校正
- `map_image` 接受一个 2D 向量场（即每像素偏移），与 Ch6 Calibration 算出的 lens distortion map 联用做镜头畸变校正。

### 5.4 关键参数速记
- **Interpolation**：`'nearest_neighbor'`（最快/锯齿）、`'bilinear'`（默认，平衡）、`'bicubic'`（平滑）、`'weighted'`（亚像素）
- **AdaptImageSize**：仿射时是否自动扩展到完整保留目标（旧版）
- **HomMat2D**：HALCON 的 HomMat2D 内部用 3×3 齐次矩阵（9 元素 `HTuple`）

## 6. FFT（31）—— 频域滤波核心族

> **本章最大新族**：31 个算子，按用途分 4 大类：
> - **(A) FFT 主线**：`fft_image` / `fft_image_inv` / `fft_generic` / `rft_generic`
> - **(B) 滤波器核生成**：`gen_lowpass` / `gen_highpass` / `gen_bandpass` / `gen_bandfilter` / `gen_gauss_filter` / `gen_mean_filter` / `gen_gabor` / `gen_derivative_filter` / `gen_filter_mask` / `gen_sin_bandpass` / `gen_std_bandpass`
> - **(C) 卷积/相关**：`convol_fft` / `correlation_fft` / `convol_gabor` / `phase_correlation_fft`
> - **(D) 频域分析**：`energy_gabor` / `phase_deg` / `phase_rad` / `power_byte` / `power_ln` / `power_real`
> - **(E) 性能优化**：`optimize_fft_speed` / `optimize_rft_speed` / `read_fft_optimization_data` / `write_fft_optimization_data` / `serialize_fft_optimization_data` / `deserialize_fft_optimization_data`

### 6.1 频域 vs 空域：何时用 FFT？

| 场景 | 推荐 |
|---|---|
| 大核（σ > 10）卷积 | **频域**（`convol_fft`，O(n log n)） |
| 小核（≤ 7×7）卷积 | **空域**（Smoothing 族） |
| 亚像素位移估计 | **频域**（`phase_correlation_fft`） |
| 周期性纹理提取 | **频域带通**（`gen_bandpass` + `convol_fft`） |
| Gabor 滤波器组 | **频域**（`gen_gabor`） |

### 6.2 FFT 参数体系
- **Direction**：`'to_freq'`（正向）或 `'from_freq'`（反向）
- **Norm**：`'n'`（无归一）、`'sqrt'`（单位能量）、`'none'`
- **Mode**：`'dc_center'`（低频在中心）或 `'dc_edge'`（低频在边缘，HALCON 默认）
- **ResultType**：`'complex'`（复数）、`'real'`（实部）、`'imag'`（虚部）、`'byte'`

### 6.3 流水线：频域高斯滤波 → 反 FFT（典型）
1. `fft_image(Image, ImageFFT)` —— 转复频谱
2. `gen_gauss_filter(ImageGauss, 2.5, 2.5, 0, 'n', 'dc_center', W, H)` —— 频域高斯
3. `convol_fft(ImageFFT, ImageGauss, ImageConvol)` —— 频域乘积
4. `fft_image_inv(ImageConvol, Smooth)` —— 转回实图

### 6.4 性能技巧
- 大图反复执行同尺寸 FFT 时，用 **`optimize_fft_speed`** 把 sin/cos 系数表持久化，第二次同尺寸 FFT 提速 2-5 倍。
- 持久化文件用 `write_fft_optimization_data` → 部署时 `read_fft_optimization_data` 预热。

## 7. Lines（4）—— 直线检测

> 4 个算子，覆盖灰度/彩色两套：
> - `lines_gauss` —— **高斯线模型 + 亚像素**（最常用，最准确）
> - `lines_facet` —— **Facet 模型**（小核，速度快）
> - `lines_color` —— 彩色边线检测
> - `bandpass_image` —— 用窄带通提取特定宽度的线状结构（横纹/竖纹/网格等）

### 7.1 关键参数
- **Sigma**（lines_gauss）：决定线宽尺度
- **Low/High**：滞后阈值
- **LightDark**：'light' / 'dark' 选择明暗线条

### 7.2 典型场景
- **票据/二维码网格线提取**：`bandpass_image` + `lines_gauss`
- **条形码定位**：`lines_gauss` 高速粗定位 → 后续解码

## 8. Match（4）—— 模板匹配族

> 4 个算子：
> - `exhaustive_match` —— **穷举全像素扫描**（最经典，小模板首选）
> - `exhaustive_match_mg` —— **多网格版本**，大图加速明显
> - `gen_gauss_pyramid` —— 构造高斯金字塔（多尺度）
> - `monotony` —— 灰度单调性度量（**实际是分类器**，非匹配但归在 Match 下）

### 8.1 流水线：多尺度模板匹配
1. `gen_gauss_pyramid(Image, ImagePyramid, 'weighted', 0.5)` —— N 级
2. 按层缩小模板
3. `exhaustive_match_mg` 多网格扫描
4. 在最相似位置附近做亚像素插值（如 `find_ncc_model`）

### 8.2 模式参数
- `exhaustive_match(Mode)`：
  - `'dfd'`（SAD，绝对差）── 抗噪
  - `'ncc'`（归一化互相关）── 光照鲁棒
  - `'ssd'`（误差平方和）── 精度高
  - `'msd'`（均值平方差）── 对比度归一

## 11. 10 条常见误区

1. **`sobel_amp` 的 Size 默认 3**，要 5/7 须显式传；**`sobel_dir` 才有 Sigma**，没有 Size 参数。
2. **`edges_image` vs `edges_sub_pix`**：前者输出 pixel 级幅值图，后者直接输出亚像素 XLD 轮廓（内存≈W·H/4）。
3. **`emphasize` 的 Factor 不是缩放系数** —— 是锐化强度（>1 锐化，<1 模糊，=0 返回原图）。
4. **`mean_curvature_flow` 的 `Sigma` 不是预平滑** —— 是"扩散控制尺度"，传 0 也会算。
5. **修补算子的 Region 是要修补的位置**，**不是**保留的区域 —— `Region=Mask` + 周边像素推算填补内容。
6. **`affine_trans_image` 的 HomMat2D 是 3×3 而非 3×2** —— HALCON 的 HomMat2D 内部用 3×3 齐次矩阵表示平移分量。
7. **`rotate_image` 的 Phi 是弧度** —— 想转 90° 传 `1.5708`（即 π/2），不是 90。
8. **FFT 的 Mode `dc_center` vs `dc_edge`**：HALCON 默认 `'dc_edge'`，画图展示时需 flip center 才符合"低频在中央"的视觉习惯。
9. **`lines_gauss` 没有生成 XLD 算子** —— 它直接返回 XLD Line 对象，**不是** region/cont_xld。
10. **`exhaustive_match_mg` 的 Level ≥ 2 才有意义** —— Level=1 时退化为普通穷举，**不会**自动多分辨率加速。

## 14. 备注

- 中卷新增 **3 族 39 个算子**（FFT 31 + Lines 4 + Match 4），覆盖频域滤波、直线检测、模板匹配三大工业刚需。
- **FFT 主族参数 4 件套**：`Direction`/`Norm`/`Mode`/`ResultType`，是 HALCON 频域的固定语法；任何带 `gen_*` 滤波器核的算子都遵循同一套参数表。
- **Lines 3 件套**：`Sigma` + `Low/High` + `LightDark`（'light'/'dark' 双极）。
- **Match 3 件套**：`Mode`（'dfd'/'ncc'/'ssd'/'msd'）+ `Level`（多网格深度）+ `Threshold`（过滤阈值）。
- 中卷算子都是 **像素图 ↔ 像素图** 或 **像素图 ↔ XLD** 转换，输出 **永远不进 Tuple/Region 语义层**（区别于上卷 Mult/Add 既能与 Tuple 又能与 Region 互转）。
- 下卷预告：**Smoothing 24 + Noise 5 + OpticalFlow 4 + Points 7 + SceneFlow 2 + Texture 3 + Misc 8 + Wiener 6 = 59 算子**，进入空域线性平滑、噪声模拟、特征点提取、光流场估计、纹理度量、Wiener 去卷积。

---

**统计**：本卷 87 算子 × 14 节；含 1 张总图（八角放射 + 7 子组 box）、12 张算子分组表、3 张速查卡、10 条误区、5 语言对照表。
**最后核对**：所有签名节选自 HALCON 20.11.1.0 Operator Reference，本卷算子在 20.11 完全一致。
