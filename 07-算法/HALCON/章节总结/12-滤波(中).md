# 第 12 章 · Filters · 中卷 —— 边缘 / 增强 / 修补 / 几何变换

> **章节定位**：本卷承接上卷（像素级独立计算）迈入 **"邻域" 与 "空间变换"** 的层。所有算子开始依赖 1×N 像素邻域或图像级几何变换。
> 上卷 = 像素级（41 ops）；**本卷 = 邻域 + 空间（48 ops）**；下卷 = 频域 + 平滑 + 特征点 + 光流（98 ops）。

本卷算子数：**48 个**（Edges 23 + Enhancement 7 + Inpainting 6 + Geometric Transformations 12）。

---

## 1. 中卷四族一览

| 族 | 中文 | 算子数 | 核心抽象 | 典型用法 |
|---|---|---|---|---|
| **Edges** | 边缘检测 | 23 | 像素梯度算子、Sobel/Prewitt/Canny/LoG/DoG | 工件边缘提取、缺陷边界、亚像素定位 |
| **Enhancement** | 图像增强 | 7 | 直方图均衡、对比度、各向异性扩散 | 弱对比度增强、HDR 平滑、纹理保边 |
| **Inpainting** | 图像修补 | 6 | 区域 → 邻域插值，5 种插值模型 + 1 纹理合成 | 旧照片修复、OCR 字符补全 |
| **Geometric Transforms** | 几何变换 | 12 | 仿射 / 投影 / 镜像 / 极坐标 / 向量场 | 倾斜校正、极坐标展开、镜头畸变校正 |

> **共同点**：四族都开始读邻域或进行空间重采样 —— 算子内部都会有 **Sigma/Size** 等"邻域尺寸"参数。
> 与上卷的 **Mult/Add**（点级缩放/偏置）相比，本卷的 **核心参数是"邻域半径/矩阵"**。

## 2. Edges（23）—— 边缘检测总览

> HALCON 把边缘算子按"是否带方向/是否亚像素/灰度or彩色"分门别类。
> 经典分类：
> - **3×3 / 5×5 卷积** 直接给幅值：Sobel / Prewitt / Roberts / Kirsch / Robinson / Frei
> - **二阶导** 给过零点：Laplace / LoG / DoG
> - **Canny 类**：高斯 → 梯度 → 非极大抑制 → 双阈值 + 滞后连接
> - **彩色版**：3 通道联合求幅值/方向
> - **辅助**：边缘闭合、查询滤波器

### 2.1 3×3 卷积边缘算子（共 12 个 = 6 套 × 2（幅/向））

| 算子 | 输出 | 卷积核特点 |
|---|---|---|
| `sobel_amp` / `sobel_dir` | 幅值 / 幅值+方向 | Sobel（含可调 Size，仅 `sobel_dir` 含平滑 Sigma） |
| `prewitt_amp` / `prewitt_dir` | 幅值 / 幅值+方向 | Prewitt |
| `kirsch_amp` / `kirsch_dir` | 幅值 / 幅值+方向 | Kirsch（8 方向加权） |
| `robinson_amp` / `robinson_dir` | 幅值 / 幅值+方向 | Robinson（3 套掩码） |
| `frei_amp` / `frei_dir` | 幅值 / 幅值+方向 | Frei（类同 Kirsch，归一化更平） |
| `roberts` | 幅值 | 2×2 Roberts 对角差 |

### 2.2 二阶导边缘

| 算子 | 输出 | 模型 |
|---|---|---|
| `laplace` | 二阶导幅值 | 4/8 邻域 Laplace，可配 MaskSize/FiterMask |
| `laplace_of_gauss` | LoG | 高斯 σ → 二阶导 → 寻过零点（亚像素） |
| `diff_of_gauss` | DoG | LoG 的近似，加速版本 |
| `derivate_gauss` | 高斯任意阶导数 | `Component='x'/'y'/'xx'/'xy'/'yy'` 任意 |

### 2.3 Canny 边缘（Canny 全流程）

| 算子 | 输出 | 用途 |
|---|---|---|
| `edges_image` | 幅值图 + 方向图（pixel） | 经典 Canny 灰度 |
| `edges_sub_pix` | 边缘 XLD（亚像素） | Canny 灰度亚像素 |
| `edges_color` | 幅值 + 方向（pixel） | 彩色版（3 通道联合） |
| `edges_color_sub_pix` | 边缘 XLD（亚像素） | 彩色版亚像素 |

Canny 算子关键参数（4 个）：
```
Filter : 'canny'/'deriche1'/'deriche2'/'lanser1'/'lanser2'/'shen'/'mshen'
Alpha  : double  // 平滑强度（与 Filter 配套）
NMS    : 'nms'/'none'/'hysteresis'  // 非极大抑制法
Low/High : int    // 双阈值
```

### 2.4 边缘辅助

| 算子 | 用途 |
|---|---|
| `close_edges` | 用梯度把断开的小段边缘"延伸闭合" |
| `close_edges_length` | 在 `EdgeImage` 上把缺口**沿梯度方向追踪指定像素** |
| `info_edges` | 查询上述 edges_* 支持的滤波器参数 |
| `highpass_image` | 频域高通（**双关**：算 subspace 杂讯） |

### 2.5 边缘流水线示例

```
原图 → derivate_gauss(I, Igauss, 1.5, 'x')   // 高斯平滑后取 x 方向导数
     → derivate_gauss(I, Igauss_y, 1.5, 'y')
     → sqrt(Igauss² + Igauss_y²)              // 自合成幅值图（融合版）
     → threshold(Amp, EdgeRegion, 30, 255)   // 阈值出边缘区域
     → close_edges(EdgeRegion, Amp, EdgeClosed, 1)   // 闭环
```

## 3. Enhancement（7）—— 图像增强算子

> 7 个算子目的不同：3 个对比度/直方图、3 个扩散方程、1 个去噪。

| 算子 | 子类 | 数学本质 |
|---|---|---|
| `equ_histo_image` | 直方图均衡 | 灰度级重映射到均匀分布（彩色按 R/G/B 三通道） |
| `emphasize` | 锐化（Unsharp Masking） | Output = I + Factor × (I − Mean(Mask)) |
| `illuminate` | 同态滤波 | H/L band 分离 → 滤低频 → 合成 → 抑照度不均 |
| `scale_image_max` | 自适应线性拉伸 | 自动按局部最大值重映射（等效方差归一） |
| `mean_curvature_flow` | 各向同性扩散 | ∂I/∂t = MC（沿等照度线平滑） |
| `coherence_enhancing_diff` | CED 扩散 | 各向异性，沿结构方向去噪 |
| `shock_filter` | 激波滤波 | 沿等照度线**锐化**（MCF 的对偶） |

> 💡 **3 种扩散** 互为对偶：
> - `mean_curvature_flow` —— 平滑保边
> - `coherence_enhancing_diff` —— 平滑且沿一致方向增强
> - `shock_filter` —— 反向锐化（沿等照度线尖锐化）
> 三个算子都共享 `Sigma`(正则化尺度) + `Theta`(时间步长) + `Iterations`(迭代次数)。

### 3.1 增强流水线：低对比度 OCR 案例

```
原图（明暗不均）
  → illuminate(I, Ihom, MaskW, MaskH, Factor)         // 同态，抑制照度
  → equ_histo_image(Ihom, Ieq)                        // 局部分布均衡
  → scale_image(Ieq, Inorm, 255/127.5, -127.5)        // 归一化（ch12 上卷）
  → emphasize(Inorm, Iout, 9, 9, 2.0)                  // 锐化
  → threshold(Iout, TextChar, 0, 50)                  // 出 OCR 区域
```

## 4. Inpainting（6）—— 5 种插值模型 + 1 纹理合成

> 当图上有"被打叉/划线/缺角"的小区域需要补全时用修补算子。
> 修补算子统一接口：`inpainting_*(Image, RegionMask : InpaintedImage : 参数)`。

| 算子 | 模型 | 适用场景 | 关键参数 |
|---|---|---|---|
| `harmonic_interpolation` | Laplace 解（调和函数） | 平滑渐变（图章擦拭、自然纹理） | `Precision`（收敛阈值） |
| `inpainting_aniso` | 各向异性扩散（沿等照度线） | 结构明显（裂缝、毛刺） | `Contrast`(对比控制)、`Theta`、`Iterations`、`Rho` |
| `inpainting_ced` | CED 各向异性 | 边缘/纹理的延伸 | 同 CED |
| `inpainting_ct` | Coherence Transport | **沿主方向**保持纹理 | 与 CED 同类但保留方向性 |
| `inpainting_mcf` | Mean Curvature Flow | 光滑（无结构）的填补 | `Sigma`、`Theta`、`Iterations` |
| `inpainting_texture` | 纹理合成采样 | 重复纹理（砖墙、织物） | 默认参数即可 |

> 全部修补算子都接受 `Region` 参数（要修补的区域 mask），**不是**基于像素图的"哪要补"判断。
> 通常用法：
> ```
> threshold(Diff, RepairMask, Threshold, 255)   // 找出需要补的部分
> inpainting_texture(I, RepairMask, Out)
> ```

## 5. Geometric Transformations（12）—— 空间重采样

> 把图像从 (row, col) 重映射到新坐标 (row', col')。HALCON 把变换分"重采样"和"矩阵类"两类。

### 5.1 4 类基本几何变换

| 算子 | 变换 | 接口 |
|---|---|---|
| `affine_trans_image` | 2D 仿射 (6 DoF：旋转+平移+均匀缩放+shear) | `ImageAffineTrans(I : O : HomMat2D, Interpolation, AdaptImageSize :)` |
| `affine_trans_image_size` | 仿射 + 显式指定输出 Width/Height | 同上 + `'Width','Height'` |
| `projective_trans_image` | 投影（8 DoF，单应性矩阵 H） | `ProjectiveTransImage(I : O : HomMat2D, Interpolation, AdaptImageSize :)` |
| `projective_trans_image_size` | 投影 + 显式尺寸 | 同上 |
| `rotate_image` | 绕中心 2D 旋转 | `rotate_image(I : O : Phi, Interpolation :)` |
| `zoom_image_factor` | 按比例缩放 | `zoom_image_factor(I : O : ScaleWidth, ScaleHeight, Interpolation :)` |
| `zoom_image_size` | 按目标尺寸缩放 | `zoom_image_size(I : O : Width, Height, Interpolation :)` |
| `mirror_image` | 镜像 | `mirror_image(I : O : 'Mode')`，Mode=`'row'`/`'column'`/`'diagonal'` |

### 5.2 极坐标变换

| 算子 | 用途 |
|---|---|
| `polar_trans_image_ext` | 笛卡尔 → 极坐标（带任意角度/半径区间，宽高自定义） |
| `polar_trans_image_inv` | 极坐标 → 笛卡尔（逆变换） |

极坐标变换把"环形/圆形物体"展成"矩形"——非常适合 OCR 圆环字符盘、雷达图、车牌圆框识别。

### 5.3 向量场畸变校正

| 算子 | 输入 | 输出 |
|---|---|---|
| `convert_map_type` | vector field (2-channel) ↔ map matrix | 转换两种格式 |
| `map_image` | `Image + Map` | 按 2D 向量场重采样 |

`map_image` 与 `affine_trans_image` 区别：仿射是**规则矩阵变换**，map_image 是**每像素独立向量**——适合镜头径向畸变、自定义鱼眼校正、像素级 warp。

### 5.4 关键参数速记

```
所有几何变换算子都共享：
  Interpolation : 'nearest_neighbor' / 'bilinear' / 'bicubic' / 'weighted'
                  （HALCON 默认 'weighted'，比双线性更好且更快）
  AdaptImageSize : 'true' / 'false'
                  （'true' 自动扩图避免裁剪；'false' 固定尺寸）
  TransformDomain : 'false'（默认）/'true'
                  （'true' 同时变换 domain 区域）
```

### 5.5 流水线：车牌倾斜校正

```
read_image(Img, 'plate')
  → edges_sub_pix(Img, Edges, 'canny', 1.0, 20, 40)   // 找边
  → segment_contours_xld(...)                           // 边分组
  → fit_line_contour_xld(...)                          // 拟合 4 条主边
  → gen_arrow_contour_xld(...) → hom_mat2d_from_3_points(...)  // 算 3x3 仿射
  → affine_trans_image(Img, PlateAligned, HomMat, 'bilinear', 'true')
```

## 6. 中卷算子与其他章节的关系

```
Ch12 中 邻域 + 空间变换
   ├─ Ch3 Image  → read_image / reduce_domain 给本卷准备输入

                    后面直接接 select_shape_xld / segment_contours_xld
```

### 7.3 性能速记

- 边缘算子是**单遍卷积**，N×N 图像、3×3 卷积核约 **O(N²)**，512×512 一帧在 1ms 量级
- Canny 的 NMS + 双阈值会比 edges_image 慢约 **5-10×**，亚像素版再 **2-3×**
- 各向异性扩散是**迭代算法**，Iterations 直接线性放大耗时，20 次 ≈ 30ms（512²）
- 投影变换 (`projective_trans_image`) 比仿射 (`affine_trans_image`) 重但**同等量级**（8 DoF vs 6 DoF）
- 极坐标 `polar_trans_image_ext` 不会做内存重分配，输入尺寸直接决定输出尺寸
- 向量场 `map_image` 必须先 `convert_map_type` 把 vector field 转成 map matrix，单遍几乎免费

## 8. 8 条常见误区

1. **`edges_image` 的 `Low/High` 是双阈值，不是 high-pass 阈值** —— 双阈值的比例通常 3:1（或 4:1），High 必须高于 Low。
2. **`sobel_amp` 的 `FilterType` 含 'sum_abs'/'sum_sqrt'/'thin_max_abs'** —— 不要跟 'canny' 混用，Canny 走 `edges_image`。
3. **`laplace_of_gauss` 返回的是"过零点图"而不是 LoG 图像** —— 想看 LoG 实际幅值，用 `laplace(Image, O, 'gradient', 3, 'n_4')`。
4. **`emphasize` 的 Factor 不是缩放系数** —— 是锐化强度（>1 锐化，<1 模糊，=0 返回原图）。
5. **`mean_curvature_flow` 的 `Sigma` 不是预平滑** —— 是"扩散控制尺度"，传 0 也会算。
6. **修补算子的 Region 是要修补的位置**，**不是**保留的区域 —— `Region=Mask` + 周边像素推算填补内容。
7. **`affine_trans_image` 的 HomMat2D 是 3×3 而非 3×2** —— HALCON 的 HomMat2D 内部用 3×3 齐次矩阵表示平移分量。
8. **`rotate_image` 的 Phi 是弧度** —— 想转 90° 传 `1.5708`（即 π/2），不是 90。

## 11. 备注

- 中卷最大族是 **Edges（23 个）**，且 edges_* 算子均有"color + sub_pix + gray + pixel" 4 种模式 —— 调用时按业务需求 4 选 1。
- 修补算子系列统一接 `Mask: Region` 参数，与 Ch13 Morphology 的 `morph_*` 算子共用 Region 概念，但语义相反：**修补用 Region = "要补的位置"**，而 morph 用 Region = "操作图章"。
- 几何变换是 Ch6 Calibration 的下游 —— HomMat2D 多由 `vector_to_hom_mat2d`/`hom_mat2d_rotate` 算出，再回灌 `affine_trans_image`。Ch6 调通后本卷可直接用。
- 下卷预告：**FFT 31 + Smoothing 24 + Noise/Wiener 11 + Misc 8 + Lines/Match/Points/OpticalFlow/SceneFlow/Texture 24 = 98 算子**，进入频域、空域线性滤波、特征点提取、光流场估计。
