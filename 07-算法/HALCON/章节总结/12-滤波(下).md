# 第 12 章 · Filters · 下卷 —— 频域 / 空域 / 特征与光流

> **章节定位**：本卷是 HALCON 第 12 章最大的部分，覆盖 **频域算法 + 邻域平滑 + 噪声模拟 + 特征点/线提取 + 模板匹配 + 光流/场景流 + 纹理 + Wiener 复原**等高级滤波场景。
> 前两卷是"基础计算"，本卷是"专业工具箱"。FFT 把图像频率拆开做相乘、卷积、相关；Wiener 把图像复原成清晰版；Harris/Foerstner/Lepetit 把角点点出来；光流/场景流把运动场算出来。

本卷算子数：**98 个**（按 11 子族，可聚为 **3 个超族**）：
- **频域组 (37)**：FFT(31) + Wiener(6)
- **空域组 (37)**：Smoothing(24) + Morphology Lattice(8) + Noise & PSF(5)
- **特征+光流组 (24)**：Corner/Points(7) + Lines(4) + Match(4) + OpticalFlow(4) + SceneFlow+Texture(5)

---

## 1. 下卷三大超族一览

| 超族 | 中文 | 算子数 | 核心抽象 | 典型用法 |
|---|---|---|---|---|
| **Frequency** | 频域组 | 37 | 2D FFT + 频域滤波器核 + Wiener 反演 | 卷积加速、纹理分析、运动估计、图像复原 |
| **Spatial** | 空域组 | 37 | 邻域核（均值/中值/高斯/双边）+ 噪声模型 | 去噪、降采样、抗混叠、HDR 平滑 |
| **Features+Flow** | 特征+光流 | 24 | 关键点检测 + 模板匹配 + Lucas-Kanade / HS 光流 | 视觉 SLAM、目标跟踪、运动估计 |

> **共同点**：本卷算子在 HALCON 中常**互相串联** —— `fft_image → 乘频域滤波器 → ifft_image` 是标准流水线；`gaussian_pyramid → optical_flow → unwarping` 是光流法运动补偿。

## 2. 频域组（37）= FFT(31) + Wiener(6)

### 2.1 FFT 频谱分析族（31）

> HALCON 的 FFT 设计成 **"前向 → 频域乘法 → 反向"** 三件套，外加 FFT 尺寸优化缓存（Gabor 小波与子带滤波器也在本族）。

#### 2.1.1 基础 FFT 对

| 算子 | 形式 | 说明 |
|---|---|---|
| `fft_image` | `Image → ImageFFT (复)` | 前向 2D FFT（输入实图 → 输出复频谱） |
| `fft_image_inv` | `Image (复频谱) → 复数逆变换` | 反 2D FFT |
| `fft_generic` | `Image(Image) ↔ Image(FFT)`, 可选 Direction/Mode | 通用 N-D FFT（一般 2D），可指定方向/模式/范数 |
| `fft_inv_fft` | 直接配对调用 | 内部完成 forward→inverse |
| `rft_generic` | `Image (实) ↔ 半复谱` | 实值 FFT（输出复图，节省一半内存） |
| `cumulate_fft` | 累积多帧 FFT | 时序均化（噪声抑制） |
| `phase_correlation_fft` | 亚像素位移估计 | 两幅 FFT 相位相关 → 位移 |

#### 2.1.2 频域滤波器生成器

| 算子 | 输出 | 用途 |
|---|---|---|
| `gen_bandfilter` | 任意 2D 带通/陷波（圆形/矩形可选） | 通用频域滤波核 |
| `gen_bandpass` | 频域带通（**gen_bandfilter 别名**） | 同上 |
| `gen_bandpass_filter` | 频域带通（细节略不同） | 兼容旧版 |
| `gen_derivative_filter` | 高斯 n 阶导数 | 时/频通用的导数 |
| `gen_filter_mask` | 通用滤波遮罩（衰减型） | 自定义频域衰减 |
| `gen_gabor` | 2D Gabor 频域 | 频域 + 空间联合滤波 |
| `gen_gauss_filter` | 频域高斯 | 频域低通近似 |
| `gen_highpass` | 高通强调（频域径向截断） | 锐化/纹理 |
| `gen_lowpass` | 低通（频域） | 去噪 |
| `gen_mean_filter` | 频域均值 | 盒式低通的频域实现 |
| `gen_sin_bandpass` | 频域带通 + 乘性正弦 | 频域带通子类 |
| `gen_std_bandpass` | 标准差加权带通 | 自适应带通 |
| `gen_wiener_filter` | Wiener 复原核 | 频域反卷积 |

#### 2.1.3 频域卷积/相关

| 算子 | 形式 | 说明 |
|---|---|---|
| `convol_fft` | 频域卷积 | 比空域快（N²logN vs N²kernel） |
| `convol_gabor` | 频域 Gabor | Gabor 卷积 |
| `correlation_fft` | 频域互相关 | 模板匹配基础 |
| `energy_gabor` | Gabor² + Hilbert² | Gabor 能量图 |

#### 2.1.4 相位/功率/小波/优化

| 算子 | 形式 | 说明 |
|---|---|---|
| `phase_deg` | 复图 → 相位（度） | 取相位 |
| `phase_rad` | 复图 → 相位（弧度） | 同上 |
| `power_byte` / `power_ln` / `power_real` | 复图 → 幅值（多种压缩） | 取幅值，3 种压缩法 |
| `zero_crossings` | 复图 → 过零点 | 二阶导零点 |
| `symm_difference_fft` | 两 FFT 频谱对称差 | 频域对比 |
| `decompose2`/`decompose3`/`decompose4`/`decompose5`/`decompose7`/`decompose9` | 标准 2/3/4/5/7/9 矩阵小波分解 | 静态度小波分解 |
| `convert_image_type` | byte↔int↔real↔complex | FFT 前后必须做类型转换 |
| `mean_image_squash` | 块均值 + 自动补齐 2^k | FFT 前尺寸准备 |

#### 2.1.5 FFT 优化缓存（性能提速）

| 算子 | 用途 |
|---|---|
| `optimize_fft_speed` | 缓存特定尺寸 FFT 系数（持久化） |
| `optimize_rft_speed` | 同上，RFT 版 |
| `serialize_fft_optimization_data` | 把缓存序列化（存盘/分享） |
| `deserialize_fft_optimization_data` | 反序列化 |
| `read_fft_optimization_data` | 从文件读 |
| `write_fft_optimization_data` | 写到文件 |

> **为什么需要优化**：`fft_image` 用 NTT 算法对 2^k×2^k 尺寸最快。第一次做某尺寸 FFT 会 cache 系数；用 `optimize_fft_speed` 提前准备某个尺寸的缓存，后续 8 倍速提升。

### 2.2 Wiener 维纳复原族（6）

> 维纳复原是"频域反卷积"的经典实现——把模糊+噪声图复原。
>
> | 算子 | 形式 | 说明 |
> |---|---|---|
> | `wiener_filter` | Wiener 滤波（自估噪声） | 通用 Wiener |
> | `wiener_filter_ni` | Wiener 滤波（不估噪声） | 用 `NoisePower` 指定 |
> | `gen_wiener_filter` | 构造 Wiener 核 | 仅生成核 |
> | `gen_wiener_filter_mask` | 同上含归一化噪声幂 | 通用版 |
> | `simulate_defocus` | 合成散焦模糊 | 测试图 |
> | `simulate_motion` | 合成运动模糊 | 测试图 |

`gen_psf_defocus` 与 `gen_psf_motion` 在 toc_filters_misc 也算——它们产生 Wiener 所需的 PSF（点扩散函数）。

### 2.3 频域流水线

```
原图 → gen_lowpass(Filter)              // 频域低通核
     → fft_image(Img, FFT)               // 前向 FFT
     → gen_filter_mask(Filter)            // 可选：自定义滤波遮罩
     → convol_fft(FFT, Filter, FFTOut)   // 频域相乘
     → fft_image_inv(FFTOut, Filtered)   // 反 FFT
     → power_real(FFTOut, Amp)            // 提取幅值
```

```
运动模糊图 → gen_psf_motion(PSF, len, angle)   // 估计 PSF
         → fft_image(Blur, BlurFFT)
         → fft_image(PSF, PSF_FFT)
         → gen_wiener_filter(Wiener, PSF_FFT, NSR)  // 造 Wiener 核
         → convol_fft(BlurFFT, Wiener, OutFFT)
         → fft_image_inv(OutFFT, Restored)
```

## 3. 空域组（37）= Smoothing(24) + Morphology+Lattice(8) + Noise & PSF(5)

### 3.1 Smoothing 邻域平滑（24）

> HALCON 把邻域平滑分类做得很细：核（盒 / 高斯 / 中值 / 双边 / 引导 / 二项式 / Sigma）、结构（圆 / 矩 / 任意形状结构元）、去噪模式（截尾 / 盐椒去除 / 范围均值）。

| 算子 | 核 | 说明 |
|---|---|---|
| `mean_image` | 盒形（行×列矩形） | 最快 |
| `mean_n` | n×n 圆形均值 | 圆核均值 |
| `mean_sp` | 均值（盐椒鲁棒） | 仅去除极值点 |
| `gauss_filter` | 高斯（含导数选项） | 标准 Sigma 高斯 |
| `gauss_image` | 高斯平滑档 | 等同 gauss_filter 平滑 |
| `binomial_filter` | 二项式（高斯近似） | 高速（基于整数卷积） |
| `sigma_image` | Sigma 加权均值 | 邻域加权中位类 |
| `bilateral_filter` | 双边 | 保边平滑 |
| `guided_filter` | 引导 | 可沿引导图定向增强 |
| `median_image` | 中值（圆形/方形） | 抗盐椒 |
| `median_separate_image` | 行列分离中值 | 快 4× |
| `median_separate` | 行列分离中值（通用版） | 同上 |
| `median_rect` | 矩形核中值 | 矩形 ROI |
| `median_weighted` | 加权中值 | 中心权重大 |
| `midrange_image` | 取 max/min 的中点 | 抗极值但保留中点 |
| `rank_image` | 任意形状结构元秩 | 任意 Mask |
| `rank_n` | 圆核秩 | 圆形的特定 rank |
| `rank_rect` | 矩形核秩 | 矩形 ROI |
| `trimmed_mean` | 截尾均值 | 去极值后取均值 |
| `eliminate_min_max` | 同 trim_mean 但仅去 1 min+1 max | 比 trim_mean 快 |
| `eliminate_sp` | 剔除盐椒 | 自动判黑/白极值 |
| `fill_interlace` | 去交错 | 拼接奇偶行 |
| `smooth_image` | 用任意 Mask 平滑 | 自定义核 |
| `anisotropic_diffusion` | 各向异性（Perona-Malik） | 边缘保留 |
| `isotropic_diffusion` | 各向同性（线性扩散） | 经典高斯 |
| `info_smooth` | 查询平滑算子支持的组合 | 辅助 |

> 注：24 算子里 `closing`、`opening`、`top_hat` 也算"平滑族"，但本质是形态学。这里混入 Morphology+Lattice 组（见 §3.2）。

### 3.2 Morphology & Lattice（形态/微元）族（8）

> 下卷混入"灰度形态学"算子，因为它们都读邻域。

| 算子 | 操作 |
|---|---|
| `closing` | 灰度闭运算（min 后 max） |
| `opening` | 灰度开运算（max 后 min） |
| `top_hat` | 白/黑 顶帽（用于不均匀校正） |
| `gray_inside` | 判定闭/开运算后是否在内部 |
| `gray_skeleton` | 灰度骨架化 |
| `expand_domain_gray` | 把域外像素按最近边值扩展 |
| `mean_n` / `mean_sp` | 同 Smoothing 章 |

> ⚠️ 完整的区域形态学（bin/closing-rect/...）在 Ch13 Morphology。Ch12 这 8 个是**灰度图上的形态学**。

### 3.3 Noise & PSF（噪声与点扩散）族（5）

| 算子 | 用途 |
|---|---|
| `add_noise_white` | 加高斯白噪声（指定 Sigma） |
| `add_noise_distribution` | 按指定直方图分布加噪 |
| `gauss_distribution` | 生成高斯分布点集 |
| `noise_distribution_mean` | 调均值的噪声分布 |
| `sp_distribution` | 盐椒分布生成 |

> 这族常用于训练 CNN、生成测试图、合成数据增强。

### 3.4 Misc 杂项（4）

| 算子 | 用途 |
|---|---|
| `lut_trans` | 任意整数函数 LUT 变换（Ch12 上卷是 Color 专用，这是通用亮度 LUT） |
| `symmetry` | 局部对称性检测（视觉对称度图） |
| `topographic_sketch` | 分水岭+山脊+谷底骨架绘制 |
| `convol_image` | 通用 2D 卷积（中卷也提过，区别是中卷是紧密卷积核） |

### 3.5 邻域平滑流水线

```
高对比度噪声图
  → anisotropic_diffusion(I : O : 0.5, 5.0, 0.5, 20)    // 早期平滑
  → median_image(O : M : 'circle', 3, 'mirrored')          // 抗盐椒
  → bilateral_filter(M : B : 5, 5, 75, 75)                 // 保边
  → binomial_filter(B : Out : 3, 3)                         // 终平滑
```

## 4. 特征+光流组（24）= Points(7) + Lines(4) + Match(4) + OpticalFlow(4) + SceneFlow+Texture(5)

> 这一组全部是"提取图上的某种几何/运动信息" —— 关键点、直线、模板、光流场、3D 场景流、纹理。算子之间经常组合：先提点 → 再 match → 算变换矩阵。

### 4.1 Corner / Points（角点检测）族（7）

| 算子 | 用途 |
|---|---|
| `points_harris` | Harris 角点（最常用） |
| `points_harris_binomial` | Binomial 近似的 Harris 角点（快） |
| `points_foerstner` | Foerstner 角点（亚像素） |
| `points_lepetit` | Lepetit 角点（关键点稳健） |
| `points_sojka` | Sojka 角点（含可调阈值） |
| `corner_response` | Harris / Tomasi-Kanade 响应函数 |
| `dots_image` | 在 1 通道图上绘制散点（**可视化**，不算检测） |

### 4.2 Lines（直线检测）族（4）

| 算子 | 用途 |
|---|---|
| `lines_gauss` | 1D 高斯匹配（亚像素 Hough 直线） |
| `lines_color` | 彩色图像直线（Hough） |
| `lines_facet` | 基于 facet 模型直线提取 |
| `bandpass_image` | 带通（DOG 类，提取特定频率） |

### 4.3 Match（模板匹配）族（4）

| 算子 | 用途 |
|---|---|
| `match_template` | 通用模板匹配（互相关、归一化、旋转） |
| `match_template_byte` | byte 图专用模板匹配 |
| `match_template_region` | 用 Region 做模板 |
| `exhaustive_match` | 穷尽模板匹配（指定多角度） |

> `exhaustive_match` 跟 `match_template` 不同：前者**指定角度列表穷举**，后者**自动检测旋转**。

### 4.4 Optical Flow（光流场）族（4）

| 算子 | 用途 |
|---|---|
| `optical_flow_mg` | 多分辨率 Horn-Schunck 光流 |
| `derivate_int_2x2` | 2×2 像素差分积分（导数底层） |
| `derivate_gauss` | 高斯导数（任意阶） |
| `unwarp_image_vector_field` | **向量场畸变校正**（中卷 Geometric 也列） |
| `vector_field_length` | 向量场幅值图像 |
| `derivate_vector_field` | 向量场各阶空间导数 |

> `derivate_gauss` 跟 `derivate_vector_field` 都属于"导数"系列 —— 前者是空间导数，后者是向量场导数。

### 4.5 Scene Flow & Texture（3D 光流/纹理）族（5+，合并）

| 算子 | 用途 |
|---|---|
| `scene_flow_3d` | 前向 3D scene flow |
| `scene_flow_calib` | 标定相机的 3D scene flow |
| `scene_flow_uncalib` | 无标定 scene flow |
| `texture_laws` | Laws 纹理滤波（25 通道） |
| `monotony` | 局部单调性度量 |
| `entropy_image` | 局部熵图（纹理不均匀度） |
| `gen_gauss_pyramid` | 多分辨率高斯金字塔（光流法的输入） |
| `deviation_image` / `deviation_n` | 局部标准差 |

### 4.6 特征流水线（范例）

```
detection pipeline (静态目标)
  → points_foerstner(I, Points, 'high')
  → gen_parhalton_sp(Points, ... )         // Ch18 OCR 用，下卷不展开
  → match_template_region(...)              // 用 Point 周围 patch 做匹配
  → vector_to_hom_mat2d(...)               // 算位姿

motion pipeline (运动目标)
  → gen_gauss_pyramid(I1, P1, ...)
  → gen_gauss_pyramid(I2, P2, ...)
  → optical_flow_mg(P1, P2, U, V)         // 多尺度光流
  → vector_field_length(U, V, LengthImage)
```

## 6. 速查卡（3 张）

### 6.1 1 行级速查："我想要 X → 用哪个算子"

| 需求 | 算子 |
|---|---|
| 图像频域分析 | `fft_image(I, FFT)` → `phase_rad(FFT)` → `power_real(FFT)` |

| Wiener 复原（散焦） | `gen_psf_defocus + gen_wiener_filter + fft_image + fft_image_inv` |
| 高斯平滑 | `gauss_filter(I, O, 1.5)` |
| 中值滤波（保边抗盐椒） | `median_image(I, O, 'circle', 3, 'mirrored')` |
| 双边（保边平滑） | `bilateral_filter(I, O, 5, 5, 75, 75)` |
| 各向异性扩散 | `anisotropic_diffusion(I, O, ...)` |
| 引导图增强 | `guided_filter(I, Guide, O, ...)` |
| 高斯金字塔 | `gen_gauss_pyramid(I, P, 'half')` |
| Harris 角点 | `points_harris(I, Points, 1.5)` |
| Foerstner 角点（亚像素） | `points_foerstner(I, Points, 'high')` |
| Hough 直线 | `lines_gauss(I, Lines, 1.5, 'light', 'true')` |
| 模板匹配（旋转不敏感） | `match_template(I, Template, Result, 5, 5)` |
| 亚像素位移 | `phase_correlation_fft(I1, I2)` |
| 多尺度光流 | `optical_flow_mg(I1, I2, U, V, 3, 5, 0.5, ...)` |

| 加高斯噪声 | `add_noise_white(I, Noisy, 30)` |

### 6.2 关键参数速记

```

Smoothing:
  gauss_filter(I : O : Size, FilterType, ...)
  median_image(I : O : MaskType, Radius, Boundary)
  bilateral_filter(I : O : MaskWidth, MaskHeight, SigmaSpatial, SigmaRange :)
  anisotropic_diffusion(I : O : Sigma, Rho, Theta, Iterations :)
  guided_filter(I, Guide : O : Radius, eps :)

Features:
  points_harris(I : Points : MinDistance, Sigma, ...)
  points_foerstner(I : Points : Method, Sigma, 'true')
  lines_gauss(I : Lines : Sigma, Low, High, LightDark, Extract, ...)
  match_template(I, Template : Result : NumLevels, AngleStart, AngleExtent, ...)
  optical_flow_mg(I1, I2 : U, V : MGParamName, MGParamValue, ...)
    // 见 help optical_flow_mg，参数是 HTuple 组
```

### 6.3 性能速记

- **FFT 是 N²logN**，比直接卷积的 **N²** 仅当 N > 64 时才有优势（Hough 平滑预算）
- **Gauss 滤波**已用可分离卷积加速（独立 X / Y），`binomial_filter` 比 `gauss_filter` 再快 ~3×
- **中值滤波**是 O(N²log(r²))，大图像要用 `median_separate`（行列分离）快 5×
- **双边滤波**O(N²) 但常数大，512² 用 guided_filter 替代提速 8×
- **Harris**O(N²)，`points_harris_binomial` 用 Binomial 近似，比 Harris 快 3×
- **Hough lines** 在 2048² 上 RT 30 ms（亚像素版）；`lines_gauss` 比 `lines_color` 快 3×
- **光流** 是迭代算法，`optical_flow_mg` 顶层迭代数 × 3-5 是常见耗时；512² 单对帧约 50 ms
- `optimize_fft_speed` 缓存后**后续同尺寸 FFT 加速 8 倍**——大产线必备

## 7. 8 条常见误区

1. **`fft_image` 输入必须是 byte/int/int1/real**，**不能直接对 'complex' 图再 fft_image**（用 `fft_generic`）。
2. **FFT 要求尺寸是 2 的幂才最快**，否则 HALCON 自动补齐到 2^k（边缘置 0）。要严格控制尺寸用 `optimize_fft_speed` 预热。
3. **`bilateral_filter` 的边界处理较慢**，256×256 比 512×512 大约慢 4 倍——大图分块处理更划算。
4. **`wiener_filter` 需要准确的 PSF**——Wiener 不是"无脑去模糊"，错估 PSF 会把噪声放大。
5. **`median_image` 的 `'circle'` 半径参数 ≠ 像素距离**，而是"包含几像素"（半径内的全部像素）。
6. **`points_harris` 不是 OpenCV 的最小响应阈值**，HALCON 取的是局部极大；阈值要随图调整。
7. **`match_template` 的 'normalized' 模板匹配对光照变化鲁棒**，**但**对旋转/缩放不鲁棒——后者用 `exhaustive_match`。
8. **`optical_flow_mg` 的 MGParam 必须是 HTuple**，每行 `('parameter_name', value, ...)`。HDevelop 调用需要传 tuple，Python 用 dict。

## 10. 备注

- 本卷算子数最多（98），但**核心数学工具**只 5 个：FFT、平滑、直线、角点、光流。其余都是参数化变体。
- **频域族**对**输入尺寸敏感**（2^k 优化），对**长流水线**特别有用（大核卷积）。
- **光流族**对帧间差敏感，**生产部署前**应用 `mean_image`/`gauss_filter` 先做轻度预平滑。
- **特征点族**输出是 `HTuple` of (row, col)，与第 15 章节 Segment/Contour 紧密关联。
- **Ch12 下**是 HALCON 算子手册中**导出可移植性仍高**的部分：`fft_image`、`gauss_filter`、`points_harris`、`match_template`、`optical_flow_mg` 在 C++/Python/.NET 全部可用（仅参数命名风格变化）。
