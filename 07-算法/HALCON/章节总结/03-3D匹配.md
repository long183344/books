# 第 3 章 · 3D Matching 算子体系总结

> **一句话结论**：这一章正式跨进 **3D 世界**——前两章（第 1 / 2 章）都是"在 2D 像素图里找特征"，本章直接在 **3D 点云 / 3D 物体模型** 里做匹配，返回物体在场景里的 **6 自由度位姿 (Pose)**：3 个平移 + 3 个旋转。本章 40 个算子围绕 **4 大匹配家族** 展开——**3D Box**（找规则长方体）、**Deformable Surface-Based**（找柔性可变形曲面）、**Shape-Based**（基于 3D CAD 的特征匹配）、**Surface-Based**（基于稠密点云的曲面匹配）。每家的"造模型 → 造匹配器 → 出结果 → 取参 → 存取"流水线都长得一模一样，按"族"理解即可。
>
> **数据基准**：HALCON 20.11.1.0 ｜ **难度**：中高 ｜ **前置**：[章节总结 01-1D测量](./../01-1D测量.md)（1D 边缘测量基础）、[章节总结 02-2D测量](./../02-2D测量.md)（MetrologyHandle 概念）；本章起涉及 `ObjectModel3D` / `Pose` / `CamParam` / `XYZ Mapping` 等 3D 概念，详见 §2 词汇表。

## 0. 速查：3 章的核心区别

| | 第 1 章 1D Measuring | 第 2 章 2D Metrology | **第 3 章 3D Matching** |
| --- | --- | --- | --- |
| **核心句柄** | `MeasureHandle` (一条扫描带子) | `MetrologyHandle` (一整张 2D 测量图纸) | `ModelID` 各族不同 (ShapeModel3DID / SurfaceModelID / DeformableSurfaceModel)** |
| **数据维度** | 2D 像素图 + 几何形状 | 2D 像素图 + 几何形状混装 | **3D 点云 (ObjectModel3D) + 6 自由度 Pose (3 移 + 3 转)** |
| **一次找几个** | 1 个边缘点对 | 同模型多个对象实例 | **多个候选实例 + 每个的位姿** |
| **核心输入** | `Image` + `measure_*` | `Image` + `MetrologyHandle` | **`ObjectModel3D` 场景 + `ModelID`** |
| **粗定位** | 手工 `translate_measure` | `align_metrology_model` | 由模型搜索 `find_*` 本身 (Pose 直接做粗+精) |
| **精定位** | `measure_*` | `apply_metrology_model` | `refine_*_pose` (可再次精化) |
| **结果类型** | 边缘点 (Row, Column) | 几何参数 (中心/半径/角度) | **3D 位姿 `Pose` (7 或 8 元 pose 串) + 评分 `Score` + 可选 3D 物体** |
| **典型场景** | PCB 焊盘宽 | 一张 PCB 30 个尺寸一次测完 | **机器人抓取/姿态识别/无序抓取 (Bin Picking) / 3D 尺寸测量** |

> 一句话：**前 2 章问"图里这个尺寸对不对"，第 3 章问"场景里这个东西在 3D 空间的姿态是什么"。** 第 3 章不再是边缘测量，是**物体识别 + 位姿估计**。

## 1. 为什么需要 3D Matching？

第 1 / 2 章只能告诉你 2D 像素层面的几何尺寸信息。但工业 / 机器人场景里有大量问题必须靠"3D 位姿"才能回答：

1. **机器人无序抓取 (Bin-Picking)**
   一堆混放的机械零件散在箱子里 → 用 3D 点云 → **找到每个零件的精确 6 自由度位姿** → 告诉机器人从哪个角度、抓哪点能被夹起来。
2. **3D 检测 / 在线量测**
   工件三维尺寸 (长宽高、内孔深、平面度) → 用 3D 模型 → **测整件**而不是单特征。
3. **箱体抓取 (`find_box_3d`)**
   物流场景：标准纸箱/塑料箱在传送带/料框里 → 用 3D 数据 → **直接找到整箱可夹持位置 + 长宽高**，无需知道箱体纹理。
4. **柔性变形工件**
   食品、橡胶、塑料软管、布料 → 形状会变 → **Deformable Surface-Based** 用一个"统计变形模板"找到柔性物体的实际形态。

> **凡是要回答"这堆点云里有没有我认识的物体，有的话它在哪儿、朝向怎样、用哪点可以抓"——翻本章节。**

### 1.1 全章涉及的核心对象 / 概念（含量 4 条术语的解释）

| 概念 | 一句话解释 | 何时出现 |
| --- | --- | --- |
| **`ObjectModel3D`** | 整个 HALCON 里"3D 数据"的统一表示。可能是点云 (`xyz_to_object_model_3d`) / 多边形网格 / 三角面片 / 边 (`edges_object_model_3d`)。所有 3D 算子的"参数"和"返回值"。 | 全章几乎每个算子都有这玩意儿 |
| **`Pose`** | 一个 6 自由度位姿，本质是一个 **7 元 (transX, transY, transZ, rotX, rotY, rotZ, Code) 或 8 元** 的 tuple。`create_cam_pose_look_at_point` 是构造它的简单办法。**单位长度=米，旋转=弧度**。 | `find_*` / `refine_*` 永远返回 `Pose` |
| **`XYZ Mapping` (X/Y/Z 三通道图)** | 3D 点云最简易的图像表达——3 张普通 2D 图像，分别存每个像素的 X、Y、Z (米) 坐标。`xyz_to_object_model_3d` 把这 3 张图变成 `ObjectModel3D`。`find_box_3d` 直接吃这种图。 | 3D Box 分支；其他形状匹配前的预处理 |
| **`CamParam` (相机内参)** | 相机的焦距、像素尺寸、像主点、畸变系数等。算子是相机无关的不需要它，但 `create_shape_model_3d` / `find_shape_model_3d` / `project_shape_model_3d` 等要靠它把"3D 模型"投影回 2D 图像。 | Shape-Based 全族 |
| **`Score`** (分数) | 模型在某个位姿下的匹配度，0~1。生产实战中 `MinScore=0.7~0.85` 是常见起点。 | `find_*` / `refine_*` 返回值 |
| **`RelSamplingDistance`** (相对采样距离) | 模型点云 / 场景点云的采样密度系数，相对于模型"直径"。`0.05`=用模型 5% 直径做采样间隔，**越小越精细越慢**。 `0.1` 粗，`0.02` 细。 | `create_surface_model` / `find_surface_model` |

## 2. 全章 40 个算子按 4 大族分组

| 族 | 个数 | 一句话职责 | 关键算子速览 |
| --- | --- | --- | --- |
| **A. 3D Box** | **1** | 在 3D 数据里找**规则长方体**（纸箱/料箱），输出可夹持位姿 + 3 边长范围 | `find_box_3d` |
| **B. Deformable Surface-Based** | **13** | 找**柔性可变形**物体（食品/橡胶/软管），用"统计形变模板"匹配 | `create_deformable_surface_model` / `find_deformable_surface_model` / `refine_deformable_surface_model` / `add_*_sample` |
| **C. Shape-Based** | **12** | 基于 **3D CAD 物体模型** + 相机内参，枚举枚举**视图**去匹配——比 surface-based 更快但要求物体有大体固定形状 | `create_shape_model_3d` / `find_shape_model_3d` / `project_shape_model_3d` / `trans_pose_shape_model_3d` |
| **D. Surface-Based** | **14** | 基于**稠密点云 + 法向量**，对场景与模型的曲面匹配——通用性最强 | `create_surface_model` / `find_surface_model` / `refine_surface_model_pose` / `find_surface_model_image` |
| | **40** | | 4 族 40 算子 ✅ |

> 总数校验：1 + 13 + 12 + 14 = **40** ✅

## 4. 族 A. 3D Box（仅 1 个算子，但功能完整）

### 4.1 用途 & 何时选

你**只想找一个规则长方体**（纸箱/塑料箱/木箱/砖块），不需要知道它表面任何纹理或细节。输入是**整个场景的 3D 点云** (XYZ Mapping)，输出是**可夹持位姿 + 3 边长范围**。典型场景：物流分拣、料箱上件。

### 4.2 算子详解

```
find_box_3d( : :
            ObjectModel3DScene : 场景点云 (XYZ Mapping from xyz_to_object_model_3d)
            SideLen1 : X轴方向的 (min, max)，如 [0.3, 0.5]
            SideLen2 : Y轴方向的 (min, max)
            SideLen3 : Z轴方向的 (min, max)，设为 -1 表示不限深（只看到一面）
            MinScore : 0.6 默认（0..1）
            GenParam : 'num_scene_points', 'max_overlap_dist_*', ... 见 §6.4
            :
            GrippingPose : 6 自由度位姿，机器人抓这个 Pose 就能夹起来
            Score       : 该候选的评分
            ObjectModel3DBox : 检出长方体本身（三角化后），可画可取
            BoxInformation : Dict，含 box_pose / box_length_x/y/z /
                            gripping_pose / score / sampled_edges /
                            sampled_scene / gen_param
                          )
```

### 4.3 关键参数经验值

| 参数 | 常见设定 | 原因 |
| --- | --- | --- |
| `SideLen{1,2,3}` | `(min, max)` 比如纸箱 `(0.2, 0.4)` | 给一个范围，算法在范围内穷举验证 |
| `SideLen3 = -1` | 不限深度 | 只看到箱体一面也能找 |
| `MinScore` | 默认 0.6，工业验证建议 0.7 | 越低误检越多 |
| `'num_scene_points'` GenParam | `10000` 左右 | 采样的场景点数，太少会找不到 |
| `'max_overlap_dist_abs'` | 0.05~1 | 多目标时的最小间隔 |

### 4.4 HDevelop 1 行实战

```hdevelop
* 1. 准备场景点云
xyz_to_object_model_3d(X_xyz, Y_xyz, Z_xyz, OM3D_scene)

* 2. 找箱子
find_box_3d(OM3D_scene, \
            [0.30, 0.50], [0.20, 0.40], [-1, -1], \  * 长宽已知，高未限
            0.7, [], \
            GrippingPose, Score, OM3D_box, BoxInfo)

* 3. 用 Pose 算夹爪坐标
pose_to_hom_mat3d(GrippingPose, HomMat3D)
affine_trans_point_3d(HomMat3D, 0, 0, 0, GripX, GripY, GripZ)

clear_object_model_3d([OM3D_scene, OM3D_box])
```

## 5. 族 B. Deformable Surface-Based（柔性变形匹配）

### 5.1 用途 & 何时选

**物体形状会变化**——鱼、面包、软管、曲面广告板、布料等不能用刚体 6D 位姿匹配。本族的做法是：

1. **离线采集** K 个 3D 样例（鱼 50 条各拍一张 3D）
2. **`add_deformable_surface_model_sample`** 把每个样本加入
3. **`add_deformable_surface_model_reference_point`** 在每个样本上指定语义点（比如"鱼嘴"）
4. **`create_deformable_surface_model`** 综合所有样本学出一个"统计形变模板"
5. **运行时**，用 `find_deformable_surface_model` 在场景里找一条鱼
6. 可用 `refine_deformable_surface_model` 用一张初始模板再精修位置

### 5.2 13 个算子一览

| 算子 | 一句话用途 |
| --- | --- |
| `create_deformable_surface_model` ( : : `ObjectModel3D`, `RelSamplingDistance`, `GenParam`, `GenParamValue` : `DeformableSurfaceModel`) | 用样本 + Reference Points 建柔性模型（离线） |
| `add_deformable_surface_model_sample` ( : : `DeformableSurfaceModel`, `ObjectModel3D` : ) | 添加一个 3D 样本（**多次调用累积**） |
| `add_deformable_surface_model_reference_point` ( : : `DSM`, `ReferencePointX/Y/Z` : `ReferencePointIndex`) | 在**最新加入的样本**上指定语义点 |
| `find_deformable_surface_model` ( : : `DSM`, `Scene3D`, `RelSamplingDistance`, `MinScore`, `GenParam`, `GenParamValue` : `Score`, `DeformableSurfaceMatchingResult`) | 在场景中找柔性实例 |
| `refine_deformable_surface_model` ( : : `DSM`, `Scene3D`, `RelSampling`, `InitialDeformationObjectModel3D`, `GenParam`, `GenParamValue` : `Score`, `DeformableSurfaceMatchingResult`) | 已找到的匹配再用一张样本精修 |
| `get_deformable_surface_matching_result` ( : : `Result`, `ResultName`, `ResultIndex` : `ResultValue`) | 取匹配的位姿/参考点/轮廓等 |
| `get_deformable_surface_model_param` ( : : `DSM`, `GenParam` : `GenParamValue`) | 查模型参数 |
| `read/write/serialize/deserialize` `deformable_surface_model` | 持久化（4 件套） |
| `clear_deformable_surface_model` | 释放句柄 |
| `clear_deformable_surface_matching_result` | 释放匹配结果 |

### 5.3 `find_deformable_surface_model` 关键 GenParam

| GenParam Name | 作用 | 常见值 |
| --- | --- | --- |
| `'model_invert_normals'` | 模型法向是否需要翻转 | `'true' / 'false'` |
| `'scale_min' / 'scale_max'` | 模型允许的尺度范围（变化范围） | `0.9`, `1.1` |
| `'bending_max'` | 最大弯曲度量 | `5`, `10`, `20` |

### 5.4 工作流示例（伪 HDevelop）

```hdevelop
* ============ 离线训练期 ============
* 读 K 张 3D 样本 (鱼的 3D scan)
read_object_model_3d('sample1.om3', 1, [], [], OM3D_Sample, 1)

* 用第一条样本初始化柔性模型（这里"创建"将所有 add 的样本合并）
create_deformable_surface_model(OM3D_Sample, 0.05, [], [], DSM)

* 加额外样本
for i := 2 to K by 1
    read_object_model_3d('sample'+i+'.om3', 1, [], [], OM3D_i, 1)
    add_deformable_surface_model_sample(DSM, OM3D_i)

    * 在样本 i 上加 3 个参考点 (例如鱼头、鱼尾、鱼鳃)
    add_deformable_surface_model_reference_point(DSM, X1, Y1, Z1)
    add_deformable_surface_model_reference_point(DSM, X2, Y2, Z2)
    add_deformable_surface_model_reference_point(DSM, X3, Y3, Z3)
endfor

write_deformable_surface_model(DSM, 'fish.dsm')

* ============ 运行时 ============
read_deformable_surface_model('fish.dsm', DSM)
find_deformable_surface_model(DSM, OM3D_Scene, 0.03, 0.7, [], [], \
                               Score, Result)
get_deformable_surface_matching_result(Result, 'pose', 0, PoseOut)
```

## 6. 族 C. Shape-Based（基于 3D CAD 的多视图匹配）

### 6.1 用途 & 何时选

你**有一份 3D CAD 模型**（STL / PLY / OBJ），并且你**有相机的内参** (`CamParam`)。你需要从枚举"所有可能视角"的角度去找匹配。比 surface-based **快**（一般几毫秒到几十毫秒），但要求物体**形状不能变形、不能有大尺度遮挡**。典型场景：识别汽车发动机缸体、机械外壳、SMT 元件。

### 6.2 12 个算子一览

| 算子 | 一句话用途 |
| --- | --- |
| `create_cam_pose_look_at_point` ( : : `CamPosX/Y/Z`, `LookAtX/Y/Z`, `RefPlaneNormal`, `CamRoll` : `CamPose`) | 用"相机站在哪，看向哪，向上的法向 + 绕光轴旋转" 构造一个 `Pose` |
| `create_shape_model_3d` ( : : `ObjectModel3D`, `CamParam`, `RefRotX/Y/Z`, `OrderOfRotation`, `LongMin/Max`, `LatMin/Max`, `CamRollMin/Max`, `DistMin/Max`, `MinContrast`, `GenParam`, `GenParamValue` : `ShapeModel3DID`) | 用 3D CAD + 相机**离线**枚举视角建 3D 形状模型 |
| `find_shape_model_3d` (`Image` : : `ShapeModel3DID`, `MinScore`, `Greediness`, `NumLevels`, `GenParam`, `GenParamValue` : `Pose`, `CovPose`, `Score`) | 在输入**2D 图像**里找 → 输出 6D `Pose` |
| `project_shape_model_3d` ( : `ModelContours` : `ShapeModel3DID`, `CamParam`, `Pose`, `HiddenSurfaceRemoval`, `MinFaceAngle`) | 把 3D 模型用指定 `Pose` + `CamParam` 投影回 2D `ModelContours`，**画到图像上观察** |
| `get_shape_model_3d_contours` ( : `ModelContours` : `ID`, `Level`, `View` : `ViewPose`) | 按指定金字塔层 + 视角取出模型在该视点的 2D 轮廓 |
| `trans_pose_shape_model_3d` ( : : `ID`, `PoseIn`, `Transformation` : `PoseOut`) | 在 3D 形状模型自身坐标系下变换位姿（注意：先调用此再 find_shape_model_3d 才有效） |
| `get_shape_model_3d_params` ( : : `ID`, `GenParam` : `GenParamValue`) | 查模型参数 |
| `read/write/serialize/deserialize` `shape_model_3d` | 持久化（4 件套） |
| `clear_shape_model_3d` | 释放句柄 |

### 6.3 关键签名

```hdevelop
* (1) 构造一个"相机站位 + 朝向 + 翻滚角"的位姿
create_cam_pose_look_at_point(
    0.1, 0.0, 0.5,            * CamPosXYZ
    0.0, 0.0, 0.0,            * LookAtXYZ
    [0,0,1],                  * RefPlaneNormal (地板法向)
    0.0,                      * CamRoll
    CamPose)

* (2) 离线建模型（用 CAD OM3D）
read_object_model_3d('engine_cad.ply', 1, [], [], OM3D_CAD, 1)
create_shape_model_3d(OM3D_CAD, CamParam, \
                      0.0, 0.0, 0.0,             * RefRotX/Y/Z, 固定参考旋转
                      'rodriguez',               * OrderOfRotation
                      -0.5, 0.5,                 * LongitudeMin/Max
                      -0.5, 0.5,                 * LatitudeMin/Max
                      -3.1416, 3.1416,           * CamRollMin/Max（绕光轴转一圈）
                      0.3, 1.0,                  * DistMin/Max 相机距模型 0.3-1.0m
                      10, [], [],                * MinContrast, 无 GenParam
                      ShapeModel3DID)

* (3) 在线找（吃 2D 图 + 相机内参）
find_shape_model_3d(Image, ShapeModel3DID, 0.7, 0.9, 0, [], [], Pose, CovPose, Score)

* (4) 画到图上看
project_shape_model_3d(ModelContours, ShapeModel3DID, CamParam, Pose, 1, 0.5236)
dev_display (ModelContours)
```

### 6.4 `find_shape_model_3d` 关键参数

| 参数 | 范围 | 默认 | 含义 |
| --- | --- | --- | --- |
| `MinScore` | 0..1 | **0.7** | 找匹配的下限分数 |
| `Greediness` | 0..1 | **0.9** | 越大越快，越小越准 |
| `NumLevels` | int, 0=auto | 0 | 金字塔层数 |
| `'min_face_angle'` (GenParam) | 弧度 | 0.52 | 最小面夹角（去重混淆视角） |
| `'pose_ref_*'` (GenParam) | int / float | - | 用 `trans_pose_shape_model_3d` 已变换的参考 Pose 调搜范围 |

## 7. 族 D. Surface-Based（稠密曲面匹配——工业主流）

### 7.1 用途 & 何时选

**最通用**：被找的物体可以用**稠密点云 + 表面法向量**表示；场景也是**稠密 3D 点云**（来自结构光、ToF、双目、Stereo）。本族是工业 3D 视觉的灵魂（消费电子、汽车、机器人）。速度比 Shape-Based 慢，但适应任意姿态、任意形状，**对噪声、大尺度变化、部分遮挡都很鲁棒**。

### 7.2 14 个算子一览

| 算子 | 一句话用途 |
| --- | --- |
| `create_surface_model` ( : : `ObjectModel3D`, `RelSamplingDistance`, `GenParam`, `GenParamValue` : `SurfaceModelID`) | 用一个 3D 物体点云离线建模型 |
| `find_surface_model` ( : : `SurfaceModelID`, `Scene3D`, `RelSamplingDistance`, `KeyPointFraction`, `MinScore`, `ReturnResultHandle`, `GenParam`, `GenParamValue` : `Pose`, `Score`, `SurfaceMatchingResultID`) | 在 3D 场景中找模型（**纯 3D 匹配**，无图） |
| `find_surface_model_image` (`Image` : : `SurfaceModelID`, `Scene3D`, `RelSamplingDistance`, `KeyPointFraction`, `MinScore`, `ReturnResultHandle`, `GenParam`, `GenParamValue` : `Pose`, `Score`, `SurfaceMatchingResultID`) | 在 3D 场景 + 2D 图里同时约束找（**更准**） |
| `refine_surface_model_pose` ( : : `SurfaceModelID`, `Scene3D`, `InitialPose`, `MinScore`, `ReturnResultHandle`, `GenParam`, `GenParamValue` : `Pose`, `Score`, `SurfaceMatchingResultID`) | 给定一个粗 Pose 在原尺度上精修 |
| `refine_surface_model_pose_image` (`Image` : : `SurfaceModelID`, `Scene3D`, `InitialPose`, `MinScore`, `ReturnResultHandle`, `GenParam`, `GenParamValue` : `Pose`, `Score`, `SurfaceMatchingResultID`) | 同上，加原图约束 |
| `get_surface_matching_result` ( : : `Result`, `ResultName`, `ResultIndex` : `ResultValue`) | 取**单个匹配或全部**的指定字段——`'pose'` / `'score'` / `'surface_matching'` / `'sampled_scene'` / `'inlier_indices'` 等 |
| `get_surface_model_param` ( : : `ID`, `GenParam` : `GenParamValue`) | 查模型参数 |
| `set_surface_model_param` ( : : `ID`, `GenParam`, `GenParamValue`) | **运行时改**模型参数（其他族没这能力） |
| `read/write/serialize/deserialize` `surface_model` | 持久化（4 件套） |
| `clear_surface_model` | 释放句柄 |
| `clear_surface_matching_result` | 释放匹配结果 |

> 全章只有 **`set_surface_model_param`** 这一个 set_parameter 算子，因为 Surface-Based 是最灵活/可调的族。

### 7.3 关键 GenParam（按 `find_surface_model` 的三步骤分组）

HALCON 把 `find_surface_model` 的内部实现拆成了**三步**（见官方 `<h3>The Three Steps of the Matching</h3>` 节），对应的 GenParam 也按步骤分类：

#### 第 1 步 — Approximate Matching（粗匹配 / 召回）

| GenParam 名 | 作用 | 类型/默认 |
| --- | --- | --- |
| `'num_matches'` | 返回的最大匹配数 | 1 / 2 / 5 |
| `'max_overlap_dist_rel'` | 多匹配的最小中心间距（**相对物体直径**） | 0.1 / 0.5 / **1.0**（完全不重叠） |
| `'max_overlap_dist_abs'` | 同上，但**绝对距离** | 1 / 2 / 3 |
| `'scene_normal_computation'` | 场景法向计算方式 | `'fast'`（默认）或 `'mls'`（高精度/噪声大数据，推荐 ToF 数据用） |
| `'scene_invert_normals'` | 翻转场景法向 | `'true' / 'false'` |
| `'scene_sample_dist_rel'` | 采样的场景点密度 | 0.05 / 0.1 / 0.25 |

#### 第 2 步 — Intermediate / Scene Sampling（场景下采样）

| GenParam 名 | 作用 | 默认 |
| --- | --- | --- |
| `'num_scene_points'` | 场景采用多少点采样 | 20000 |
| `'model_point_fraction'` | 模型采用多少比例的点 | 0.1~0.5 |

#### 第 3 步 — Refinement（精化）

| GenParam 名 | 作用 | 默认 |
| --- | --- | --- |
| `'pose_ref_num_steps'` | 精修的最大步数 | 30 |
| `'pose_ref_scm_dist_rel'` | 采样点距离容差（相对） | 0.05 |

### 7.4 工作流示例（HDevelop 风格伪代码）

```hdevelop
* ============ 离线建模型期 ============
read_object_model_3d('allen_key.om3', 1, [], [], OM3D_model, 1)

* 关注参数 (GenParam)：
*   'model_invert_normals'     — 模型法向是否要翻转
*   'feat_step_size_rel'       — 描述子步长
*   'feat_angle_resolution'    — 描述子角度分辨率
*   'train_3d_edges'           — 是否训练 3D 边缘（建议 true 提高匹配鲁棒性）
*   'train_self_similar_poses' — 自相似姿态合并
create_surface_model(OM3D_model, 0.03, \
                     'train_3d_edges', 'true', \
                     [], SurfaceModelID)
write_surface_model(SurfaceModelID, 'allen_key.dsf')

* ============ 运行时 ============
read_surface_model('allen_key.dsf', SurfaceModelID)

read_object_model_3d('scene_messy_box.om3', 1, [], [], OM3D_scene, 1)

find_surface_model(SurfaceModelID, OM3D_scene, 0.03, \
                   0.2,           \  * KeyPointFraction (用 20% 关键点)
                   0.7,           \  * MinScore
                   'true',        \  * ReturnResultHandle (要精细结果)
                   ['num_matches', 'max_overlap_dist_rel'], [3, 0.5], \
                   Pose, Score, SurfaceMatchingResultID)

* 取每个匹配的详细
num := |Score|
for i := 0 to num-1 by 1
    get_surface_matching_result(SurfaceMatchingResultID, 'pose', i, Pose_i)
    get_surface_matching_result(SurfaceMatchingResultID, 'sampled_scene', i, SampledScene_i)
endfor
```

### 7.5 `get_surface_matching_result` 的 `ResultName`

| ResultName | 含义 | 类型 |
| --- | --- | --- |
| `'score'` | 每个匹配的分数 | real tuple |
| `'pose'` | 每个匹配的 6D Pose | 7 元 tuple |
| `'sampled_scene'` | 为此匹配采样的场景点云子集 | ObjectModel3D 数组 |
| `'sampled_model'` | 为此匹配采样的模型点子集 | ObjectModel3D 数组 |
| `'inlier_indices'` | 模型 inlier 点的索引 | tuple |
| `'surface_matching'` | 完整原始匹配数据（用于精细可视化） | Dict |
| `'om3d_object_model_3d'` | 匹配的 3D 物体 | ObjectModel3D |

## 8. 四族对比（一表选型）

| 维度 | A. 3D Box | B. Deformable Surface | C. Shape-Based (3D) | D. Surface-Based |
| --- | --- | --- | --- | --- |
| 目标输入 | 1 张 3D 场景 | K 张 3D 样例 + 参考点 | 1 个 3D CAD 模型 + 相机内参 | 1 个 3D 物体点云 |
| 场景输入 | XYZ Mapping | XYZ 点云 | **2D 图像** + 相机内参 | XYZ 点云（或 +2D） |
| 输出 | 可夹持 Pose + 边长 | Pose + 参考点对应 | Pose + Score + CovPose | **Pose + Score + 匹配点云** |
| 抗噪 | 中（靠边缘） | 中（基于统计） | **强**（基于边缘的强特征） | **强**（基于曲面） |
| 抗遮挡 | 弱（面要全） | 中 | 弱 | **强** |
| 抗形变 | ✗ | **✓（核心）** | ✗ | ✗ |
| 速度 | **最快** | 慢（多样本平均） | 快 | 较慢（粗+精） |
| 内存 | 小 | 大（要存训练） | 中（视角 + 金字塔） | 大（点云 + 法向） |
| 工业主流 | 物流抓箱 | 食品/橡胶 | 已知 CAD 元件 | **机器人抓取/3D 检测** |
| `*_param` 套装 | `clear_/_model`, `clear_/_matching_result` | + `add_*` / `refine_*` | + `create_cam_pose_look_at_point` / `project_*` / `trans_*` | **+ `set_surface_model_param`**（运行时改） |

> **选型口诀**：
>
> - **目标纯规则长方体** → **A**
> - **目标会变形** → **B**
> - **目标有 CAD**，且**只要 2D 图就能行** → **C**
> - **其它一切 3D 工作** → **D**
>
> ——本章默认你 80% 时间在 D。

## 10. 10 条误区（业界实测教训）

1. **❌ `find_*` 觉得"pose 算出来就是对的"**
   👉 必须用 `refine_*_pose` 再精修一次。粗阶段匹配分 0.7 上下很正常，精修才上 0.9+。

2. **❌ `ObjectModel3D` 现场采集完直接送进匹配器**
   👉 需要去噪 + 统计离群 + 必要时 `sample_object_model_3d` 下采样。如不处理，时间放大 5 倍、精度崩盘。

3. **❌ `MinScore=0.99` 想"100% 不误检"**
   👉 模型/场景差别大时根本找不到。**生产经验 0.6~0.8 起步**，再视漏检/误检率收紧或放松。

4. **❌ 一份 `CamParam` 用到老**
   👉 `find_shape_model_3d` / `project_shape_model_3d` 对 `CamParam` 极敏感，相机移动或换镜头必重新标定。

5. **❌ 把 `create_shape_model_3d` 当 `create_surface_model` 用**
   👉 Shape-Based 必须有 CAD + 相机内参；要是只给点云没相机内参，必须用 Surface-Based。

6. **❌ `find_surface_model` 一次找完就算完**
   👉 它分 3 步：**approximate → intermediate → refine**。要敢用 GenParam 中的 `pose_ref_*`、`feat_*` 调步骤行为，缺调速度可能慢 10 倍。

7. **❌ `deformable_surface_model` 训练样本 = 1**
   👉 至少 ≥ 10 个形变样本；推荐 30~50。参考点必须每个样本对应标。样本少会"过拟合"。

8. **❌ `SideLen3 = -1` 当万能**
   👉 只看到一面时确实有用，但若深度结构有重叠，`SideLen3` 给个 `(min,max)` 才能避免误匹配。

9. **❌ 忘了 `clear_object_model_3d` / `clear_*_model`**
   👉 `ObjectModel3D` 和 `ShapeModel3DID / SurfaceModelID / DeformableSurfaceModel / ` Result 都是**堆栈式**句柄，**漏 clear = 内存飙升**。特别是放在循环里跑的程序，必加 try / catch + clear。

10. **❌** 觉得这一章算子多就"难"
   👉 关键就 **4 句话**：
    - A. 拿 3D 数据（XYZ Mapping 或 OM3D）
    - B. 用对应 `create_*_model` 把数据变成 model ID
    - C. `find_*_model (ModelID, SceneData, …, → Pose, Score, Result)`
    - D. `get_*_matching_result (Result, 'pose', 0, PoseOut)` 取位姿

   其余算子全是 set\_、clear\_、read/write/serialize/deserialize，都是"配套工具人"。
