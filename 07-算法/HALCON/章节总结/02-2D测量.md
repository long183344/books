# 第 2 章 · 2D Metrology 算子体系总结

> **一句话结论**：这章围绕一个核心抽象 **MetrologyHandle = "一张测量图纸"** 展开——图纸上**装若干个几何对象**（圆/椭圆/线/矩形/通用形状），每个对象自带"测量带子"。`align_*` 移动整张图纸粗定位，`apply_*` 在图像里精找所有对象的实例（可一次找多个），`get_*_result` 取出结果。**对比第 1 章的 MeasureHandle 只是一条扫描带子，本章是把整张产品的"测量方案"打包管理**。
>
> **数据基准**：HALCON 20.11.1.0 ｜ **难度**：进阶 ｜ **前置**：[章节总结 01-1D测量](./../01-1D测量.md)（理解 MeasureHandle 与模糊打分基础）

---

## 0. 速查：第 1 章 vs 第 2 章的根本区别

| | 第 1 章 1D Measuring | 第 2 章 2D Metrology |
| --- | --- | --- |
| **核心句柄** | `MeasureHandle`（一条扫描带子） | `MetrologyHandle`（一整张"测量图纸"） |
| **一次能测几个对象** | 1 个 | 任意多个（圆、线、矩形混装） |
| **对象形状** | 不指定（测量带沿用） | 5 种：圆 / 椭圆 / 线 / 矩形2 / 通用 |
| **粗定位** | 手动 `translate_measure` | `align_metrology_model`（可移动+旋转整体） |
| **精定位** | `measure_*` | `apply_metrology_model`（一次性求所有对象） |
| **多实例** | 需循环 | 原生支持（一次 `apply` 找同类对象的多个实例） |
| **结果** | 边缘点 | 几何参数 (center, radius, phi, …) |
| **何时用** | 少量、灵活的边缘测量 | **一整张产品图多尺寸联合测量**（如 PCB、芯片、齿轮） |

## 1. 为什么需要 2D Metrology？

**真实场景举例**（直接说明什么时候该翻这一章）：

1. **电路板检测**：1 块 PCB 上同时测 30 个焊盘圆 + 12 条走线宽 + 4 个定位孔间距 → 1 个 `MetrologyHandle` 装 46 个对象，一次 `apply` 全测。
2. **芯片引脚**：量 200 个 BGA 球的**位置+直径+圆度** → 对象用 `add_metrology_object_circle_measure`，设 `num_instances=200` 自动找所有球。
3. **汽车齿轮**：每个齿面是直线、齿根是圆弧 → 同一模型里 `add_metrology_object_line_measure` + `add_metrology_object_circle_measure` 混装。
4. **机械零件姿态校正**：工件传送带姿态不固定 → `align_metrology_model` 把整张"图纸"摆正，再 `apply` 测细节。

> 总之：**凡是要"在图里同时测多个特征，且希望它们作为一个整体管理"**——选这一章。

## 2. 全章 30 个算子按职责分 7 大族

| 族 | 个数 | 一句话职责 | 算子 |
| --- | --- | --- | --- |
| **A. 模型生命周期** | 3 | 建 / 删 / 删对象 | `create_metrology_model`, `clear_metrology_model`, `clear_metrology_object` |
| **B. 添加对象** | 5 | 把各种几何形状塞进模型 | `add_metrology_object_circle_measure`, `add_metrology_object_ellipse_measure`, `add_metrology_object_line_measure`, `add_metrology_object_rectangle2_measure`, `add_metrology_object_generic` |

## 4. 逐族详解：每个算子是做什么 / 怎么用 / 用途

### A. 模型生命周期（3 个）

| 算子 | 做什么 | 怎么用 | 典型用途 |
| --- | --- | --- | --- |
| `create_metrology_model` | 创建一个空模型（图纸） | `create_metrology_model(MetrologyHandle)` | **每个测量流程的起点** |
| `clear_metrology_model` | 销毁整个模型 | `clear_metrology_model(MetrologyHandle)` | 测完释放内存，**必调** |
| `clear_metrology_object` | 仅删指定编号的对象 | `clear_metrology_model(MetrologyHandle, Index)` | 调试时删单对象重新加 |

> **重点**：`MetrologyHandle` 是**指针**（int 类型），不绑图像——和 1D 的 `MeasureHandle` 一样可复用。

---

### B. 添加对象（5 个）—— 整章**最常用**

**共同签名骨架**（圆/椭圆/线/矩形都有）：

```
add_metrology_object_<shape>_measure (
    : :  MetrologyHandle,
         <shape 参数>,                ← 各形状不同
         MeasureLength1, MeasureLength2,  ← 测量带子半长
         MeasureSigma,                  ← 高斯平滑 σ
         MeasureThreshold,              ← 灰度阈值
         GenParamName, GenParamValue,   ← 额外参数
         Index                         ← 返回：对象编号 1, 2, 3…
)
```

**MeasureLength1 / Length2 / Sigma / Threshold**：与第 1 章 `gen_measure_rectangle2` 的参数**完全一样**——因为它们底层就是给每个对象装一个扫描带子。

**5 个对象类型的参数差异**：

| 算子 | 几何参数 | 何时用 | 返回 Index 编号 |
| --- | --- | --- | --- |
| `add_metrology_object_circle_measure` | `Row, Column, Radius` | 圆孔、焊盘、BGA 球 | 从 1 自增 |
| `add_metrology_object_ellipse_measure` | `Row, Column, Phi, Radius1, Radius2` | 倾斜视角的圆、椭圆孔 | 同上 |
| `add_metrology_object_line_measure` | `RowBegin, ColumnBegin, RowEnd, ColumnEnd` | 直线边缘、走线宽 | 同上 |
| `add_metrology_object_rectangle2_measure` | `Row, Column, Phi, Length1, Length2` | 矩形框、芯片长宽 | 同上 |
| `add_metrology_object_generic` | `Shape, ShapeParam[]` | **任意 XLD 形状**（不规则轮廓） | 同上 |

**例子**——加 3 个不同形状的对象：

```hdevelop
* 圆 1：焊盘，半径 50，半径允差 ±5
add_metrology_object_circle_measure (ModelHandle, 200, 300, 50, 30, 5, 1, 30, \
                                       [], Index1)

* 圆 2：同一型号多实例（一次 find 50 个相同的焊盘）
add_metrology_object_circle_measure (ModelHandle, 200, 500, 50, 30, 5, 1, 30, \
                                       ['num_instances', 50], Index2)

* 直线：连接两个焊盘的走线
add_metrology_object_line_measure (ModelHandle, 200, 305, 200, 495, 30, 5, 1, 30, \
                                    [], Index3)
```

> **关键 insight**：每个对象都自带**自己的 measure 区域**（在几何形上画一段 MeasureLength1×MeasureLength2 的扫描带）——这就是为什么这章叫 2D Metrology 而 1D 章只叫 1D Measuring。

---

### C. 对齐 + 求解（2 个）—— 整章的**两把刀**

| 算子 | 干什么 | 何时调 | 注意 |
| --- | --- | --- | --- |
| `align_metrology_model` | **整体**平移+旋转整张"图纸" | 上料姿态不固定、传送带定位偏差 | 只动图纸，不动图；多次调=累加 |
| `apply_metrology_model` | 在图像里**实际搜索**每个对象的实例 | 找所有对象位置 | **真正测量"开火"那一下**；必须先 `add_*` 完所有对象 |

**对齐 vs 应用必须分清**：

```
         align_metrology_model                apply_metrology_model
       (粗调"图纸"位置/角度)              (基于 measure 带子做精找)
                 │                                    │
   改 MetrologyHandle 内部状态             改 MetrologyHandle 内部"结果"
   几何中心、角度被覆盖                   每个对象的位置/形状被填
   多次调用会累加偏移                      同一图上只能调一次（除非换图）
```

**`align` 典型用法**：

```hdevelop
* 工件在图像里大致中心为 (640, 480)，角度 3°
align_metrology_model (ModelHandle, 480, 640, rad(3))
```

**`apply` 必用姿势**：

```hdevelop
* 拿到图后
grab_image (Image, AcqHandle)
apply_metrology_model (Image, ModelHandle)  ← 这一行跑了所有测量
```

> ⚠️ **apply 只能对当前图跑一次**；要测多张图就循环 `grab_image + apply` 多次（模型和 measure 都不需要重建）。

---

### D. 取结果（4 个）—— 把"测量图纸"上的成果扒下来

#### D.1 `get_metrology_object_result`：拿数值结果

```
get_metrology_object_result (
    : : MetrologyHandle,
         Index,        ← 对象编号（'all' = 所有）
         Instance,     ← 实例编号（'all' = 所有）
         GenParamName, ← 'result_type' 等
         GenParamValue :  ← 'param', 'position', 'shape', 'score', 'all'
         Parameter
)
```

| GenParamValue | 返回内容 | 用途 |
| --- | --- | --- |
| `'position'` | (Row, Column) 实际位置 | 显示在图上 |
| `'shape'` | 实际几何参数 (Radius, Phi, …) | 判过/不过 |
| `'score'` | 模糊打分 | 滤低分结果 |
| `'edges'` | 找到的边缘点 (Row, Column) | 显示在图上 |
| `'all'` | 把以上 4 类全塞进一个 tuple | 后处理方便 |

**重点**：`Index='all'` 和 `Instance='all'` 是**两个维度的全选**——前者选所有对象，后者选同一对象的所有实例。

#### D.2 `get_metrology_object_result_contour`：拿画好线的轮廓

```hdevelop
get_metrology_object_result_contour (Contour, ModelHandle, 'all', 'all', 1.5)
*                                          ↑         ↑     ↑     ↑     ↑
*                                          输出     模型  对象  实例  Resolution
dev_display (Contour)
```

> 用途：直接叠加在图上看测量结果是否正确，**比 get_result 更快调试**。

#### D.3 `get_metrology_object_num_instances`：该对象在图里被找到了几次

```hdevelop
get_metrology_object_num_instances (ModelHandle, 1, Num)
*                                          ↑     ↑   ↑
*                                          模型 对象 结果
```

> 用途：**多实例场景必备**——BGA 板上有 200 个球，apply 后看每个对象都"被找到了几次"。

#### D.4 `get_metrology_object_model_contour`：取"图纸上的原始轮廓"（apply 之前）

> 对比 D.2：apply **之前**取的是模型本身的形状，apply **之后**取的是拟合实际图的结果轮廓。

### E. 取测量带（1 个）—— 桥接第 1 章

#### `get_metrology_object_measures`

```
get_metrology_object_measures (
    : Contours :     ← 返回 XLD 轮廓（每个 measure 带子一条）
        MetrologyHandle, Index, Transition :  ← 选对象 + 边缘方向
        Row, Column   ← 输出: measure 带子上各采样点 (R, C)
)
```

> **桥接关键**：返回的 `(Row, Column)` 就是**第 1 章 1D Measuring** 章节里 measure 带子的位置！也就是说，你可以：先用 2D metrology 找到位置，**再用第 1 章的 `fuzzy_measure_pairs` 单独再细测一遍**——两种粒度互不冲突。

---

### F. 参数系统（10 个）—— 三层配置

| 层级 | 算子 | 用途 |
| --- | --- | --- |
| **模型级** | `set_metrology_model_image_size` | 声明图尺寸（决定 measure 区域越界判断） |
| | `set_metrology_model_param` / `get_metrology_model_param` | 全局参数（实例数、参考位姿等） |
| **对象级** | `set_metrology_object_param` / `get_metrology_object_param` | 单对象参数（`num_instances`, `measure_transition`, `min_score`…） |
| | `reset_metrology_object_param` | 把对象参数恢复默认 |
| **模糊级** | `set_metrology_object_fuzzy_param` / `get_metrology_object_fuzzy_param` | 给该对象的模糊打分装自定义函数 |
| | `reset_metrology_object_fuzzy_param` | 撤掉自定义模糊函数 |

**常见 GenParam 速查**（`set_metrology_object_param` 用）：

| GenParamName | GenParamValue | 含义 |
| --- | --- | --- |
| `'num_instances'` | int | **同一对象在图里要找几处**（多实例），如 BGA 200 球 |
| `'measure_transition'` | `'uniform'`/`'positive'`/`'negative'`/`'all'` | 边缘过渡方向（与 1D 一致） |
| `'min_score'` | 0~1 | 模糊分低于此被剔除（与 1D `FuzzyThresh` 等价） |
| `'distance_threshold'` | pixels | 同形状多实例间的最小间距，用于分簇 |

> **set/get 一一对应**：get 没改过返回默认值；改完用 reset 可以重置。

---

### G. 持久化 / 复制（5 个）

| 算子 | 用法 | 适用 |
| --- | --- | --- |
| `write_metrology_model` | `write_metrology_model(ModelHandle, 'case.mtr')` | 落盘（.mtr 是 HALCON 私有二进制） |
| `read_metrology_model` | `read_metrology_model('case.mtr', ModelHandle)` | 重新打开 |
| `serialize_metrology_model` | 拿到 `SerializedItemHandle` | 跨进程/HDevEngine |
| `deserialize_metrology_model` | 恢复 `MetrologyHandle` | 同上 |
| `copy_metrology_model` | `copy_metrology_model(ModelHandle, 1, CopiedHandle)` | **只克隆指定编号的对象**到新模型；不是整图复制 |

> ⚠️ `write` 的 `.mtr` 包含**所有对象 + 参数 + 模糊配置**——存一次可以跨图像复用。

## 5. 完整工作流（复制即可用）

```hdevelop
* 1. 准备：读图 + 创模型
read_image (Image, 'pcb.png')
get_image_size (Image, Width, Height)
create_metrology_model (ModelHandle)
set_metrology_model_image_size (ModelHandle, Width, Height)

* 2. 加对象：10 个焊盘圆 + 1 个定位孔（这里用 loop 示范多实例）
for i := 0 to 9 by 1
    add_metrology_object_circle_measure (ModelHandle, 200 + i*50, 100, 30, 20, 5, \
                                          1, 30, [], Index)
    set_metrology_object_param (ModelHandle, Index, 'num_instances', 1)
endfor
add_metrology_object_circle_measure (ModelHandle, 100, 600, 50, 30, 5, 1, 30, [], HoleIdx)

* 3. 可选：粗对齐（如果工件位置不固定）
align_metrology_model (ModelHandle, Height/2, Width/2, 0)

* 4. 求解
apply_metrology_model (Image, ModelHandle)

* 5. 拿结果
* 5a. 拿所有焊盘中心
get_metrology_object_result (ModelHandle, 'all', 'all', 'result_type', 'position', \
                              PositionTuple)
* 5b. 拿所有焊盘半径
get_metrology_object_result (ModelHandle, 'all', 'all', 'result_type', 'shape', \
                              ShapeTuple)
* 5c. 拿所有实例数（诊断有没有漏测）
get_metrology_object_indices (ModelHandle, Indices)
for i := 0 to |Indices|-1 by 1
    get_metrology_object_num_instances (ModelHandle, Indices[i], Num[i])
endfor

* 6. 画到图上看
get_metrology_object_result_contour (Contours, ModelHandle, 'all', 'all', 1.0)
dev_display (Image)
dev_set_color ('green')
dev_display (Contours)

* 7. 存盘 + 清理
write_metrology_model (ModelHandle, 'pcb_layout.mtr')
clear_metrology_model (ModelHandle)
```

## 7. 常见误区

1. ❌ **忘了调 `set_metrology_model_image_size`**。后果：measure 带子被裁切到默认 640×480，大图直接测错。
2. ❌ **`align_metrology_model` 写错参数顺序**。它要的是**整图的偏移 + 旋转**，不是单个对象的位置。
3. ❌ **`apply_metrology_model` 一张图上反复调**。第二次会把第一次结果覆盖——除非换图、或者 `align` 重定位。
4. ❌ **`num_instances` 设太大**。`num_instances=200` 但图里只有 50 个对象，会浪费时间在死搜索上。
5. ❌ **`get_metrology_object_result(..., 'all', 'all', 'result_type', 'shape', ...)` 忘了 `'all'`**。少给一个，得到的 tuple 形状对不上。
6. ❌ **`copy_metrology_model` 以为复制整张模型**。它**只克隆指定编号的对象**。
7. ❌ **`write_metrology_model` 后改名再 `read_measure`** 没问题，但**改文件内容会直接报错**——`.mtr` 是二进制。
8. ❌ **空对象模型就 `apply`**。`apply` 一个没 `add_*` 的模型 = 静默成功但什么都没发生——测前用 `get_metrology_object_indices` 检查。
9. ❌ **改了对象参数忘了 `apply` 重测**。`set_metrology_object_param` 只改配置，**结果缓存不刷新**。
10. ❌ **把模糊参数写到 `set_metrology_object_param` 里**。模糊是**单独的** `set_metrology_object_fuzzy_param`，与普通参数不互通。

## 8. 与第 1 章的衔接

| 想做的事 | 走第 1 章还是第 2 章 |
| --- | --- |
| 量 PCB 上 1 条走线的边缘 | **第 1 章**（`gen_measure_rectangle2` + `measure_pairs`） |
| 量 PCB 上 30 个焊盘 + 12 条线 | **第 2 章**（一次 `apply`） |
| 已有 2D metrology 结果，想**更细**量单条边 | **`get_metrology_object_measures` 拿到位置 → 第 1 章 measure** |
| 工件姿态不固定 + 多个对象 | **第 2 章**（`align` 摆 + `apply` 测） |
| 多实例且形状不规则 | **第 2 章 + `add_metrology_object_generic`** |

## 9. 速查卡（一图理全章）

```
                            MetrologyHandle
                                   │
```
