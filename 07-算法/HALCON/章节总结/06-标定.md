# 第 6 章 · Calibration 算子体系总结

> **章节定位**：把"世界坐标系" → "相机坐标系" → "像素坐标系"这条几何管**焊死**，把每段泄漏都堵上。
> 本章是 HALCON 视觉系统中**前置几何层**——所有 2D 测量（Ch.1/Ch.2）、3D 匹配（Ch.3）、3D 重建（Ch.5）都**必须**先经过本章才能拿到 "相机知道自己在看什么" 的能力。
> 全章共 **64 个算子**，分 **10 个子族**（截图上的目录与 HALCON 20.11.1.0 本地 Operator Reference 完全对齐）。

> ⚠️ **以文档为准的核对结果**：本地文档覆盖 62/64 算子；截图里的 `find_caltab_object`（已被 `find_caltab` 取代，文档未收录）、`get_calib_data_observ_pose` 与 `set_calib_data_observ_pose` 是 HALCON 20.11.1.0 的**当前写法**（无复数 `_poses`），以本地 Operator Reference 为准。

---

## §1 章节价值：从 2D 像素到 3D 物理世界的"通行证"

机器视觉系统拿到一幅 2D 图后，必须知道：

1. **这台相机"看见"的几何是什么**（内参 *相机参数* / 镜头畸变）
2. **这台相机装在哪里，朝向何处**（外参 *相机位姿* / 手眼矩阵）
3. **图像上一个像素对应世界里的哪条射线/哪个平面点**（投影 / 反投影）
4. **不同相机之间的相对位置**（标定多相机 rig）
5. **如果买不起或忘了带标定板**（自标定）

本章 10 个子族恰好覆盖以上 5 大问题，对应下面**一张看板**：

```
┌────────────────────────── 世界 / 物理层 ──────────────────────────┐
│   ③ 投影        ② 拍摄标定板 / 配多相机      ⑤ 自标定（无标定板）│
│   project_3d_point   binocular_calibration     radial_distortion…
│   反投影        →   camera_calibration          radiometric_…      │
│   get_line_of_sight  hand_eye_calibration       stationary_…      │
└────────────────────────────────┬──────────────────────────────────┘
                                 ▼
┌───────────────────── 相机 / 几何层 (CamParam + Pose) ─────────────┐
│ ① 相机参数 Tuple (8 ops)         ② Rectification 去畸变 (9 ops)  │
│    read_cam_par / write_…            gen_image_to_world_plane_map   │
│    serialize_… / deserialize…        image_to_world_plane           │
│ ① CalibData 模型 27 ops           ② hand-eye 多相机管理 4 ops     │
└────────────────────────────────┬──────────────────────────────────┘
                                 ▼
┌────────────────────────── 像素 / 2D 层 ───────────────────────────┐
│      image_points_to_world_plane  image_to_world_plane (鸟瞰)     │
│      送给 Ch.1/2 测量 / Ch.3 匹配 / Ch.5 重建                     │
└────────────────────────────────────────────────────────────────────┘
```

## §2 全章算子速览表（10 子族 · 64 算子）

> 下表按"使用顺序"而非字母序排列，方便选型。

| # | 子族 | 算子数 | 一句话 | 关键算子（英文） |
|---|---|---|---|---|
| A | **Binocular** | 1 | 双目立体标定（基于已提取的标定板像素 + 起始内外参）| `binocular_calibration` |
| B | **Calibration Object** | 8 | 标定板的"造、画、识、提"全周期 | `gen_caltab` / `create_caltab` / `find_caltab` / `find_marks_and_pose` / `caltab_points` / `disp_caltab` / `sim_caltab` / `find_caltab_object`（已弃）|
| C | **Camera Parameters** | 6 | 内参 `CameraParam` Tuple 的 4 种持久化格式（文本 / 二进制 / 矩阵互转）| `read_cam_par` / `write_cam_par` / `serialize_cam_par` / `deserialize_cam_par` / `cam_mat_to_cam_par` / `cam_par_to_cam_mat` |
| D | **Hand-Eye** | 4 | 相机与机器人 base/tool 之间的 6D 刚体变换求解 | `hand_eye_calibration`（老）/ `calibrate_hand_eye`（新，基于 CalibData 模型）/ `get_calib_data_observ_pose` / `set_calib_data_observ_pose` |
| E | **Inverse Projection** | 1 | 单像素 → 通过相机中心的射线两点（3D 重建的起点）| `get_line_of_sight` |
| F | **Monocular** | 1 | 单相机内外参一次性求解（基于多角度标定板图像）| `camera_calibration` |
| G | **Multi-View** | 27 | **本章最重的族**，通用 N-camera × M-calibration-object 的"测量数据 + setup 模型"句柄（含序列化）| `create_calib_data` / `set_calib_data_*` / `get_calib_data` / `calibrate_cameras` / `set_calib_data_observ_points` / `query_calib_data_observ_indices` / 序列化 8 件套 / `set_camera_setup_param` 等 |
| H | **Projection** | 4 | 3D 点 → 像素（反投影的逆运算）| `project_3d_point` / `project_hom_point_hom_mat3d` / `project_point_hom_mat3d` / `cam_par_pose_to_hom_mat3d` |
| I | **Rectification** | 9 | 去除/调整镜头径向畸变，或把图像压到"地面真实坐标"平面（鸟瞰/对位）| `gen_image_to_world_plane_map` + `map_image` / `image_to_world_plane` / `image_points_to_world_plane` / `contour_to_world_plane_xld` / `change_radial_distortion_*` 4 件 / `gen_radial_distortion_map` |
| J | **Self-Calibration** | 3 | "没带标定板"的自救 3 法 | `radial_distortion_self_calibration` / `radiometric_self_calibration` / `stationary_camera_self_calibration` |

合计 = 1+8+6+4+1+1+27+4+9+3 = **64** 算子 ✅（与用户截图、Operator Reference 目录完全对齐）

## §3 三套 API 选型（最重要的认知）

HALCON 同时维护**两套**标定 API，外加**一套**自标定 API，**新手最容易踩的坑**就是把它们混在一起。

### 3.1 路线 A — 老 Flat-Tuple API（fast style）

> 适用：单/双目简单场景、初学演示、几十张图的事后研究。
> 算子：**`camera_calibration`**（F 族）/ **`binocular_calibration`**（A 族）/ **`hand_eye_calibration`**（D 族，老版）

#### 签名（摘自本地 Operator Reference）

```
camera_calibration(
    NX, NY, NZ : control // 标定板标记的 3D 世界坐标 (m)
    NRow, NCol : control // 提取到的像素坐标
    StartCamParam : control     // 内参初值
    NStartPose   : control      // 每张图对应一个外参 Pose 初值
    EstimateParams : control    // 'all' / 'alpha_caltabs' / 'alpha_rel'
    : CameraParam (out)         // 求解后的内参
    : NFinalPose (out)          // 每张图的外参 Pose
    : Errors (out)              // 像素平均重投影误差
);
```

```
binocular_calibration(
    NX, NY, NZ : control
    NRow1, NCol1, NRow2, NCol2 : control   // 双目左右两幅图各自的像素
    StartCamParam1, StartCamParam2 : control
    NStartPose1, NStartPose2     : control
    EstimateParams : control
    : CamParam1, CamParam2 (out) // 两相机的内参
    : NFinalPose1, NFinalPose2 (out)
    : RelPose (out)              // ★ 副产物：相机2 在 相机1 坐标系下的 6D 位姿
    : Errors (out)
);
```

#### EstimateParams 取值（`camera_calibration` / `binocular_calibration`）

| 取值 | 含义 |
|---|---|
| `'all'`（默认）| 同时估计 `kappa, sx, sy, cx, cy, focal` 全部 6 个内参 |
| `'alpha_caltabs'` | 估计 alpha（`S = (1, alpha)` 比例因子）、每张图的位姿；用于**远心相机** |
| `'alpha_rel'` | 同上，但一次性估计所有图的 alpha（全局单一 alpha）|

### 3.2 路线 B — 新 CalibData 模型 API（推荐，多相机/可序列化）

> 适用：3 个及以上相机、机器人手眼、要做"标定→存档→再加载→再优化"。

#### 核心理念：**5 个句柄相互协作**

```
CreateCalibData
       │
       │ (CalibDataID)
       ▼
┌───────────────────────────────────────────────┐
│ set_calib_data_cam_param  ←→  set_camera_setup_param
│ set_calib_data_calib_object
│ set_calib_data_observ_points (+ Pose)
│ set_calib_data_observ_pose    ←（Hand-Eye 用）
└───────────────────────────────────────────────┘
       │
       ▼
   calibrate_cameras (或 calibrate_hand_eye)
       │
       ▼
   get_calib_data / get_camera_setup_param / get_calib_data_observ_*
       │
       ▼
   (序列化 read/write/serialize/deserialize, 或清空 clear_*)
```

#### `create_calib_data` 关键 GenParam

| 参数 | 默认 / 取值 | 说明 |
|---|---|---|
| `CalibSetup` | `'calibration_object'`（默认）| 标定模式：标准 N-camera 看 N-calibobject |
| | `'hand_eye_moving_cam'` | Eye-in-Hand，相机装在机器人末端 |
| | `'hand_eye_stationary_cam'` | Eye-to-Hand，相机固定，机器人带标定板 |

#### `set_calib_data_cam_param` 关键 GenParam

| 参数 | 默认 / 取值 | 说明 |
|---|---|---|
| `CameraIdx` | `0`（首个）| 也可 `'all'`——一次性给所有相机设同一组初值 |
| `CameraType` | `''`（自动）| 取值：`'area_scan_division'` / `'area_scan_polynomial'` / `'area_scan_telecentric_division'` / `'area_scan_tilt'` / `'area_scan_telecentric_polynomial'` 等 |

### 3.3 路线 C — Self-Calibration（无标定板自救）

适用：现场没法摆标定板（如已建成大型 pipeline / 镜头畸变但不想拆下来标）。
见 §11。

### 3.4 三套 API 对比决策表

| 场景 | 选 A 老 Flat-Tuple | 选 B 新 CalibData | 选 C Self-Calib |
|---|---|---|---|
| 单相机 + 1 张标定板图 | ✅ 极简 | 也可以 | ❌ 不需要 |
| 双目立体 + ≥10 张图 | ✅ `binocular_calibration` | ✅ `create_calib_data('calibration_object')` | ❌ |
| **3+ 相机** | ❌ 难写 | ✅ **唯一选** | ❌ |
| 机器人 Eye-in-Hand | ⚠️ `hand_eye_calibration` | ✅ `create_calib_data('hand_eye_moving_cam')` | ❌ |
| 机器人 Eye-to-Hand | ⚠️ `hand_eye_calibration` | ✅ `create_calib_data('hand_eye_stationary_cam')` | ❌ |
| 现场没法摆标定板 | ❌ | ❌ | ✅ 三选一 |
| 标定结果要序列化保存 | ❌（手写文件）| ✅ `write_calib_data` | ❌ |
| 给分布式 5 个相机统一标定 | ❌ | ✅ | ❌ |

**口诀：能上 B 就上 B，只有教学/单双目的小项目才走 A，C 只在没标定板时使用。**

## §4 子族 B · Calibration Object —— 标定板的"造/画/识/提"

> **概念**：`caltab` = **cal**ibration **tab**let = 标定板。
> 本族共 **8 算子**，是其他所有族的前置——没有它，`find_marks_and_pose` 拿不到对照基准。

### 4.1 全族表

| 算子 | 角色 | 关键签名/输入 | 备注 |
|---|---|---|---|
| `gen_caltab` | **生成 .descr 文件** | `(XNum, YNum, MarkDist, DiameterRatio) → CalPlateDescr + CalPlatePSFile` | 离线工具，不进入生产代码 |
| `create_caltab` | **构造指定 finder pattern** 的不规则标定板 | `(NumRows, MarksPerRow, Diameter, FinderRow, FinderColumn, Polarity) → CalPlateDescr + CalPlatePSFile` | 用于特殊场景（机器臂末端抓手识别）|
| `disp_caltab` | 把 .descr 对应的 3D 板画到窗口上，看内嵌位姿 | `(Window, CalPlateDescr, CameraParam, CalPlatePose, ScaleFac)` | 调试/可视 |
| `caltab_points` | 读出 .descr 中每个圆点的世界坐标 | `(CalPlateDescr) → X/Y/Z` | 给后续 `find_marks_and_pose` 提供 3D 标准 |
| `find_caltab` | **（推荐）** 从图中找标定板区域，输出 Region + 中心 6D Pose | `(Image, CalPlateDescr, SizeGauss, MarkThresh, MinDiamMarks) → CalPlate, CalPlatePose` | 比 `find_caltab_object` 新 |
| `find_caltab_object` | ⚠️ **老**：只输出 Region，不估 Pose | `(Image, CalPlateDescr, SizeGauss, MarkThresh, MinDiamMarks) → CalPlate` | 已弃用，下游还得自己估 Pose |
| `find_marks_and_pose` | 从 Region 内**精确提取**所有圆心像素坐标 + 估出 Pose | `(Image, CalPlate, CalPlateDescr, StartCamParam, StartThresh, …) → RCoord, CCoord, StartPose` | `camera_calibration` 的标准喂入 |
| `sim_caltab` | 仿真生成一张标定板灰度图（用于测试 pipeline）| `(CalPlateDescr, CameraParam, CalPlatePose, Gray*) → SimImage` | 离线 |

### 4.2 典型标定流程（**算子用法串联**）

```
                  离线                  ↓                      现场
       gen_caltab / create_caltab     生成 .descr + .ps        把 .ps 打印
                                          ↓
                                    标定板实物
                                          ↓
        每个位姿 1 张图:                    find_caltab        把标定板区域框出来
                                          find_marks_and_pose  提取所有圆心像素
                                            ↓
                                  累积 NX,NY,NZ,NRow,NCol,NStartPose
                                            ↓
                              camera_calibration / binocular_calibration
```

### 4.3 关键 GenParam（`find_caltab` / `find_marks_and_pose`）

| 算子 | 参数 | 默认 | 备注 |
|---|---|---|---|
| `find_caltab` | `SizeGauss` | `3` | 平滑σ；图像噪声大时加大 |
| | `MarkThresh` | `128` | 圆点对比度阈值 |
| | `MinDiamMarks` | `5` | 圆点最小直径，防漏检极小目标 |
| `find_marks_and_pose` | `StartThresh` | `128` | 边缘检测初始阈值 |
| | `DeltaThresh` | `10` | 循环步长：每次递减直到找到 |
| | `MinThresh` | `20` | 兜底最低阈值 |
| | `Alpha` | `0.7` | 边缘滤波参数 |
| | `MinContLength` | `10` | 圆周最小长度 |
| | `MaxDiamMarks` | `100` | 圆点最大直径 |

## §5 子族 C · Camera Parameters —— 内参 Tuple 的"4 种存取"

> **`CameraParam` 是个变长 Tuple**：含义随 `CamType`（参见 §3.2）变化，如 `'area_scan_division'` 时是 8 元素 `(Focus, Kappa, Sx, Sy, Cx, Cy, ImageWidth, ImageHeight)`。

| 算子 | 用途 | 一句话说明 |
|---|---|---|
| `read_cam_par` | `.dat` 文本文件 → CameraParam | **生产部署默认格式**——XML 之外的低成本方案 |
| `write_cam_par` | CameraParam → `.dat` 文本文件 | 同上，反向 |
| `serialize_cam_par` | CameraParam → `SerializedItemHandle`（HALCON 二进制）| 适合内存传递、嵌入到 `tuple_concat`、用 `serialize_cam_par + fwrite_raw` 写自定义二进制 |
| `deserialize_cam_par` | `SerializedItemHandle` → CameraParam | 反向 |
| `cam_mat_to_cam_par` | 3x3 `CameraMatrix` + κ, W, H → CameraParam | 从 OpenCV/Pose-from-Essential 拿到的 3x3 内参矩阵喂给 HALCON 的桥梁 |
| `cam_par_to_cam_mat` | CameraParam → 3x3 `CameraMatrix` + W, H | 反向，常用于把 HALCON 内参送出去给 OpenCV / MATLAB |

### 5.1 与 §3.2 `set_calib_data_cam_param` 的区别

- 本族 `read_cam_par` 等针对**单个 CameraParam** 的持久化；
- `set_calib_data_cam_param` 是把 CameraParam **注入到 CalibData 模型**——不同的概念层。

## §6 子族 F·A · 一击即中标定（Monocular / Binocular / Hand-Eye 老 API）

虽然推荐用 B 路线，但**一相机一板**的最简场景或**教学**，这三算子最快上手。

### 6.1 `camera_calibration`（Monocular 族，1 算子）

**输入**：
- `NX, NY, NZ`：标定板圆点的世界坐标元组（米），来自 `caltab_points`
- `NRow, NCol`：提取到的像素坐标元组，来自 `find_marks_and_pose`
- `StartCamParam`：内参初值（焦距/像元/Kappa 的粗估）
- `NStartPose`：每张图对应的位姿初值（来自 `find_marks_and_pose` 输出）
- `EstimateParams`：`'all'` / `'alpha_caltabs'` / `'alpha_rel'`

**输出**：
- `CameraParam`：求解后的内参（元组）
- `NFinalPose`：每张图对应的位姿（元组）
- `Errors`：平均重投影误差（**生产线上 < 0.3 像素为优**）

### 6.2 `binocular_calibration`（Binocular 族，1 算子）

跟 `camera_calibration` 类似，但**输入参数全部 × 2**（`1` 后缀表示相机 1，`2` 后缀表示相机 2）。多了一个 `RelPose` 输出 = 相机 2 在相机 1 坐标系下的 6D 位姿，**这是 Ch.5 双目立体视差 → 3D 的关键输入**。

### 6.3 `hand_eye_calibration`（Hand-Eye 老 API，D 族 4 算子之 1）

**输入**：
- `X, Y, Z, Row, Col, NumPoints`：标定板 3D + 像素坐标元组
- `RobotPoses`：每张图对应的机器人 base→tool 位姿
- `CameraParam`：已标定的内参
- `Method`：`'linear'` / `'nonlinear'`（默认） / `'scara_linear'` / …

**输出**：
- `CameraPose`：**手眼矩阵**（关键产物！相机在 tool/base 下的 6D 位姿）
- `CalibrationPose`：标定板在 robot base 下的位姿
- `Quality`：质量评估值

> ⚠️ 这是**老**版本。新版本请用 §7 的 `calibrate_hand_eye`。

## §7 子族 G · Multi-View —— 本章**最重**的族，27 算子

> 这一族是 HALCON 标定 API 的"现代心脏"，可以**统一处理 1~N 个相机 × 1~M 个标定对象**，并把所有观察、结果、配置都装进 `CalibDataID` 句柄，支持文件/二进制序列化。

### 7.1 全族按职责分为 6 小簇

| 簇 | 算子 | 角色 |
|---|---|---|
| **生命周期 (4)** | `create_calib_data`, `clear_calib_data`, `clear_camera_setup_model`, `create_camera_setup_model` | 创建/销毁 CalibData 模型、CameraSetup 模型 |
| **配置注入 (5)** | `set_calib_data_calib_object`, `set_calib_data_cam_param`, `set_calib_data_observ_points`, `set_calib_data_observ_pose`, `set_camera_setup_cam_param` | 装配 |
| **查询/取值 (4)** | `get_calib_data`, `get_calib_data_observ_contours`, `get_calib_data_observ_points`, `get_calib_data_observ_poses` | 提取 |
| **求解 (1)** | `calibrate_cameras` | **"启动求解器"** —— 关键算子 |
| **辅助/索引 (2)** | `query_calib_data_observ_indices`, `remove_calib_data`, `remove_calib_data_observ` | 多相机/多板场景下索引观测数据 |
| **Setup 参数 + 序列化 (10)** | `get_camera_setup_param`, `set_camera_setup_param`, `set_camera_setup_cam_param`, `read_calib_data`, `read_camera_setup_model`, `write_calib_data`, `write_camera_setup_model`, `serialize_calib_data`, `deserialize_calib_data`, `serialize_camera_setup_model`, `deserialize_camera_setup_model` | **保存**所有计算结果 |

### 7.2 `create_calib_data` 三种 `CalibSetup` 模式对比

| `CalibSetup` | 含义 | 适用 | 求解器 |
|---|---|---|---|
| `'calibration_object'` | 标准 N-camera 看同一标定板 | 双目 / 多目 rig | `calibrate_cameras` |
| `'hand_eye_moving_cam'` | Eye-in-Hand：相机装在机器人末端 | 手眼标定（动态相机）| `calibrate_hand_eye` |
| `'hand_eye_stationary_cam'` | Eye-to-Hand：相机固定，机器人带板子 | 手眼标定（静态相机）| `calibrate_hand_eye` |

### 7.3 完整 HDevelop 工作流（最常见：3 相机 + 1 标定板）

```hdevelop
* 1) 创建模型
create_calib_data ('calibration_object', 0, 3, CalibDataID)  // 0 板（后设）, 3 相机

* 2) 装配：相机/标定板描述
for CamIdx := 0 to 2 by 1
    set_calib_data_cam_param (CalibDataID, ['all'], 'area_scan_division',
                              [0.016, 0, 8.5e-6, 8.5e-6, 640, 480, 1280, 960])
endfor
set_calib_data_calib_object (CalibDataID, 0, 'my_caltab.descr')

* 3) 注入每个观察（每张图像）
NumImages := 15
for Img := 1 to NumImages by 1
    read_image (Image, 'calib/cam_' + CamIdx + '/' + Img$'.02d')
    find_caltab (Image, CalPlate, 'my_caltab.descr', 3, 112, 5)
    find_marks_and_pose (Image, CalPlate, 'my_caltab.descr', StartCamParam,
                         128, 10, 20, 0.7, 12, 100, \
                         RCoord, CCoord, StartPose)
    set_calib_data_observ_points (CalibDataID, CamIdx, 0, Img-1, RCoord, CCoord,
                                  'all', StartPose)
endfor

* 4) 求解
calibrate_cameras (CalibDataID, Error)  // Error = RMSE in pixels

* 5) 提取结果
get_camera_setup_param (CameraSetupModelID, [], 'params', SetupParams)
get_calib_data (CalibDataID, 'camera', 0, 'params', CamParam0)

* 6) 落盘
write_calib_data (CalibDataID, 'multicam_calib.dat')
```

### 7.4 `calibrate_cameras` 是什么？

```
calibrate_cameras(CalibDataID : Error)
```

唯一输入是 `CalibDataID`（必须已经 fill 了所有 set_*），输出 `Error` = **反投影 RMSE（像素单位）**。看 `Error` 是否在容忍范围内（产线 < 0.3，建议 < 0.1）决定是否重拍。

### 7.5 重要约束（来自本地 Operator Reference）

| 参数 | 必须满足 |
|---|---|
| `NumCameras` | >= 0（0 表示运行时再 add） |
| `NumCalibObjects` | >= 0 |
| `CalibSetup` | 必须三选一：`'calibration_object'` / `'hand_eye_moving_cam'` / `'hand_eye_stationary_cam'` |

## §9 子族 E·H · Inverse Projection & Projection —— 3D ↔ 像素互转（5 算子）

> 这 5 个算子是**Ch.5 3D 重建**的入口出口：把从立体视觉算出来的 3D 点变成像素，或反向求射线。

### 9.1 Inverse Projection（1 算子）

```
get_line_of_sight(Row, Col, CameraParam : PX, PY, PZ, QX, QY, QZ)
```

- 输入：单个像素 (Row, Col) + 内参
- 输出：射线上两点 `(P, Q)` 在**相机坐标系**下（默认 P = 相机中心，Q = 通过相机的归一化平面）

### 9.2 Projection（4 算子）

| 算子 | 入参类型 | 出参类型 | 用于 |
|---|---|---|---|
| `project_3d_point` | 3D 点元组 + CameraParam | 像素 (Row, Col) | **最常用**：验 Ch.3 6D Pose 是否正确 |
| `project_point_hom_mat3d` | 单 3D 点 + 3×4 HomMat3D | 2D 像素齐次 (Qx, Qy) | 给定任意投影矩阵（非内参）投影 |
| `project_hom_point_hom_mat3d` | 单齐次点 + HomMat3D | 单齐次像素 | 通用齐次 |
| `cam_par_pose_to_hom_mat3d` | CameraParam + Pose | 3×4 HomMat3D | **重要桥梁**：把内参 + 外参拼成一个可复用的"投影矩阵"，再喂给上面两算子 |

## §10 子族 I · Rectification —— 去畸变 + 鸟瞰（9 算子）

> **两大用途**：
> 1. **去径向畸变**（`change_radial_distortion_*` + `gen_radial_distortion_map`）：把鱼眼/广角图变标准
> 2. **到世界平面鸟瞰图**（`gen_image_to_world_plane_map` + `image_to_world_plane`）：经典 "鸟瞰测量"pipeline，量出地面真实长度

### 10.1 Rectification 全族表

| 算子 | 输入 | 输出 | 关键 GenParam |
|---|---|---|---|
| `gen_radial_distortion_map` | `CamParamIn` + `CamParamOut` + `MapType` | `Map` (= 重映射表) | `MapType`: `'nearest_neighbor'`, `'bilinear'`, `'coord_map_sub_pix'` |
| `change_radial_distortion_cam_par` | `Mode` + `CamParamIn` + `DistortionCoeffs` | `CamParamOut` | `Mode`: `'fullsize'` (保持图大小) / `'adaptive'` (默认) / `'fixed'` (保留 corner) |
| `change_radial_distortion_image` | `Image` + `Region` + `CamParamIn` + `CamParamOut` | `ImageRectified` | 配合 `change_radial_distortion_cam_par` |
| `change_radial_distortion_points` | `(Row, Col)` | `(RowChanged, ColChanged)` | 给点云用的版本 |
| `change_radial_distortion_contours_xld` | `Contours` | `ContoursRectified` | 给 XLD 边缘用的版本 |
| `gen_image_to_world_plane_map` | `CameraParam` + `WorldPose` + W_in + H_in + W_mapped + H_mapped + `Scale` + `MapType` | `Map` | `Scale` 默认 `'m'`，可选 `'cm','mm','microns','um'`；**这是鸟瞰 pipeline 的关键算子，配合 `map_image`** |
| `image_to_world_plane` | `Image` + `CameraParam` + `WorldPose` + W + H + `Scale` + `Interpolation` | `ImageWorld` | 一次性鸟瞰（不预计算 Map） |
| `image_points_to_world_plane` | `(Rows, Cols)` + `CameraParam` + `WorldPose` + `Scale` | `(X, Y)` | 像素→世界平面坐标点 |
| `contour_to_world_plane_xld` | `Contours` + `CameraParam` + `WorldPose` + `Scale` | `ContoursTrans` | XLD→世界坐标 |

### 10.2 关键分工对比

- **`gen_*_map` + `map_image`** = "**预计算映射表**，之后 N 张图共享"——**最省时**的批量方案
- **`image_to_world_plane`** = "一次性把单张图像转换"——单张调试时用
- **`image_points_to_world_plane`** = "像素坐标→世界平面坐标"——**测距**时用（只算几个点）

### 10.3 经典鸟瞰 pipeline（HDevelop）

```hdevelop
* 假设：相机俯视地面，地面 z=0
PoseGround := [0.0, 0.0, 1.5, 0, 0, -0.5, 0]   * 高度1.5m，绕X轴转-0.5rad
Scale := 'mm'
W := 1280
H := 1024

* 方案 1：一次性鸟瞰
image_to_world_plane (Image, ImageWorld, CameraParam, PoseGround, W, H, Scale, 'bilinear')
* → ImageWorld 每个像素代表 1mm 实际距离

* 方案 2：批量场景，预计算 Map
gen_image_to_world_plane_map (Map, CameraParam, PoseGround, W_in, H_in, W, H, Scale, 'bilinear')
for I := 1 to 100 by 1
    read_image (Image, 'frame_' + I$'.03d')
    map_image (Image, Map, ImageWorld)   * 一行重映射
endfor

* 方案 3：算几个测量点
image_points_to_world_plane (CameraParam, PoseGround, [200,400,600], [300,500,700], Scale,
                             X, Y)
* → X/Y 是这 3 个像素对应的真实地面 (mm) 坐标
```

### 10.4 关键 GenParam（`gen_image_to_world_plane_map`）

| 参数 | 默认 | 取值范围 |
|---|---|---|
| `Scale` | `'m'` | `'m'` / `'cm'` / `'mm'` / `'microns'` / `'um'` + 任意数值 |
| `MapType` (在 `map_image` 里) | `'bilinear'` | `'nearest_neighbor'` / `'bilinear'` / `'coord_map_sub_pix'` 等 |

> ⚠️ **坑**：`Scale` 决定输出图的 1 像素 = 多少米。例如 Scale=`'mm'` + Width=1024 ⇒ 视野宽 1.024m。

## §11 子族 J · Self-Calibration —— 无标定板的"3 种自救"（3 算子）

> 没带标定板（或者标定板已不在车间），用下面 3 种方法。

### 11.1 三种自标定对比表

| 算子 | 解出 | 输入要求 | 关键 GenParam |
|---|---|---|---|
| `radial_distortion_self_calibration` | **仅径向畸变系数 κ + 焦距**（+ 可选 principal point）| 多张图的"曲边轮廓"（直线段没有，共线物体建筑边缘）| `DistortionModel`: `'division'` / `'polynomial'` ; `DistortionCenter`: `'adaptive'` / `'fixed'` / `'variable'` ; `PrincipalPointVar`（0=光心在像面中心）|
| `radiometric_self_calibration` | **相机的灰度响应曲线**（非均匀曝光/伽马矫正）| 多张不同曝光比的图 | `FunctionType`: `'discrete'` / `'discrete_real'` / `'polynomial'` ; `Smoothness` (默认 1.0, 0.3-3.0) |
| `stationary_camera_self_calibration` | **完整内参**（focus + principal point + kappa），无标定板 | ≥2 张固定相机的图像 + 它们之间的单应变换矩阵 | `EstimationMethod`: `'gold_standard'` / `'linear'` / `'nonlinear'` ; `CameraModel`: `['focus','principal_point']` 等 |

### 11.2 何时用哪一种

```
Question 1: 我能不能拍到 2 张以上不同视角？
    ├─ 否  → 不适合自标定，先上 Ch.6 标准 API
    └─ 是
        │
        ▼
Question 2: 主要问题是镜头畸变（直线变弯）？
    ├─ 是 → radial_distortion_self_calibration
    └─ 否
        │
        ▼
Question 3: 主要问题是曝光不均（同物不同灰）？
    ├─ 是 → radiometric_self_calibration
    └─ 否
        │
        ▼
Question 4: 已知 2 张图之间的单应变换矩阵 H？
    └─ 是 → stationary_camera_self_calibration (求出 focus + 主点 + κ)
```

## §13 12 条实战误区（按危险程度排序）

| # | 误区 | 后果 | 正确做法 |
|---|---|---|---|
| 1 | **混用 A/B API** | 数据格式不互认 | 同一次标定只用一条线，A 用于教学，B 用于生产 |
| 2 | `StartCamParam` 给 0 | `camera_calibration` 不收敛 | 用相机 Datasheet 的 `Focus` 和 `Sx,Sy` 估算初值 |
| 3 | `find_marks_and_pose` 的 `DeltaThresh` 设过大 | 圆点漏检 → 标定失败 | `StartThresh=128, DeltaThresh=10, MinThresh=20` |
| 4 | 手眼只动 5 个位姿 | `Errors > 10mm` | 至少 10 个，覆盖足够多方位 |
| 5 | 鸟瞰 `Scale='m'` 但 Width 设计成 1024 | 显示范围 1024m，零件小到看不见 | 按目标视野反推：`Width = 视野m * 1000` |
| 6 | `change_radial_distortion_image` 忘传 `CamParamIn == CamParamOut` | 静默无变化 | 必须 2 个内参**必须不同**才有意义 |
| 7 | 直方图式自标定 (`radiometric_*`) 当成镜头标定 | 灰度矫正 ≠ 几何标定 | 它解的是 response function，不是几何 |
| 8 | `Number of different images < 2` 触发 `stationary_camera_self_calibration` | 报错 | 至少 2 张 |
| 9 | `binocular_calibration` 输入 `EstimateParams='all'` 但 Kappa 太大 | Kappa > 1 物理上不可能 | 先 `'alpha_rel'` 估全局 alpha，再 `'all'` |
| 10 | `calibrate_cameras` 返回 `Error > 0.5` 像素直接上线 | 现场精度堪忧 | 重拍+检查标定板是不是高反光/模糊 |
| 11 | **不存 CameraParam** | 每次启动重拍标定板 | 标完立刻 `write_cam_par` 留底 |
| 12 | `image_to_world_plane` 内参 + 位姿单位混 | 视野漂移 | CameraParam 是 mm、WorldPose 也是 mm/deg |

| 与本章配合的章节 | 用什么结果 | 怎么传 |
|---|---|---|
| **Ch.1 1D Measuring** | 用 `image_to_world_plane` 把原始图**先变成世界平面图**，再用 1D measure 量像素差 | Ch.6 是前置 |
| **Ch.2 2D Metrology** | `CameraParam` + `WorldPose` 也用于 metrology | Ch.6 给 Pose |
| **Ch.3 3D Matching (Surface-Based)** | `SurfaceModel` 的**位姿**以"相对相机坐标"为单位，**相机的世界位姿**由 Ch.6 决定 | Ch.3 find_surface_model 的 Pose 输出 + Ch.6 的相机外参 = 物体世界位姿 |
| **Ch.5 3D Reconstruction** | `binocular_calibration.RelPose` 是 `disparity_to_distance` 必须输入 | Ch.6 → 给 Ch.5 → 给 Ch.3 匹配 |
| **Ch.7 OCR / Barcode** | 经常配合 `image_to_world_plane` 做文档扫描（去透视）| 在文档扫描项目里直接串联 |
| **Ch.9 3D Visualization** | 用 `gen_image_to_world_plane_map` 预处理 + `disparity_image_to_xyz` 后 3D 显 | 流水线 |

## §16 总结口诀

> **"焊好三段管，6D 随便玩"**

- 三段管：**世界坐标** → **相机坐标** → **像素坐标**
- 本章十族 = 三个工具箱：
  - **B/G** = "怎么造扳手（标定板 + 模型）"
  - **C/H/I** = "怎么测电表（存储/投影/鸟瞰）"
  - **D/J** = "怎么调表（手眼/自标定）"
- 没有本章的标定结果，**Ch.1/2/3/5/7 都不能告诉用户真实世界尺寸**。
