# 第 1 章 · 1D Measuring 算子体系总结

> **一句话结论**：这一章所有算子都在围绕 **一个把手 (MeasureHandle)** 转——`gen_*` 制造它、`measure_*` / `fuzzy_measure_*` 消费它、`set_*` 调节它、`translate_*` 搬动它、`serialize_*/read/write_measure` 持久化它、`close_*` 释放它。**理解了这个句柄模型，整章 18 个算子就只剩"该用哪个 measure_*" 这一件事。**
>
> **数据基准**：HALCON 20.11.1.0 ｜ **难度**：进阶 ｜ **前置**：[01-圆形椭圆与圆弧算子解析](./../01-圆形椭圆与圆弧算子解析.md) §4（了解 1D 测量的基本概念）、[02-窗口显示与绘图显示算子解析](./../02-窗口显示与绘图显示算子解析.md)

## 1. 这一章解决什么问题

场景：**图像里有近似直的边缘**——芯片引脚、印刷电路、瓶口、齿轮齿面、装配缝隙——你想**亚像素级**提取出边缘的精确位置、宽度、或边缘对的间距。

| 你要做的 | 该看哪一节 |
| --- | --- |
| 创建这个测量用的"扫描带" | §4.1 生成算子 |
| 在图像里提取边缘 | §4.2 提取算子 |
| 用模糊逻辑打分挑边缘 | §4.3 + §4.4 模糊族 |
| 把扫面带平移到下一处（不重建） | §4.5 变换算子 |
| 存盘 / 跨进程复用 | §4.6 持久化 |
| 流程闭环 | §5 完整工作流 |
| 选哪个 `measure_*` 不踩坑 | §6 + §7 对比 |
| 仿真实战 | §8 |

## 2. 一个贯穿全章的核心抽象：MeasureHandle

理解这一章的关键不在算子多，而在**句柄模型**：

```
                       MeasureHandle
                            │
        ┌───────────────────┼───────────────────┐
   生成 │                调节               使用 │
        │                   │                   │
gen_measure_arc       set_fuzzy_measure      measure_pos
gen_measure_rectangle2  set_fuzzy_measure_norm_pair  measure_pairs
                       reset_fuzzy_measure  measure_thresh
                                            measure_projection
                                            fuzzy_measure_pos
                                            fuzzy_measure_pairs
                                            fuzzy_measure_pairing
        │                   │                   │
   几何                    模糊配置          提取结果
        └──── 搬动 → translate_measure ←───────┘
                            │
                  持久化 ┌──┴──┐ 释放
                read_measure  write_measure
            serialize_measure  deserialize_measure
                            close_measure
```

**MeasureHandle 是个什么？**

- 由 `gen_measure_rectangle2` / `gen_measure_arc` 创建，**几何信息 + 插值方式都被封进句柄**（即"矩形/圆弧扫描带 + 双线性插值"打成一捆）。
- 后续 `measure_*` / `fuzzy_measure_*` 只接受句柄 + 图像，**不需要再传坐标**——这意味着你可以做两件事：
  1. **同一带子在多张图上复用**（如批量产品图）。
  2. **带子位置不重建**：用 `translate_measure` 平移而**不丢失模糊配置**。

⚠️ 一句话对比：算子参数多看着吓人，但 **多数参数 (Sigma, Threshold, Transition, …) 是 image-wide 的，重复传给每个 `measure_*` 调用，不是绑在句柄上**；只有模糊配置（`set_fuzzy_measure*`）是绑在句柄上的。

## 3. 全章 18 个算子按职责拆成 6 大族

| 族 | 算子数 | 算子 | 职责一句话 |
| --- | --- | --- | --- |
| **① 生成 (gen_)** | 2 | `gen_measure_rectangle2` / `gen_measure_arc` | 由几何 + 插值方法造出 MeasureHandle |
| **② 核心提取 (measure_)** | 4 | `measure_pos` / `measure_pairs` / `measure_thresh` / `measure_projection` | 在带子上跑提取（硬阈值） |
| **③ 模糊提取 (fuzzy_measure_)** | 3 | `fuzzy_measure_pos` / `fuzzy_measure_pairs` / `fuzzy_measure_pairing` | 同上但用模糊打分替代硬阈值 |
| **④ 模糊配置 (set/reset_fuzzy)** | 3 | `set_fuzzy_measure` / `set_fuzzy_measure_norm_pair` / `reset_fuzzy_measure` | 给句柄装 / 卸模糊函数 |
| **⑤ 几何搬动 (translate)** | 1 | `translate_measure` | 平移参考点而不重建句柄 |
| **⑥ 持久化 + 释放** | 5 | `read_measure` / `write_measure` / `serialize_measure` / `deserialize_measure` / `close_measure` | 存盘 / 跨进程 / 释放 |

> 全章总算子数 = 2+4+3+3+1+5 = **18** ✅，与你截图的目录完全对应。

## 4. 6 大族逐族详解

每族给出**职责、函数签名（实参顺序）、关键参数取舍**。

### 4.1 生成族：`gen_measure_*`

**干什么**：把"在图像哪个位置、按什么方向、用多宽的带子"封装成一个句柄。

**两个算子**

| 算子 | 几何形状 | 何时用 |
| --- | --- | --- |
| `gen_measure_rectangle2(Image, Row, Column, Phi, Length1, Length2, Width, Height, Interpolation : MeasureHandle)` | 矩形带子，长轴沿 Phi，宽 = 2·Length2 | **90% 场景**：直边、孔位、间隙 |
| `gen_measure_arc(Image, CenterRow, CenterCol, Radius, AngleStart, AngleExtent, AnnulusRadius, Width, Height, Interpolation : MeasureHandle)` | 圆弧带子，圆心+起角+角度范围，宽度 AnnulusRadius | 圆弧边缘、弧形槽宽 |

> `Image` 这里只用于**取尺寸**，句柄本身不绑图——这是后续能跨图复用的基础。

**插值参数 Interpolation**

- `'nearest_neighbor'`：最快、最糊
- `'bilinear'`（默认）：亚像素边缘常用
- `'bicubic'` / `'bicubic_clipped'`/`'bicubic_2'`：更平滑，但慢

**实战**：缺边→选 `bicubic`；批量高速→选 `nearest_neighbor` 或 `bilinear`。

### 4.2 核心提取族：`measure_pos` / `measure_pairs` / `measure_thresh` / `measure_projection`

**签名共性**（输入侧）：`Image : : MeasureHandle, Sigma, Threshold[/AmpThresh], Transition[, Select] : ...OutputEdges`

| 算子 | 返回 | 何时用 |
| --- | --- | --- |
| `measure_pos` | 每个边缘的 (Row, Column, Amplitude, InterDistance) | 数单边 |
| `measure_pairs` | 边缘**对**(首边+次边)，含 IntraDistance (对内距) 和 InterDistance (对间距) | 量两条边的宽度/槽宽 |
| `measure_thresh` | 直接返回穿过阈值的"过门点"坐标 (RowThresh, ColumnThresh) | 类似 threshold_subpixel 但限定在带子上 |
| `measure_projection` | 返回整条带子的灰度剖面 (GrayValues) | 想自己决定怎么找边缘 (自定义亚像素算子、找峰值等) |

**关键参数**

- **Sigma**：高斯平滑 σ。**越大越抗噪，但越糊边缘**。经验值：
  - 边缘梯度尖锐：0.6 ~ 1.0
  - 有噪声：1.5 ~ 3.0
  - 边缘附近有纹理：3.0 ~ 5.0
- **Threshold / AmpThresh**：`measure_*` 用 **绝对灰度阈值**；`fuzzy_measure_*` 用 **最小振幅**（边缘响应强度的下限）。
- **Transition**：
  - `'all'`：所有边缘
  - `'positive'` / `'negative'`：只取亮到暗或暗到亮的过渡
  - `'uniform'`：要求带子上**所有边缘过渡方向一致**
- **Select**：`'all'` / `'first'` / `'last'`，限制返回数量。

### 4.3 模糊提取族：`fuzzy_measure_pos` / `fuzzy_measure_pairs` / `fuzzy_measure_pairing`

**和 §4.2 的本质差别**：用**模糊函数打分**判定边缘是否合格，而不是单一阈值。

**三者区别**

| 算子 | 返回 | 关键差异 |
| --- | --- | --- |
| `fuzzy_measure_pos` | 边缘 + FuzzyScore + Distance | 返回"被模糊判定为合格的"单边 |
| `fuzzy_measure_pairs` | 边缘对 + FuzzyScore + IntraDistance + InterDistance | 同上但限定为边缘对 |
| `fuzzy_measure_pairing` | 同上，但额外参数 **Pairing**（"left_first"/"right_first"/"all"/"none"）和 **NumPairs**（要几对） | 控制对的方向与数量 |

**多出的 FuzzyThresh 参数**：打分低于它就被剔除。建议 0.5 ~ 0.9，越接近 1 越严。

### 4.4 模糊配置族：`set_fuzzy_measure` / `set_fuzzy_measure_norm_pair` / `reset_fuzzy_measure`

**干什么**：给句柄装**自定义模糊函数**（如果 §4.3 的内置打分不够用）。

| 算子 | 何时用 |
| --- | --- |
| `set_fuzzy_measure(MeasureHandle, SetType, Function)` | 单点打分函数。SetType 选 `'contrast'/'position'/'size'` |
| `set_fuzzy_measure_norm_pair(MeasureHandle, PairSize, SetType, Function)` | 边缘对打分函数；PairSize 是期望的对内距 |
| `reset_fuzzy_measure(MeasureHandle, SetType)` | 撤销刚才的 set，恢复默认 |

> 推荐：先用 §4.3 的内置版本（开箱即用），确认场景需要再上 §4.4 自定义。

### 4.5 几何搬动：`translate_measure`

`translate_measure(MeasureHandle, Row, Column)`：**平移句柄的参考点**。

- **关键好处**：不用重新 `gen_*`——所以**模糊函数、Smoothness 等配置都还在**，只是原点挪到下一处。
- 典型场景：批量产品图上扫一行孔，每孔平移到下一处（`for i := 0 to N-1 by 1 ; translate_measure(...,-dx*i,0) ; measure_pairs(...); endfor`）。

### 4.6 持久化 + 释放：`read/write/serialize/close_measure`

| 算子 | 文件格式 | 用途 |
| --- | --- | --- |
| `write_measure(MeasureHandle, FileName)` | HALCON 二进制 (`.msr`) | 落盘，几何+配置一起存 |
| `read_measure(FileName)` | 同上 | 重新打开 |
| `serialize_measure(MeasureHandle)` → `deserialize_measure(SerializedItemHandle)` | 内存序列化句柄 | 跨进程传递 / 网络传输（如 HDevEngine + RPC） |

`close_measure(MeasureHandle)`：**用完必关**，否则句柄池会泄漏。

## 5. 典型工作流（一个完整闭环）

```hdevelop
* 1. 生成句柄
read_image (Image, 'pcb_with_pads.png')
gen_measure_rectangle2 (MeasureHandle, 100, 200, 0, 50, 5, 7, Height, 'bilinear')

* 2. (可选) 装自定义模糊
set_fuzzy_measure (MeasureHandle, 'size', my_size_fuzzy_function)

* 3. 提取
measure_pairs (Image, MeasureHandle, 1.0, 30, 'all', 'all', \
                RowEdgeFirst, ColEdgeFirst, AmplitudeFirst, \
                RowEdgeSecond, ColEdgeSecond, AmplitudeSecond, \
                IntraDistance, InterDistance)

* 4. 在多个 ROI 上复用同一句柄
for i := 0 | 5 by 1
    translate_measure (MeasureHandle, -10*i, 0)
    measure_pairs (Image, MeasureHandle, 1.0, 30, 'all', 'all', \
                   R1, C1, A1, R2, C2, A2, Intra, Inter)
endfor

* 5. (可选) 持久化供下次 session 用
write_measure (MeasureHandle, 'pad_measure.msr')

* 6. 一定记得 close
close_measure (MeasureHandle)
```

## 6. `measure_*` vs `fuzzy_measure_*` 对比（最常被问）

| 维度 | `measure_*` (硬阈值) | `fuzzy_measure_*` (模糊打分) |
| --- | --- | --- |
| **取舍标准** | 单阈值 Threshold | FuzzyThresh (默认模糊函数已能处理很多场景) |
| **抗光照不均** | 差（阈值一固定，灰度变了全挂） | 好（打分自适应） |
| **抗遮挡/部分边缘** | 差 | 好（中等打分也能入选） |
| **速度** | 略快 | 略慢（多一步打分） |
| **可定制** | 无（Sigma/Transition 是上限） | 强（`set_fuzzy_measure*` 加自定义函数） |
| **何时选** | 光照稳、边缘干净、教学/原型 | **生产环境**首选 |

> 经验：**生产代码默认上 `fuzzy_measure_*`**，失败再退回 `measure_*`。

## 7. 边缘对 vs 单边缘 vs 灰度投影 选哪一个？

| 用例 | 推荐算子 | 为什么 |
| --- | --- | --- |
| 量一个边缘位置 | `measure_pos` 或 `fuzzy_measure_pos` | 单点提取 |
| 量两条平行边的**间距**（如槽宽、线宽） | `measure_pairs` 或 `fuzzy_measure_pairs` | 直接给 IntraDistance |
| 已知理想宽度，要"在 ±5% 内才取" | `set_fuzzy_measure_norm_pair` + `fuzzy_measure_pairing` | PairSize 把宽度作为打分维度 |
| 要**自定义**找边缘算法（算子响应、相关匹配等） | `measure_projection` 拿原始剖面 + 自己写 | 完全掌控 |
| 只想拿"灰度穿阈值"位置 | `measure_thresh` | 不算完整亚像素边缘提取，只是阈值通过点 |

## 8. 实战示例：批量测量 PCB 焊盘宽度

```hdevelop
dev_close_window ()
read_image (Image, 'pcb.png')
get_image_size (Image, Width, Height)
dev_open_window (0, 0, Width/2, Height/2, 'black', WindowID)
dev_display (Image)

* —— 一个矩形 ROI (长 100, 宽 4), 角度 0 ——
Row := 80
Column := 100
Phi := 0
Length1 := 50
Length2 := 2
AnnulusWidth := 3

* 1. 建句柄 (几何 + 插值都封进去)
gen_measure_rectangle2 (MeasureHandle, Row, Column, Phi, Length1, Length2, \
                         AnnulusWidth, Height, 'bilinear')

* 2. 直接 production-grade 上模糊
measure_pairs (Image, MeasureHandle, 1.2, 25, 'all', 'all', \
               R1, C1, _, R2, C2, _, Intra, Inter)

* —— Intra = 焊盘宽度 (像素) ——
for i := 0 to |Intra|-1 by 1
    disp_message (WindowID, 'Pad width: ' + Intra[i]$'.3f' + ' px', \
                  'window', 12 + 18*i, 12, 'black', 'true')
endfor
```

如果光照变化大，把上面 `measure_pairs` 换成：

```hdevelop
fuzzy_measure_pairs (Image, MeasureHandle, 1.2, 30, 0.5, 'all', \
                     _, _, _, _, _, _, \
                     RowCenter, ColCenter, Fuzzy, Intra, Inter)
```

并按 `Fuzzy < 0.7` 过滤掉低分对（半透明边缘、表面油污）。

## 9. 常见误区

1. ❌ **忘了 `close_measure`**。句柄会一直占用缓冲区，跑一晚上内存慢慢涨。
2. ❌ **`Sigma` 给太大**。3.0+ 让两近边糊成一条，结果就是"明明两根线只出了一对"。
3. ❌ **Selection="all" + Threshold=30 但图像里灰度只到 200**。直接返回空。**永远先 `min_max_gray` 看一眼分布**再设阈值。
4. ❌ **同一 `MeasureHandle` 跨图像大小不同的图复用**。带子按绝对长度定义，**分辨率不同 = 带子物理宽度不同**，边缘响应不可比。要重 `gen_*`。
5. ❌ **`gen_measure_arc` 的 `AnnulusRadius` 设反了**或太大，扫到图像外。带子必须**完全落在图内**，否则 `measure_*` 抛错。
6. ❌ **Translation 不是 `translate_image` 的镜像**。`translate_measure` 是**沿 Row/Column 平移参考点**，不会反过来平移边缘结果。
7. ❌ **`fuzzy_measure_*` 第一次调就用 `set_fuzzy_measure` 自定义**。先不开 set、用内置模糊验证流程，**确认算子和几何都对再上自定义**，否则排错时多一个变量。
8. ❌ **Transition='positive' 漏掉暗边缘**。过暗区带子灰度变化方向可能反。要么改 `'negative'`，要么直接 `'all'`。
9. ❌ **`write_measure` 文件被改了再 `read_measure`**。HALCON `.msr` 是**自定义二进制**，编辑器改完必坏。要改就重跑 `gen_*`。
10. ❌ **`measure_*` 当作"任意方向边缘提取"用**。它们**只对垂直于带子长轴的边缘敏感**，斜边/任意边最好用 `edges_sub_pix` + `fit_*_contour_xld` 走第 1 章圆/椭圆算子那套。
