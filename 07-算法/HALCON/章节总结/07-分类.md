# 第 7 章 · Classification 算子体系总结

> 思维导图：[07-分类.png](./07-分类.png)
> 适用：HALCON 20.11.1.0（手册 `Operators/Classification`）
> 算子总数：**101 个**（6 族 + 101 ops + 共享 TrainData 工具）
> 作者：Long·阿龙｜2026-08-21

---

## 0. 速读：本章看一遍就够

第 7 章算子看似 101 个吓人，实际上**几乎所有算子都遵循同一个 5 件套模板**：
> create → 加样本 → train → classify → write/read（持久化）

只要记住这个模板，101 个算子瞬间变成 4 套（gmm / knn / mlp / svm）×5 件套 + 一些派生/辅助算子。

**6 族一览**（按手册截图对位 20+18+5+11+24+23 = 101）：

| 族 | 算子数 | 一句话定位 |
|---|---|---|
| A · **GMM** (Gaussian Mixture Models) | 20 | 概率密度估计型分类器，给出后验概率和密度值 |
| B · **KNN** (K-Nearest Neighbors) | 18 | 距离投票型 lazy learner，训练=保存样本，分类=找 K 个邻居 |
| C · **MLP** (Neural Nets / BP) | 24 | 多层感知机（反向传播），支持正则化和拒识阈值 |
| D · **SVM** (Support Vector Machines) | 23 | 最大间隔分类，可缩减支持向量、内置多核 |
| E · **LUT** (Look-Up Table) | 5 | 把 4 大模型"烧"成查表函数，**极快推理**（嵌入式 / FPGA） |
| F · **Misc** (ClassTrainData) | 11 | 模型无关的"训练样本袋"工具集（加样本/序列化/选子特征等） |

> **与 Ch.3 (3D Matching)、Ch.4 (3D Object Model)、Ch.5 (3D Reconstruction)、Ch.6 (Calibration) 不同**：本章是 HALCON **机器学习**核心，2010 年代后不再疯狂扩张；operator count 不再刷高，但用法与 sklearn 接口几乎一一对应。

## 1. 全章 101 算子按 **功能分组**（不抄名字）

> 本节**按操作类型横向切**，让你一眼看清"101 个算子其实就这几件事"。

| 功能分组 | 操作含义 | 出现族 | 算子数（≈） |
|---|---|---|---|
| ① **创建空模型** `create_class_<X>` | 创建未训练的分类器句柄 | GMM/KNN/MLP/SVM | 4 |
| ② **创建训练样本袋** `create_class_train_data` | 创建空的训练样本容器 | Misc | 1 |
| ③ **加样本（两种姿势）** | A) 直接对模型：`add_sample_class_<X>`（一次性模型+训练数据）<br>B) 加到训练样本袋：`add_sample_class_train_data`（分批管理） | 4 训练族 + Misc | 4 + 1 |
| ④ **把样本袋传给模型** | `add_class_train_data_<X>` | 4 训练族 | 4 |
| ⑤ **训练** `train_class_<X>` | 用已有样本拟合模型参数 | GMM(需训)/MLP(需训)/SVM(需训) / **KNN 不需要训** | 3 |
| ⑥ **分类** `classify_class_<X>` | 给特征向量，输出类别+置信度 | 4 训练族 | 4 |
| ⑦ **设置超参 / 取超参** | `set_params_class_<X>` / `get_params_class_<X>`（KNN 唯一用此传超参） | KNN + 4 训练族的 `get_*` | ≈10 |
| ⑧ **持久化**（模型 + 样本） | `read/write_class_<X>`、`<X>_serialize/deserialize`、`read/write_samples_class_<X>` | 全部 | ≈25 |
| ⑨ **销毁** | `clear_class_<X>` / `clear_samples_class_<X>` | 4 训练族 | ≈10 |
| ⑩ **特征选择** | `select_feature_set_<X>` / `select_sub_feature_class_train_data` | GMM/KNN/MLP/SVM + Misc | 5 |
| ⑪ **诊断 / 评估** | `evaluate_class_<X>`（连续密度，Diversity 检验）、`get_prep_info_class_<X>`（GMM/MLP/SVM 的预处理统计） | GMM/MLP/SVM | ≈8 |
| ⑫ **LUT（把模型装成查表）** | `create_class_lut_<X>` / `clear_class_lut` | LUT | 5 |
| ⑬ **SVM 专有** | `reduce_class_svm`（按 alpha 削减支持向量）、`get_support_vector_class_svm`（取出单条支持向量）、`get_support_vector_num_class_svm`（支持向量总数） | SVM | 3 |
| ⑭ **MLP 专有** | `set/get_regularization_params_class_mlp`（正则化）、`set/get_rejection_params_class_mlp`（拒识阈值） | MLP | 4 |
| ⑮ **GMM 专有** | `get_prep_info_class_gmm`（聚类预处理报告） | GMM | 1 |

> 真相：本质就是 **6 张模板表**：①-⑥ 是主链；⑦-⑮ 是每个族在自己分支长出来的小算子。

### 1.1 HDevelop 通用闭环（最常用骨架）

```hdevelop
* 1) 建空模型（族不同，参数不同 —— 详见 §3-§6）
create_class_gmm (NumDim, NumClasses, NumCenters, 'spherical', 'principal_components', 5, 42, GMMHandle)

* 2) 加训练样本（任选一种姿势）
* A) 直接对模型加（一次性，不能复用样本袋）
add_sample_class_gmm (GMMHandle, 'row', FeatureVector, ClassID)

* B) 用样本袋管理（推荐：分批、可序列化、可跨族复用）
create_class_train_data (NumDim, ClassTrainDataHandle)
add_sample_class_train_data (ClassTrainDataHandle, 'row', FeatureVector, ClassID)
add_class_train_data_gmm (GMMHandle, ClassTrainDataHandle)

* 3) 训练（KNN 跳过此步）
train_class_gmm (GMMHandle, 100, 1e-4, 'uniform', 0.0001, Centers, Iter)

* 4) 分类
Features := [f1, f2, f3, ...]
classify_class_gmm (GMMHandle, Features, 1, ClassID, ClassProb, Density, KSigmaProb)

* 5) 持久化
write_class_gmm (GMMHandle, 'model.gmm')
read_class_gmm ('model.gmm', ReloadedHandle)
```

## 2. 4 大训练族的关键对比表

| 维度 | GMM (A) | KNN (B) | MLP (C) | SVM (D) |
|---|---|---|---|---|
| **数学本质** | 多高斯混合求后验 | K 邻居多数投票 | BP 神经网络（多层感知） | 最大间隔 + 核技巧 |
| **是否需要 train** | ✅（EM 迭代） | ❌（样本直接存，懒学） | ✅（BP 迭代） | ✅（SMO/二次规划） |
| **返回除 Class 之外的输出** | `ClassProb` `Density` `KSigmaProb` | `Rating`（归一化距离） | `Confidence`（softmax 概率） | 仅 `Class`（简化接口） |
| **典型超参** | `NumCenters` `CovarType` `Preprocessing` | `k` `distance_metric` | `NumHidden` `OutputFunction` `MaxIterations` | `KernelType` `KernelParam` `Nu` |
| **特征预处理内置？** | ✅ `Preprocessing` (none/center/normalize/principal_components) | ❌ | ✅ `Preprocessing` | ✅ `Preprocessing` |
| **特征选择** | ✅ `select_feature_set_gmm` | ✅ | ✅ | ✅ |
| **拒识/置信度阈值** | 通过 `KSigmaProb` 自定义 | 通过 `Rating` | ✅ `set_rejection_params_class_mlp` | 通过计算 margin |
| **训练数据需求** | 中（每类 ≥ 几个即可，EM 扛得住） | 大（要看出簇结构） | 中大（要够 BP 收敛） | 小（边界样本即可） |
| **训练速度** | 中 | 0（懒学） | 慢 | 中 |
| **推理速度** | 中 | 慢（要算全部训练距离） | 快 | 快（支持向量数） |
| **特殊算子** | `get_prep_info_class_gmm`、`evaluate_class_gmm` | `set_params_class_knn` | 正则化+拒识两组算子 | `reduce_class_svm`、`get_support_vector_class_svm` |

## 3. 族 A · GMM（20 ops · 概率密度型）

> 关键认知：**GMM 既能分类，又能做离群点检测**（KSigmaProb 极大即异常）。

### 3.1 核心签名（以本地 Operator Reference 为准）

```
create_class_gmm( : : NumDim, NumClasses, NumCenters, CovarType, Preprocessing,
                  NumComponents, RandSeed : GMMHandle)

train_class_gmm( : : GMMHandle, MaxIter, Threshold, ClassPriors, Regularize
                 : Centers, Iter)

classify_class_gmm( : : GMMHandle, Features, Num
                    : ClassID, ClassProb, Density, KSigmaProb)

add_class_train_data_gmm( : : GMMHandle, ClassTrainDataHandle : )
```

### 3.2 关键 GenParam / 取值

| 参数 | 取值 | 含义 |
|---|---|---|
| `CovarType` | `'spherical'` / `'diag'` / `'full'` | 协方差矩阵形状（spherical 最快，full 最准） |
| `Preprocessing` | `'none'` / `'center'` / `'normalize'` / `'principal_components'` / `'canonical_variates'` | 特征预处理（推荐 `'principal_components'` 去相关） |
| `ClassPriors` | `'uniform'` / `'cluster'` / `'equal'` / `'inher'` | 训练时各类先验概率（默认 `uniform`） |
| `MaxIter` | int（默认 100） | EM 最大迭代次数 |
| `Threshold` | real（默认 1e-6） | EM 收敛阈值 |
| `Regularize` | real（默认 0.0001） | 协方差正则项（防奇异矩阵） |

### 3.3 输出含义

| 返回值 | 含义 |
|---|---|
| `ClassID` | 预测类别下标（0..NumClasses-1） |
| `ClassProb` | 后验概率 `P(class|features)` |
| `Density` | 混合高斯的联合密度 `p(features)`（大→正常；极小→离群） |
| `KSigmaProb` | Mahalanobis 距离对应的高斯累积概率（极大即远离所有中心） |

### 3.4 族特有算子速览

- **`get_prep_info_class_gmm`**：训练后取预处理报告（主成分方向、均值向量等）
- **`evaluate_class_gmm`**：与 `classify` 类似但**仅返回概率**，更轻量
- **`select_feature_set_gmm`**：自动特征选择（贪心/穷举），返回所选下标与得分

## 4. 族 B · KNN（18 ops · 距离投票）

> 关键认知：**KNN 没有"训练"**，加样本即训练，分类时遍历整个训练集找最近 K 个邻居。
> 因此 KNN 唯一专用超参设置算子 `set_params_class_knn`。

### 4.1 核心签名

```
create_class_knn( : : NumDim : KNNHandle)

train_class_knn( : : KNNHandle, GenParamName, GenParamValue : )

classify_class_knn( : : KNNHandle, Features
                    : Result, Rating)

set_params_class_knn( : : KNNHandle, GenParamName, GenParamValue : )
```

### 4.2 关键 GenParam（用 `set_params_class_knn` 设置）

| GenParam | 取值 | 含义 |
|---|---|---|
| `'k'` | int (默认 1) | 邻居数 |
| `'distance_method'` | `'euclidean'` / `'subspace'` / `'mean_diff'` / `'subspace_normalized'` | 距离度量 |
| `'metric'` | `'knn'`（默认）/ `'mean_distance'` | 是否先做距离归一化 |

### 4.3 输出含义

- `Result`：`ClassID`（多数票决）
- `Rating`：归一化距离（0=最近邻本身，1=最远训练样本）—— 可设阈值当拒识

## 5. 族 C · MLP（24 ops · BP 神经网络）

> 关键认知：HALCON 的 MLP 是 **3 层前馈网络**（输入-隐藏-输出），通过 BP 训练。**没有自动多隐藏层堆叠**——需要嵌套表达。

### 5.1 核心签名

```
create_class_mlp( : : NumInput, NumHidden, NumOutput,
                  OutputFunction, Preprocessing, NumComponents, RandSeed
                  : MLPHandle)

train_class_mlp( : : MLPHandle, MaxIterations, WeightTolerance, ErrorTolerance
                 : Error, ErrorLog)

classify_class_mlp( : : MLPHandle, Features, Num
                    : Class, Confidence)

set_regularization_params_class_mlp( : : MLPHandle, GenParamName, GenParamValue : )
set_rejection_params_class_mlp    ( : : MLPHandle, GenParamName, GenParamValue : )
```

### 5.2 关键 GenParam

| 参数 | 取值 | 含义 |
|---|---|---|
| `OutputFunction` | `'softmax'`（默认）/ `'logistic'` / `'linear'` | 输出层激活；多分类必选 softmax |
| `Preprocessing` | 同 GMM | 内置特征预处理 |
| `MaxIterations` | int | BP 最大迭代 |
| `WeightTolerance` / `ErrorTolerance` | real | 收敛判据 |

### 5.3 正则化（防止过拟合）

`set_regularization_params_class_mlp(Handle, `'gen_params_name'`, value)`

| GenParam | 含义 |
|---|---|
| `'weight_prior'` | 权重先验（默认 1.0） |
| `'min_num_samples'` | 每类最少样本（默认 5） |

### 5.4 拒识阈值（输出置信度不够时输出 `-1` 类）

`set_rejection_params_class_mlp(Handle, `'gen_param_name'`, value)`

| GenParam | 含义 |
|---|---|
| `'rejection_class_num'` | 拒识类编号（默认 `NumOutput`+1） |
| `'rejection_sample_contrast'` | 最小归一化对比度 |
| `'rejection_constrain_scale'` | 边界尺度约束 |

> 对应 `get_regularization_params_class_mlp` / `get_rejection_params_class_mlp` 读回。

## 6. 族 D · SVM（23 ops · 最大间隔）

> 关键认知：HALCON SVM 用 **Nu-SVC** 形式（不是 C-SVC），`Nu` 控制支持向量比。**支持多分类**：内置 OvO / OvR。

### 6.1 核心签名

```
create_class_svm( : : NumFeatures, KernelType, KernelParam, Nu,
                  NumClasses, Mode, Preprocessing, NumComponents
                  : SVMHandle)

train_class_svm( : : SVMHandle, Epsilon, TrainMode : )

classify_class_svm( : : SVMHandle, Features, Num : Class)

reduce_class_svm( : : SVMHandle, Method, MinRemainingSV, MaxError : SVMHandleReduced)

get_support_vector_class_svm  ( : : SVMHandle, IndexSupportVector : Index)
get_support_vector_num_class_svm ( : : SVMHandle : NumSupportVectors)
```

### 6.2 关键 GenParam

| 参数 | 取值 | 含义 |
|---|---|---|
| `KernelType` | `'rbf'`（默认）/ `'linear'` / `'polynomial'` / `'sigmoid'` | 核函数 |
| `KernelParam` | real | 核参数：rbf=γ、polynomial=degree、sigmoid=coef0 |
| `Nu` | (0, 1] | Nu-SVC 的 ν（默认 0.1） |
| `Mode` | `'one-versus-one'`（默认）/ `'one-versus-all'` / `'novelty-detection'` | 多分类模式 |
| `TrainMode` | `'default'` / `'iterative'` / `'number'` | SMO 求解器模式 |
| `Epsilon` | real | KKT 精度 |
| `Method` | `'bottom_up'` / `'top_down'`（reduce 时用） | 支持向量剪枝方向 |

### 6.3 推理输出只有 `Class`（无置信度）

如果需要置信度，HALCON 推荐改用 `evaluate_class_svm`（在 Version 20 之后内部已可调用）。

### 6.4 reduce 与 get 支持向量的工作流

```hdevelop
* 训练后裁掉 90% 几乎无用的支持向量（加速推理）
reduce_class_svm (SVMHandle, 'bottom_up', 0.1 * NumSupportVectors, 0.05, ReducedHandle)

* 取出第 5 个支持向量（可解释性分析）
get_support_vector_class_svm (SVMHandle, 5, Index)
```

## 7. 族 E · LUT（5 ops · 嵌入式快查表）

> 关键认知：LUT = 把训练好的大模型**预计算为查找表**。推理只需 1 次数组访问，**速度 10×-100×**。

### 7.1 5 个算子签名

```
create_class_lut_gmm( : : GMMHandle, GenParamName, GenParamValue : ClassLUTHandle)
create_class_lut_knn( : : KNNHandle, ...,                         : ClassLUTHandle)
create_class_lut_mlp( : : MLPHandle, ...,                         : ClassLUTHandle)
create_class_lut_svm( : : SVMHandle, ...,                         : ClassLUTHandle)
clear_class_lut      ( : : ClassLUTHandle : )
```

### 7.2 适用场景

- 工厂大批量实时推理（每帧 1000 个特征点 → 1000×快几毫秒）
- 嵌入式 / FPGA / DSP（无浮点）环境
- 一旦 LUT 建好，原模型可以丢了（但反推不可）

### 7.3 关键 GenParam

- `'bit_depth'`：LUT 表项位数（越大越准，典型 8/16/32）
- `'class_selection'`：是否包含所有类别
- `'preprocessing'`：与原模型一致的预处理

## 8. 族 F · Misc（11 ops · 训练样本袋工具）

这族**不创建任何模型**，只管理训练样本袋（`ClassTrainDataHandle`），让样本可以：
- 跨族复用（GMM/KNN/MLP/SVM 共享一份样本）
- 序列化（落盘，跨进程共享）
- 子特征筛选（只让部分特征参与训练）

| 算子 | 用途 |
|---|---|
| `create_class_train_data` | 创建空样本袋 |
| `add_sample_class_train_data` | 加单条样本（Order/Features/ClassID） |
| `get_sample_num_class_train_data` | 样本数（按类别统计） |
| `select_sub_feature_class_train_data` | 截取子特征袋 |
| `set_feature_lengths_class_train_data` | 把特征向量分成"子特征"（多模态特征） |
| `get_class_train_data` | 取单条样本的数据 |
| `read_class_train_data` / `write_class_train_data` | 持久化 |
| `serialize_class_train_data` / `deserialize_class_train_data` | 内存级序列化 |
| `clear_class_train_data` | 销毁 |

### 8.1 关键签名前 2 个

```
add_sample_class_train_data( : : ClassTrainDataHandle, Order, Features, ClassID : )

set_feature_lengths_class_train_data( : : ClassTrainDataHandle, SubFeatureLength, Names : )
```

> `Order`：`'uniform'` | `'cyclic'` | `'by_class'` —— 训练时遍历顺序
> `ClassID`：≥0 的整数，`ClassID = 0` 默认是背景类（与一些其他族的约定不同）

## 9. 6 族选型决策（什么时候用哪个）

```
需要概率 / 离群检测？  ── 是 ──► GMM
                         │
                         否
                         ▼
                  有几何距离意义？  ── 是 ──► KNN
                         │
                         否
                         ▼
                样本 ≤ 10^4 且要推理快？
                         │
                  是 ────► SVM (rbf kernel 通常最好用)
                         │
                         否
                         ▼
                数据非线性强、有充足样本 ──► MLP
                         │
                         ▼
                嵌入式 / FPGA 部署 ──► LUT（先把上面 4 种之一造好，再烧）
```

**真实工程案例速览**：

| 应用 | 推荐族 | 理由 |
|---|---|---|
| 零件 AOI（6 类缺陷） | MLP (softmax) 或 SVM (rbf) | 数据丰富，类别清晰 |
| OLED 屏幕亮点检测（离群） | GMM + KSigmaProb | 离群检测天然适合 |
| 印章匹配（少量样本） | KNN | 训练 = 几行代码，1-NN 够用 |
| 大批量产品 100% 抽检 | LUT（先 MLP/SVM 烧表） | 每帧 1ms 推理 |
| 多模态（颜色+纹理+形状） | 训练样本袋 + `set_feature_lengths` | 不必把所有特征混成一个向量 |

## 10. 10 条实战误区（按危险度排序）

1. **【致命】`create_class_X` 的 NumDim/NumFeatures 必须等于实际特征向量的长度**，否则分类结果全错且不报异常 —— 用 `set_feature_lengths_class_train_data` 确认
2. **【致命】`add_sample_class_X` 的 ClassID 不能用负数**；HALCON 默认 `ClassID=0` 是背景类，与其他族的"0=第一类"约定反着
3. **【高危】`train_class_svm` 设置 Mode='one-versus-all' 但只训练一类** —— 永远只用一个样本类训练得到的 OvR 是空分类器，必须 ≥ 2 类
4. **【高危】`create_class_mlp` 不设 `OutputFunction='softmax'` 而用 logistic** —— 多分类概率之和不为 1，结果不可信
5. **【高危】`reduce_class_svm` 设 `MaxError>0.1`** —— 精度掉了但分类边界没变，本来是要"快"结果"不准"
6. **【中危】`classify_class_gmm` 拿到的 `Density` 不直接当概率用** —— `Density` 是未归一化密度；显示用需除以类先验
7. **【中危】`select_feature_set_X` 自动特征选择只对当前 Model 有效**，迁移到其他族需要重做
8. **【中危】`serialize_class_X` 与 `write_class_X` 不可混用** —— serialize 是 HSerializedItem 字节流，write 是 HALCON 内部文件；调用 deserialize 对 read 的句柄会报错
9. **【低危】KNN 推理比训练慢得多** —— 这是设计，**别在大数据用 KNN 做实时**
10. **【低危】LUT 不能增量更新** —— 加样本必须重新 `create_class_lut_X`
