# 第 12 章 · Filters · 上卷 —— 像素级代数、位运算与颜色空间

> **章节定位**：HALCON 算子手册第 12 章 Filters 是机器视觉的"数学工具箱"，整章共 **187 个算子 / 18 个子族**，跨度极大。本卷（上卷）涵盖最基础、最常用的 3 个子族 —— 像素级算术与三角函数、位运算、颜色空间变换。
> 后续还有中卷（边缘/增强/修补/几何变换）与下卷（FFT/平滑/特征点/光流/纹理）覆盖频域、空域线性、形态学等更高级滤波。

本卷算子数：**41 个**（Arithmetic 22 + Bit 8 + Color 11）。

---

## 1. 上卷三族一览

| 族 | 中文 | 算子数 | 核心抽象 | 典型用法 |
|---|---|---|---|---|
| **Arithmetic** | 算术代数 | 22 | 像素级 `op(x) = f(x)` 一一映射 | 图像加减乘除、伽马校正、sRGB 互转 |
| **Bitwise** | 位运算 | 8 | 像素级位操作（与/或/非/移位/切片） | ROI 掩码叠加、按位掩膜提取、bit-plane 拆分 |
| **Color** | 颜色空间 | 11 | RGB ↔ HSV/YUV/Lab/CIE 互转、Bayer 解马赛克、PCA 颜色降维 | 单相机彩色处理、机器视觉照明标准化 |

> **共同点**：所有算子都是**像素独立**的 *逐点 *point operation）—— 不读邻域、不产新结果维度（除 Color 族几个特例把单通道拆/合 3 通道）。
> 这意味着它们在 GPU/多核上**并行度最高**，也是流水线最便宜的环节。

## 2. Arithmetic（22）—— 像素级数学

> 本族几乎所有算子都是 HALCON 早期就存在的"图像按元素乘方器"。算子数量大是因为 HALCON 把"每种数学函数"都做成独立算子（而不是 `apply(lambda)`）。

### 2.1 二元算术（两幅图像 + 一个常数）

| 算子 | 公式 | 关键参数 |
|---|---|---|
| `add_image` | `Out = Mult·I1 + Mult·I2 + Add` | `Mult`（缩放），`Add`（偏置） |
| `sub_image` | `Out = Mult·IMinuend - Mult·ISubtrahend + Add` | 同上，`Minuend` 被减数，`Subtrahend` 减数 |
| `mult_image` | `Out = Mult·I1·I2 + Add` | `Mult`（积缩放），`Add`（偏置） |
| `div_image` | `Out = Mult·I1 / I2 + Add` | 同上，**除零产生未定义值**（HALCON 视版本返回 0 或 MAX） |
| `max_image` | `Out = max(I1, I2)` | 像素独立取大，可用于合成两幅曝光 |
| `min_image` | `Out = min(I1, I2)` | 像素独立取小 |
| `abs_diff_image` | `Out = \|I1 - I2\| · Mult` | **L1 残差** 用于背景建模 / 缺陷差分 |

> 💡 Mult/Add 这一对参数是 HALCON 把"线性变换"前置到算子里的设计 —— 你不用先 `scale_image` 再 `sub_image`，直接 `sub_image(I1, I2, Out, 1, -128)` 就能一次性算 **"差减半再加 128"（归一化到 0-255）**。

### 2.2 一元函数（单图）

| 算子 | 公式 | 用途 |
|---|---|---|
| `abs_image` | `Out = |x|` | 整流 |
| `invert_image` | `Out = C - x` | 反相（`C=255` 等） |
| `sqrt_image` | `Out = √x` | 去噪前的方差稳定化、伽马 0.5 |
| `exp_image` | `Out = Base^x` | e^x / 2^x 等 |
| `log_image` | `Out = log_base(x)` | 对数压缩，照度均衡化 |
| `pow_image` | `Out = x^a`（a=Exponent） | 伽马校正 |
| `gamma_image` | `Out = ((x-Off)/(Th-Off))^Gamma · Max` | 带偏置阈值化的伽马映射 |

### 2.3 三角函数（弧度域）

| 算子 | 函数 | 说明 |
|---|---|---|
| `sin_image` `cos_image` `tan_image` | 基础三角 | 输入是**弧度**！byte 图需先归一化 |
| `asin_image` `acos_image` `atan_image` | 反三角 | 输出弧度 |
| `atan2_image` | `atan2(Y, X)` | 同位 quadrants 自动判别 |

> ⚠️ HALCON 中所有三角/反三角算子**全部用弧度**。byte 图（0-255）直接传入会饱和——必须先 `scale_image(I, I_rad, 2*PI/256, -PI)`。

### 2.4 典型流水线

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  scale_  │ -> │  sub_    │ -> │  abs_    │ -> │  mult_   │ -> │  log_    │
│  image   │    │  image   │    │  diff    │    │  image   │    │  image   │
│ (×2π/256)│    │ (- ref)  │    │  image   │    │ (×255)   │    │ (压缩)   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
                                    ↓ 残差图
```

## 3. Bitwise（8）—— 像素级位操作

> 位运算主要面向 **位深度 ≥ 8 的整数图（byte/int1/int2/int4/uint2 等）**，对 float 图无意义。

### 3.1 按门运算

| 算子 | 操作 | 用途 |
|---|---|---|
| `bit_and` | `Out = I1 & I2` | 掩码叠加（mask & image） |
| `bit_or` | `Out = I1 \| I2` | 区域并集、合成 |
| `bit_xor` | `Out = I1 ^ I2` | 异或 —— **图像比对/水印定位** |
| `bit_not` | `Out = ~I` | 按位取反，与 `invert_image` 区别是按位（不是按颜色） |

### 3.2 移位与掩码

| 算子 | 操作 | 关键参数 | 说明 |
|---|---|---|---|
| `bit_lshift` | `Out = x << Shift` | `Shift`（移位数） | 左移 → 高位→低位，**超界溢出丢弃** |
| `bit_rshift` | `Out = x >> Shift` | `Shift` | 右移 → 低位→0，高位补 0（逻辑右移） |
| `bit_mask` | `Out = x & BitMask` | `BitMask`（如 0xFF00） | 提取特定 bit plane 区段 |
| `bit_slice` | `Out = (x>>Bit) & 1` | `Bit`（0-31） | 提取**单 bit** → 返回 0/1 区域图 |

### 3.3 经典应用：8 个 bit-plane 拆分

```
for i := 0 to 7
    bit_slice(image, plane, i)   // 提取第 i 个 bit-plane
    rgb1_to_gray(plane, plane)   // 转灰度（plane 已经是区域转图）
endfor
→ 得到 8 张 0/1 二值图，可视化每比特变化
```

### 3.4 与 `region` 域算子关系

> `bit_*` 算子跟 Region 域算子的 `difference`/`union`/`intersection` **看起来像**但本质不同 —— Region 处理的是 area mask 而非像素灰度。**位运算算子直接修改像素值**，输出仍然是一幅"图"。

## 4. Color（11）—— 颜色空间变换

> 本族是视觉系统**进光→成像→输出**链条里"颜色"那一环。HALCON 把所有颜色空间互转做成独立算子，按"出入"两两配对。

### 4.1 颜色空间字典

| ColorSpace 取值 | 输出 3 通道含义 | 典型应用 |
|---|---|---|
| `'rgb'` | R, G, B | 默认，直观 |
| `'hsv'` | H (0-255), S, V | 色选（按 H 分选），不依赖亮度 |
| `'hsi'` | H, S, I | 同上，分量定义略不同 |
| `'yuv'` | Y (亮度), U, V | 电视信号，老式摄像头 |
| `'yiq'` | 同上变种 | 美制电视 |
| `'ycbcr'` | Y, Cb, Cr | JPEG/HEIC 内部色空间 |
| `'xyz'` | CIE XYZ | 色彩学度量 |
| `'lab'` / `'l*a*b*'` | L (0-100), a, b | **CIE Lab —— 印刷/纺织业标准**，感知均匀 |
| `'luv'` | L, u, v | 同上均匀感知 |
| `'hls'` | H, L, S | HSV 变种 |
| `'cielch_ab' / 'cielch_uv'` | L, C, H | Lab/LUV 的极坐标，方便按 H 取色 |
| `'gray'` | 单通道 | 灰度（仅 `trans_from_rgb/apply_lut` 输出灰度单通道） |

### 4.2 标准 RGB ↔ 其他

| 算子 | 形式 | 用途 |
|---|---|---|
| `trans_from_rgb(R, G, B → 3图, `'hsv'`)` | RGB 3 图 → 任意颜色空间 3 图 | 颜色空间分解 |
| `trans_to_rgb(3图 → R, G, B, `'hsv'`)` | 任意颜色空间 3 图 → RGB 3 图 | 反变换 |
| `rgb1_to_gray(RGB → Gray)` | **单通道** RGB 图（channel=1）转灰度 | HALCON 自动取 R`0.299 + G`0.587 + B`0.114 |
| `rgb3_to_gray(R, G, B → Gray)` | **三幅 1 通道图** 转灰度 | 同上但输入是分开的三幅 |

### 4.3 LUT 查表高速颜色变换

> 当**同一个变换**需要在很多像素上反复调用时，构建 LUT 比每次重算快 10-100×。

| 算子 | 作用 |
|---|---|
| `create_color_trans_lut` | 预生成 LUT（`ColorSpace`, `TransDirection`, `NumBits`） |
| `apply_color_trans_lut` | 把单通道图（或 3 通道串接）按 LUT 一一变换 |
| `clear_color_trans_lut` | 释放 LUT |

- `NumBits` 决定精度（如 NumBits=8 → LUT 含 256×3×256×3×… 项）。越大准、越大内存。

### 4.4 PCA 主成分颜色降维

| 算子 | 形式 | 输出 |
|---|---|---|
| `gen_principal_comp_trans` | `MultichannelImage → (Trans, TransInv, Mean, Cov, InfoPerComp)` | 训练阶段：返回**变换矩阵 + 协方差 + 各成分方差占比** |
| `principal_comp` | `MultichannelImage → PCAImage` | 应用阶段：用 Trans 把多通道压成 PCA 通道（按 InfoPerComp 排序，主成分在前） |
| `principal_compt` | 多通道图变换（输出维度与原图同） | 同上但**保留所有主成分**（用于可视化重构） |

> 应用：缺陷检测里把 RGB/HIS 多通道压成"主通道 + 残差"，残差图就是缺陷图。

### 4.5 Bayer / CFA 解马赛克

| 算子 | 形式 | 关键参数 | 说明 |
|---|---|---|---|
| `cfa_to_rgb` | Bayer CFA 单通道图 → RGB 三通道图 | `CFAType`（'bayer_gbrg'/'bayer_grbg'/'bayer_bggr'/'bayer_rggb'），`Interpolation` ('bilinear'/'nearest_neighbor') | 把单 sensor 出来的 Bayer 阵列还原为彩色图 |

### 4.6 线性色彩变换

| 算子 | 形式 | 说明 |
|---|---|---|
| `linear_trans_color` | RGB 三通道 → RGB 三通道，变换通过 3×3 矩阵 `TransMat` | 用 **3×3 矩阵** 把 RGB 投到线性子空间（白平衡、灰度世界法） |

> `TransMat` 通常由 `gen_principal_comp_trans`、`vector_to_proj_hom_mat2d`（Ch6）或自己手算推导。

## 6. 速查卡（3 张）

### 6.1 1 行级速查："我想要 X → 用哪个算子"

| 需求 | 算子 |
|---|---|
| 把两图相加 + 缩放 | `add_image(I1, I2, Out, Mult, Add)` |
| 残差（背景减） | `abs_diff_image(FG, BG, Out, 1.0)` |
| 灰度反转 | `invert_image(I, Out)` |
| sRGB → 线性 | `gamma_image(I, Out, 2.2, 0, 0, 255, 'true')` |
| 位掩膜 | `bit_mask(I, Out, 0xFF00)` |
| 提取第 4 个 bit | `bit_slice(I, Out, 4)` |
| RGB → HSV | `trans_from_rgb(R, G, B, H, S, V, 'hsv')` |
| RGB → 灰度 | `rgb3_to_gray(R, G, B, Gray)` 或 `rgb1_to_gray(RGB, Gray)` |
| Bayer → RGB | `cfa_to_rgb(CFA, RGB, 'bayer_gbrg', 'bilinear')` |
| 多通道 PCA 投影 | `gen_principal_comp_trans(I → (Trans,…))` 然后 `principal_comp(I, Out)` |

### 6.2 关键参数速记

```
Arithmetic:
  add_image/sub_image/mult_image/div_image
      Mult : double   // 整体缩放（默认 1.0）
      Add  : double   // 整体偏置（默认 0.0）

  gamma_image
      Gamma      : double  // 伽马指数（>1 暗化，<1 亮化）
      Offset     : double  // 偏置
      Threshold  : double  // <此值视为 0
      MaxGray    : double  // 输出最大值
      Encode     : 'true'/'false' // 是否 encode（HALCON 内部数值校准）

Bit:
  bit_lshift/bit_rshift
      Shift : int   // 移位数（负数 = 反向移位）

  bit_mask
      BitMask : int // 位掩码（如 0xFF00 提取高 8 位）

  bit_slice
      Bit : int  // 0-31，要切的 bit 位

Color:
  create_color_trans_lut
      ColorSpace       : 'rgb','hsv','lab',…
      TransDirection   : 'from_rgb'/'to_rgb'
      NumBits          : 6/8/10/12  // LUT 精度

  cfa_to_rgb
      CFAType : 'bayer_gbrg','bayer_grbg','bayer_bggr','bayer_rggb'
      Interpolation : 'bilinear','nearest_neighbor'

  gen_principal_comp_trans (输出)
      Trans, TransInv, Mean, Cov, InfoPerComp : 5 元组
```

### 6.3 性能速记

- 像素级算子在 SIMD 上**全部自动并行化**，**单线程**也比 Region 域算法快一个数量级
- LUT 颜色变换首次调用须 `create_color_trans_lut`（约 30-80ms），之后循环里**复用**是 O(1)
- 三角函数 family (`sin/cos/tan/asin/acos/atan/atan2`) 是**逐点**调用，做批量请用 `for ... from ... to ... do ... endfor`（Ch8 Control）展开而非内联
- `bit_*` 是**整型图专享**，对 float 图会先 `convert_image_type` 才跑（多一次转换，不推荐）

## 7. 8 条常见误区

1. **三角函数默认弧度不是度**：`sin_image(BYTE_128)` 全是 0。byte 图必须先 `scale_image(Irad, π/128, 0)` 再传。
2. **PCA 通道顺序**：第一通道是方差最大成分，**不是** R 通道。`InfoPerComp` 才告诉你每个通道占总方差多少。
3. **`trans_from_rgb` 接 3 个单通道图**，**不是** 1 张 3 通道图（用 `image_to_channels` 拆）。`trans_to_rgb` 同理。
4. **`rgb1_to_gray` 是 1 通道"伪装 3 通道"输入**，不读像素第 2/3 通道。需要真实 3 通道用 `rgb3_to_gray`。
5. **`cfa_to_rgb` 必须传 CFAType**，**不能根据图猜**。同一相机换镜头都要复核 Bayer 模式。
6. **`bit_slice` 返回的不是区域，是 0/1 像素图**。要做区域用 `threshold(plane, &Region, 1, 1)`。
7. **`add_image` 的 Mult 和 Add 一起用**：`Mult=1/255, Add=-0.5` 等价于"把 0-255 拉到 -0.5..+0.5"——直接传 byte 会溢出，输出图必须先 `convert_image_type(I, Ifloat, 'real')`。
8. **`gamma_image` 的 Encode 参数** —— HALCON 早期算子有用 'encode'/'no_encode'，若你看到 `'no_encode'` 通常意为"输出不归一化"。

## 10. 备注

- 本卷是 Ch12 中**唯一完全像素独立**的家族 —— 不读邻域、不依赖域大小（除 LUT 精度之外），是流水线最便宜的环节。
- HALCON 所有 `mult/sub/div/add` 的 Mult/Add 设计是为了**避免反复调用 `scale_image`**，在循环里也是单次 `add_image(I1, I2, O, 0.5, 0)` 就完成"缩放 + 偏置 + 相加"。
- `Color` 族的 PCA 是少数**输出元组（5 元）**的算子（`Trans, TransInv, Mean, Cov, InfoPerComp`），跟 Ch4 ObjectModel3D 的 `inspect_3d_object_model_3d` 同风格 —— 训练/推理分离。
- 上卷所有算子**导出可移植性 100%**（C++/Python/.NET 全可用），仅参数命名风格变化。
- 中卷预告：**Edges 23 + Enhancement 7 + Inpainting 6 + Geometrictransformations 12 = 48 算子**，从像素级迈入"邻域 + 空间变换"层。
