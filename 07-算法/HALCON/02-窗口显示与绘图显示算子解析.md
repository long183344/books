# 02 · HALCON 窗口显示与绘图显示算子解析

> **一句话结论**：HALCON 里"显示"分两类 —— **窗口显示**（把图像/区域/文本画到屏幕窗口，不进图像数据）和 **绘图显示**（让用户交互画形状取 ROI，或把图形永久画进图像矩阵）。先搞清"只是显示"还是"进了数据"，再选 `disp_*` / `draw_*` / `paint_*`。
> **数据基准**：HALCON 20.11.1.0（Operator Reference 已逐条核对）｜ **难度**：入门 → 进阶 ｜ **前置**：[01-圆形椭圆与圆弧算子解析](./01-圆形椭圆与圆弧算子解析.md)

---

## 1. 先把概念理清：三条不同的"画"

很多新手混淆，是因为这几组名字很像但**结果完全不同**：

| 你想要的 | 用哪类算子 | 结果留在哪 | 典型场景 |
| --- | --- | --- | --- |
| 把图像/区域/文字**显示**在窗口上（临时，刷新即覆盖） | `dev_display` / `disp_*` / `dev_disp_text` | 仅屏幕，**不进图像变量** | 看结果、做标注 |
| **交互**让用户用鼠标画一个形状并返回参数 | `draw_*` | 返回数值参数（Row/Column/...），**没创建对象** | 取 ROI、人工标定 |
| 把图形**永久画进图像矩阵**（像素级写入） | `paint_*` | 真正改了 `Image` 的数据 | 合成、打标、生成模板图 |

一句话记忆：

```
显示 = 画在屏幕上（disp_* / dev_display / dev_disp_text）
交互 = 鼠标画一下，给你数字（draw_*）
绘图 = 画进图像里（paint_*）
```

## 2. 窗口管理：先有窗口，才能显示

没有窗口句柄 `WindowHandle`，绝大多数 `disp_*` 都没法用。

### 2.1 打开窗口（两种写法）

**`dev_open_window`**（HDevelop 首选，参数最少）：

```
dev_open_window ( : : Row, Column, Width, Height, Background : WindowHandle)
```

| 参数 | 含义 |
| --- | --- |
| `Row, Column` | 窗口左上角在**屏幕**上的像素坐标（不是图像坐标） |
| `Width, Height` | 窗口的像素尺寸 |
| `Background` | 背景色，字符串如 `'black'`、`'white'`、`'3f47ff'` |
| `WindowHandle` | **输出**：后续所有显示算子都要传它（或靠 dev 系列自动用"当前窗口"） |

**`open_window`**（底层版，功能更全）：

```
open_window ( : : Row, Column, Width, Height, FatherWindow, Mode, Machine : WindowHandle)
```

- `FatherWindow`：父窗口的逻辑号，`'root'` 或 `0` 表示直接挂在桌面上。
- `Mode`：窗口模式（本地通常取默认可见窗口）。
- `Machine`：远程机器名，**本机留空字符串 `''`**。

> ⚠️ **`dev_*` 与无 `dev_` 的区别**：`dev_open_window` 是 HDevelop 环境的过程封装，会把它设为"当前激活窗口"，后续 `dev_display` 之类**不用传句柄**；`open_window` 是纯算子，必须自己保管 `WindowHandle` 并传给 `disp_obj(..., WindowHandle)`。

### 2.2 关闭 / 切换 / 查询

```
dev_close_window ( : : : )                      // 关闭当前窗口
dev_set_window ( : : WindowHandle : )           // 把某窗口设为"当前窗口"
dev_get_window ( : : : WindowHandle)            // 取当前窗口句柄
set_window_param ( : : WindowHandle, Param, Value : )   // 设窗口参数（见 2.3）
set_window_attr ( : : AttributeName, AttributeValue : ) // 设窗口属性（新建窗口前生效）
dev_set_window_extents ( : : Row, Column, Width, Height : ) // 改当前窗口的位置与大小
```

### 2.3 常用 `set_window_param` 参数

| Param | 作用 | 例 |
| --- | --- | --- |
| `'background_color'` | 背景色 | `'black'` |
| `'window_title'` | 窗口标题栏文字 | `'检测结果'` |
| `'flush'` | 是否立即刷新（`'true'`/`'false'`，批处理时关掉提速） | `'true'` |
| `'graphics_stack'` | 是否保留图形栈（影响 `disp_*`（非 dev）叠加行为） | `'true'` |

## 3. 显示环境设置：`dev_set_*` 控制"后面怎么画"

这一类**不改变已有显示**，而是设置"之后的显示长什么样"。常见坑：改了颜色但没生效 —— 多半是**设置写在显示之后**了。

| 算子 | 签名（简化） | 控制什么 | 取值示例 |
| --- | --- | --- | --- |
| `dev_set_color` | `( : : ColorName : )` | 后续区域/图形的颜色 | `'red'`, `'#ff8000'` |
| `dev_set_colored` | `( : : NumColors : )` | 一次显示多个对象时自动循环配色 | `12`（12 色轮换） |
| `dev_set_draw` | `( : : DrawMode : )` | 区域填充 or 仅轮廓 | `'fill'` / `'margin'` |
| `dev_set_line_width` | `( : : LineWidth : )` | 轮廓线宽（像素） | `3` |
| `dev_set_shape` | `( : : Shape : )` | 区域显示成什么形状 | `'original'` / `'rectangle1'` / `'ellipse'` |
| `dev_set_lut` | `( : : LutName : )` | 图像的查找表（伪彩/灰度映射） | `'default'` / `'rainbow'` / `'gray'` |
| `dev_set_part` | `( : : Row1, Col1, Row2, Col2 : )` | 窗口显示图像的**哪一部分**（缩放/平移） | 见下 |

### 3.1 `dev_set_part`：窗口里的"缩放与平移"

```
dev_set_part ( : : Row1, Column1, Row2, Column2 : )
```

- 四个参数是**图像坐标**的左上角 (Row1,Column1) 和右下角 (Row2,Column2)。
- 它把这小块图像"拉伸"填满整个窗口 → 实现**放大查看**。
- `(0,0,-1,-1)` 表示显示整幅图（不缩放）。
- 只对**图像类显示**（`disp_image`/`disp_color`）和区域显示生效；不影响 `disp_text` 的坐标系。

## 4. 显示图像与对象

| 算子 | 签名 | 说明 |
| --- | --- | --- |
| `dev_display` | `(Object : : : )` | 显示任意对象（图/区域/XLD），用当前窗口 |
| `disp_obj` | `(Object : : WindowHandle : )` | 同上，但**必须显式传窗口句柄** |
| `disp_image` | `(Image : : WindowHandle : )` | 只显示图像（灰度/伪彩） |
| `disp_region` | `(DispRegions : : WindowHandle : )` | 显示区域（受 `dev_set_draw`/`color` 影响） |
| `disp_xld` | `(XLDObject : : WindowHandle : )` | 显示 XLD 轮廓（亚像素，不受 region 形状设置影响） |
| `dev_clear_window` | `( : : : )` | 清空当前窗口 |

> **`dev_display` vs `disp_obj`**：前者是 HDevelop 封装、自动用当前窗口、写变量窗口；后者是纯算子，必须传 `WindowHandle`。在导出代码（C++/C#）里，`dev_display` 会被翻译成 `HWindow.DispObj`。

## 5. 文本显示（重点，已逐条核对官方文档）

文本类最容易出问题的是 `dev_disp_text` 的**坐标系统**和**方框样式**。

### 5.1 `dev_disp_text`（HDevelop 推荐，自动用当前窗口）

```
dev_disp_text ( : : String, CoordSystem, Row, Column, Color, GenParamName, GenParamValue : )
```

| 参数 | 含义 / 取值 |
| --- | --- |
| `String` | 字符串（元组）。元组每个元素一行；`'\n'` 换行；末尾换行被忽略 |
| `CoordSystem` | `'window'`（窗口坐标）或 `'image'`（图像坐标，缩放时跟着图像走） |
| `Row` | 行坐标，**或** `'top'`/`'center'`/`'bottom'`（仅 `window` 系） |
| `Column` | 列坐标，**或** `'left'`/`'center'`/`'right'`（仅 `window` 系） |
| `Color` | 文本颜色，可传元组循环使用 |
| `GenParamName/Value` | 控制文本框外观，见下 |

**九宫格定位**（CoordSystem='window' 时，Row/Column 可填组合）：

```
('top','left')    ('top','center')    ('top','right')
('center','left') ('center','center') ('center','right')
('bottom','left') ('bottom','center') ('bottom','right')
```

**通用参数（GenParamName）速查**：

| 名称 | 作用 | 默认 |
| --- | --- | --- |
| `'box'` | 是否带背景框 `'true'`/`'false'` | `'true'` |
| `'box_color'` | 框背景色（如 `'white'`、`'#aa00bba0'`，最后两位是 alpha） | `'#fce9d4'`（浅橙） |
| `'shadow'` | 是否带阴影 | `'true'`（box 无色 alpha 时） |
| `'shadow_color'` | 阴影色 | `'#f28d26'` |
| `'border_radius'` | 框圆角（0=直角） | `2` |
| `'box_padding'` | 框四周留白像素 | `0` |
| `'shadow_sigma'` | 阴影模糊量（0=锐利） | `1.5` |
| `'shadow_dx'`,`'shadow_dy'` | 阴影偏移 | `2` |

**示例**：

```halcon
dev_open_window (0, 0, 512, 512, 'black', WindowHandle)
* 窗口左上角写一行带框文字
dev_disp_text ('Display some text in a box', 'window', 12, 12, 'black', [], [])
* 图像中心写红字、无框
dev_disp_text ('圆心', 'image', Row, Column, 'red', 'box', 'false')
* 右下角多行文字
dev_disp_text (['行1','行2'], 'window', 'bottom', 'right', 'yellow', [], [])
```

### 5.2 `disp_text`（纯算子版，需传窗口句柄）

```
disp_text ( : : WindowHandle, String, CoordSystem, Row, Column, Color, GenParamName, GenParamValue : )
```

与 `dev_disp_text` **参数完全相同**，只是第一个参数是 `WindowHandle`。`dev_disp_text` 内部就是调用它并填当前窗口。

### 5.3 字体与测量

```
set_font ( : : WindowHandle, Font : )          // 设字体，如 '-Courier-Bold-20'
get_string_extents ( : : WindowHandle, Values : Ascent, Descent, Width, Height)
```

- `get_string_extents`：用当前窗口字体量出字符串的宽高（像素），用于在画标注框时**自适应大小**，避免框比字小。
- `write_string`：旧式文本输出（基于光标位置 `set_tposition`），仍可用但功能弱于 `disp_text`。
- ⚠️ `set_display_font` **不是核心算子**，它是 HDevelop 自带的过程（procedure），本质是对 `set_font` 的封装；写导出代码时会被展开成 `set_font`。

## 6. 几何图形叠加显示（`disp_*`：程序画，不交互）

这些是把一个**已知形状**画到窗口上做标注，参数由你给定，**不是**让用户画。

| 算子 | 签名（简化） | 画什么 |
| --- | --- | --- |
| `disp_circle` | `( : : WH, Row, Column, Radius : )` | 圆（轮廓） |
| `disp_ellipse` | `( : : WH, CenterRow, CenterCol, Phi, Radius1, Radius2 : )` | 椭圆（Phi=旋转角） |
| `disp_rectangle1` | `( : : WH, Row1, Col1, Row2, Col2 : )` | 轴对齐矩形（两角点） |
| `disp_rectangle2` | `( : : WH, CenterRow, CenterCol, Phi, Length1, Length2 : )` | 任意朝向矩形（中心+角+半边长） |
| `disp_line` | `( : : WH, Row1, Col1, Row2, Col2 : )` | 线段 |
| `disp_arrow` | `( : : WH, Row1, Col1, Row2, Col2, Size : )` | 带箭头的线（Size=箭头大小） |
| `disp_cross` | `( : : WH, Row, Column, Size, Angle : )` | 十字标记 |
| `disp_region` | `(DispRegions : : WH : )` | 显示一个区域（受 draw/color 影响） |
| `disp_xld` | `(XLDObject : : WH : )` | 显示 XLD 轮廓 |

> **`disp_cross`（仅显示）vs `gen_cross_contour_xld`（生成对象）**：前者直接画到窗口；后者**返回一个 XLD 轮廓对象**，可后续保存、拟合、参与测量。要"既能显示又能拿去运算"就用后者。

**示例：检测后画圆标注圆心**

```halcon
dev_display (Image)
dev_set_color ('green')
dev_set_draw ('margin')
dev_set_line_width (2)
disp_circle (WindowHandle, CircleRow, CircleCol, CircleRadius)
dev_disp_text ('半径=' + CircleRadius$'.2f', 'image', CircleRow, CircleCol, 'yellow', 'box', 'false')
```

## 7. 交互式绘制（`draw_*`：让用户画，返回参数）

`draw_*` 会**暂停程序**，等用户在窗口上拖动鼠标画一个形状，松开后返回该形状的**参数**（注意：返回的是数字，**不是对象**）。常用于人工取 ROI、标定。

| 算子 | 返回（输出参数） | 用户画 |
| --- | --- | --- |
| `draw_circle` | `Row, Column, Radius` | 圆 |
| `draw_ellipse` | `Row, Column, Phi, Radius1, Radius2` | 椭圆 |
| `draw_rectangle1` | `Row1, Column1, Row2, Column2` | 轴对齐矩形 |
| `draw_rectangle2` | `Row, Column, Phi, Length1, Length2` | 任意朝向矩形 |
| `draw_line` | `Row1, Column1, Row2, Column2` | 线段 |
| `draw_point` | `Row, Column` | 一个点 |
| `draw_xld` | `ContOut`（XLD 对象） | 自由手绘轮廓（可旋转/缩放/移动） |
| `draw_region` | `Region` | 自由涂抹区域 |
| `draw_polygon` | `PolygonRegion` | 多边形 |

**`*_mod` 变体**（如 `draw_rectangle1_mod`）：模态绘制，适合在循环里反复让用户改 ROI。

> **`draw_*` 与 `disp_*` 的根本区别**：
> - `draw_circle`：用户画 → 你拿到 `Radius` 等数字（还要自己 `gen_circle` 才能变成对象）。
> - `disp_circle`：你已经知道半径 → 直接画到屏幕（不产生任何数据）。
> - 想要"用户画完直接得到一个 Region 对象"？用 `draw_region` / `draw_xld`（它们直接返回对象），或 `draw_circle` 后接 `gen_circle(Row,Column,Radius)`。

**示例：交互取 ROI 再生成区域**

```halcon
dev_open_window (0, 0, 640, 480, 'black', WindowHandle)
draw_rectangle1 (WindowHandle, Row1, Column1, Row2, Column2)
gen_rectangle1 (ROI, Row1, Column1, Row2, Column2)   * 把数字变成可用 Region
reduce_domain (Image, ROI, ImageReduced)
```

## 8. 把图形画进图像（`paint_*`：像素级写入）

`disp_*` 只是显示；`paint_*` 是**把图形真正写进图像矩阵**，结果是一个新图像，可保存、可再处理。

```
paint_region (Region, Image : ImageResult : Grayval, Type : )
paint_gray (ImageSource, ImageDestination : MixedImage : : )
```

- `paint_region`：用**恒定灰度值** `Grayval` 把 `Region` 涂进 `Image`，输出 `ImageResult`。`Type` 控制是否按区域分别给灰度（`'byte'`/`'int2'` 等决定输出类型）。
- `paint_gray`：把 `ImageSource` 的内容"贴"到 `ImageDestination` 上（按 Source 的域），常用于把一张小图合成进大图。

> **什么时候用 paint 而不是 disp**：需要把标注/掩膜**永久固化到图像里**（例如生成训练标签图、合成测试图、导出带框的图片文件）时用 `paint_region`；只为了在屏幕上看一眼就用 `disp_region`。

## 9. 显示刷新开关：`dev_update_*`

有时你会遇到"程序跑完了，窗口却没更新"或"变量窗口不刷新" —— 多半是更新开关被关了。

| 算子 | 控制 |
| --- | --- |
| `dev_update_window ('on'/'off')` | 是否每步都刷新图形窗口 |
| `dev_update_var ('on'/'off')` | 是否刷新变量窗口 |
| `dev_update_pc ('on'/'off')` | 是否高亮当前程序行 |
| `dev_update_time ('on'/'off')` | 是否显示算子耗时 |

- **循环里关掉 `dev_update_window('off')`** 能显著提速（避免每帧重绘），循环结束再 `'on'` 并 `dev_display` 最后一次结果。
- **注意**：关掉更新后，你调用的 `disp_*` 结果可能看不到，直到重新开启或显式刷新。

## 10. 完整实战示例（HDevelop）

```halcon
* 1) 开窗口
dev_open_window (0, 0, 800, 600, 'black', WindowHandle)
dev_set_draw ('margin')
dev_set_line_width (2)

* 2) 读图并显示
read_image (Image, 'pcb')
dev_display (Image)

* 3) 交互让用户框选 ROI
draw_rectangle2 (WindowHandle, Row, Column, Phi, Length1, Length2)
gen_rectangle2 (ROI, Row, Column, Phi, Length1, Length2)
reduce_domain (Image, ROI, ImageReduced)

* 4) 阈值 + 连通域，找最大区域
threshold (ImageReduced, Region, 100, 255)
connection (Region, ConnectedRegions)
select_shape_std (ConnectedRegions, RegionMax, 'max_area', 70)

* 5) 拟合圆并标注
smallest_circle (RegionMax, CirRow, CirCol, CirRadius)
dev_set_color ('green')
disp_circle (WindowHandle, CirRow, CirCol, CirRadius)

* 6) 文字标注（带框、红字）
dev_disp_text ('最大区域半径 = ' + CirRadius$' .2f', 'image', CirRow, CirCol, \
               'red', 'box_color', '#ffffffcc')

* 7) 把结果圆永久画进图像并保存
gen_circle (CircleObj, CirRow, CirCol, CirRadius)
paint_region (CircleObj, Image, ImageMarked, 255, 'byte')
write_image (ImageMarked, 'png', 0, 'result_marked')
```

## 11. 常见误区（10 条）

1. ❌ 用 `disp_circle` 后想拿圆心去测量 → ✅ `disp_*` 不产生对象，要测量先用 `draw_circle`/`smallest_circle` 等拿到参数或对象。
2. ❌ 改了 `dev_set_color('red')` 但图形还是黑/绿 → ✅ 设置必须写在**显示算子之前**；且 `dev_set_colored` 会覆盖单色设置。
3. ❌ `dev_set_draw('margin')` 后区域看不见 → ✅ margin 只画轮廓，线宽 `dev_set_line_width` 太小（如 1）在放大时几乎看不见；或区域本身为空。
4. ❌ `draw_circle` 返回的不是 Region → ✅ 它只返回 `Row,Column,Radius` 三个数，需 `gen_circle` 转成对象。
5. ❌ `dev_disp_text` 坐标用图像坐标却显示错位 → ✅ 默认 `CoordSystem='window'`（窗口像素）；要用图像坐标必须显式传 `'image'`。
6. ❌ 文本框太大挡住图 → ✅ 用 `GenParamName=['box','box_color'], Value=['false','white']` 关框或换色；`box_padding` 控制留白。
7. ❌ 循环里 `disp_*` 很卡 → ✅ 关 `dev_update_window('off')`，循环结束再显式 `dev_display` 一次。
8. ❌ 想把标注存进图片却发现只是显示 → ✅ 显示用 `disp_*`，固化进图像用 `paint_region`。
9. ❌ 窗口放大后图像模糊/只显示局部 → ✅ 检查 `dev_set_part`，`(0,0,-1,-1)` 才是整图；否则是按设定区域拉伸。
10. ❌ 导出 C++ 后 `dev_disp_text` 行为不同 → ✅ 官方文档明确：图形算子导出后行为可能与 HDevelop 略有差异，导出项目需用 `set_font` 等底层算子补齐。

│ 画图形(程序)     │ disp_circle / disp_ellipse /               │
│                  │ disp_rectangle1/2 / disp_line /            │
│                  │ disp_arrow / disp_cross / disp_xld         │
├──────────────────┼──────────────────────────────────────────┤
│ 交互画(返回参数) │ draw_circle / draw_ellipse /               │
│                  │ draw_rectangle1/2 / draw_line /           │
│                  │ draw_xld / draw_region / draw_polygon      │
├──────────────────┼──────────────────────────────────────────┤
│ 画进图像(像素)   │ paint_region / paint_gray                  │
├──────────────────┼──────────────────────────────────────────┤
│ 刷新开关         │ dev_update_window / _var / _pc / _time     │
└──────────────────┴──────────────────────────────────────────┘

记忆口诀：
  显示=屏幕(disp_/dev_display/dev_disp_text)
  交互=鼠标给数字(draw_*)
  绘图=进图像(paint_*)
