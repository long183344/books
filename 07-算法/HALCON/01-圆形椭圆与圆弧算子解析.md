# HALCON 圆形、椭圆与圆弧算子解析

> **一句话结论**：HALCON 里的"圆"分 **Region（填充区域）**、**XLD Contour（亚像素轮廓）**、**几何参数（标量）** 三个层面；**圆弧没有独立算子**，由 `gen_circle_contour_xld` / `fit_circle_contour_xld` 的 `StartPhi/EndPhi/PointOrder` 和 `gen_measure_arc`（圆弧 1D 测量）来表达。
> **数据基准**：2026-08（HALCON 25.11 参考文档）｜ **难度**：进阶 ｜ **前置**：了解 HALCON 的 Region 与 XLD 数据类型

---

## 1. 为什么要搞懂这些算子

圆形测量是机器视觉里最高频的任务之一：轴承外径、瓶口圆度、PCB 焊盘定位、齿轮齿距、零件倒角……都绕不开"找到圆 / 拟合圆 / 沿弧量边"。

但 HALCON 的"圆"不是一个概念，而是**三种数据形态 + 一套拟合流程**。搞不清就会：

- 用 `gen_circle` 想得到边缘 → 拿到的是**填充区域**，不是边缘轮廓
- 用 `fit_circle_contour_xld` 不看 `StartPhi/EndPhi` → 不知道拟合结果其实是**弧**不是整圆
- 把 `elliptic_axis` 当成"检测圆" → 它只是把**任意区域**算出"等效椭圆"的长短轴，不是检测
- 想沿圆弧测边却用 `gen_measure_rectangle2` → ROI 是直的，曲边缘测不准

这篇把圆/椭圆/圆弧的算子**按层面理清**，每个重点算子给出签名、参数解释、用法和坑。

---

## 2. 三个层面的"圆"——必须先分清

| 层面 | 数据类型 | 是否含面积 | 精度 | 代表算子 | 典型用途 |
| --- | --- | --- | --- | --- | --- |
| **Region（区域）** | 像素填充 | 是（有面积） | 像素级 | `gen_circle`、`smallest_circle`、`opening_circle` | 掩膜、形态学、粗筛 |
| **XLD Contour（轮廓）** | 亚像素折线 | 否（线框） | 亚像素（0.01 px 级） | `gen_circle_contour_xld`、`fit_circle_contour_xld` | 精确测量、参数拟合 |
| **几何参数（标量）** | Row/Col/Radius/Phi | — | 纯数学 | `Row, Column, Radius, StartPhi, EndPhi, PointOrder` | 结果输出、判定、叠加 |

**三条铁律**：

1. **Region 是"实心"的，XLD 是"线框"的**。`gen_circle` 给你一片区域；`gen_circle_contour_xld` 给你一条轮廓线。要亚像素测量必须走 XLD。
2. **圆弧 = 圆轮廓的子集**，由 `StartPhi/EndPhi` 切出来。整圆 = `StartPhi=0, EndPhi=2π`。
3. **`PointOrder` 决定方向**：`'positive'` 逆时针（数学正方向）、`'negative'` 顺时针。拟合结果带方向，生成时也要给方向。

## 3. 算子分类总表

### 3.1 Region（区域）层面

| 算子 | 作用 | 输入 → 输出 |
| --- | --- | --- |
| `gen_circle` | 生成填充圆形区域 | Row, Col, Radius → Region |
| `gen_ellipse` | 生成填充椭圆区域 | Center, Phi, R1, R2 → Region |
| `smallest_circle` | 求区域的最小外接圆 | Region → Row, Col, Radius |
| `inner_circle` | 求区域的最大内切圆 | Region → Row, Col, Radius |
| `elliptic_axis` | 算区域的等效椭圆长短轴 | Region → Ra, Rb, Phi |
| `opening_circle` | 圆形结构元素开运算（去毛刺） | Region, Radius → Region |
| `closing_circle` | 圆形结构元素闭运算（填小洞） | Region, Radius → Region |
| `select_shape` | 按圆度等形状特征筛选区域 | Region, Features → Region |

### 3.2 XLD Contour（轮廓）层面

| 算子 | 作用 | 输入 → 输出 |
| --- | --- | --- |
| `gen_circle_contour_xld` | 生成圆/圆弧轮廓 | Row, Col, Radius, StartPhi, EndPhi, PointOrder, Resolution → Contour |
| `gen_ellipse_contour_xld` | 生成椭圆/椭圆弧轮廓 | Row, Col, Phi, R1, R2, StartPhi, EndPhi, PointOrder, Resolution → Contour |
| `fit_circle_contour_xld` | 把轮廓拟合为圆/弧 | Contour, Algorithm, … → Row, Col, Radius, StartPhi, EndPhi, PointOrder |
| `fit_ellipse_contour_xld` | 把轮廓拟合为椭圆/弧 | Contour, Algorithm, … → Row, Col, Phi, R1, R2, StartPhi, EndPhi, PointOrder |
| `segment_contours_xld` | 把轮廓切成直线/圆弧段 | Contour, Mode → Contours |
| `select_contours_xld` | 按长度/闭合度等筛选轮廓 | Contour, Feature → Contour |

### 3.3 1D 测量层面（圆弧专用）

| 算子 | 作用 | 输入 → 输出 |
| --- | --- | --- |
| `gen_measure_arc` | 预生成环形弧测量对象 | Center, Radius, AngleStart, AngleExtent, AnnulusRadius, … → MeasureHandle |
| `measure_pos` | 沿测量对象提取单个边缘点 | Image, Handle, Sigma, Threshold → RowEdge, ColEdge, Amplitude, Distance |
| `measure_pairs` | 沿测量对象提取成对边缘 | Image, Handle, Sigma, Threshold → EdgeFirst, EdgeSecond, 距离 |

### 3.4 间接支持算子（产生圆的源头）

| 算子 | 作用 | 在圆流程里的角色 |
| --- | --- | --- |
| `edges_sub_pix` | 亚像素边缘提取 | 产生待拟合的 XLD 轮廓（拟合前必备） |
| `threshold` / `connection` | 二值化 + 连通域 | 产生待筛选的 Region（Region 路线必备） |
| `hough_circle_trans` | 霍夫圆变换 | 噪声大、边缘断裂时的圆检测 |
| `area_center` | 算区域面积和质心 | 取圆心初值 |

## 4. 重点算子详解

每个算子给：**签名 → 是什么 → 关键参数 → 怎么用 → 坑**。

### 4.1 gen_circle

```
gen_circle(Region, Row, Column, Radius)
```

**是什么**：生成一个**填充**的圆形区域（Region）。`Radius` 是浮点，但输出区域是离散像素，内部按像素点填充。

**怎么用**：
- 做掩膜：限制后续 `reduce_domain` / `intersection` 的处理范围
- 做结构元素：配 `opening_circle` / `closing_circle`
- 粗筛：给 `select_shape` 当候选

**坑**：
- 想要"圆的边缘"用这个 → 拿到的是**实心圆盘**，没有边缘轮廓。要边缘走 `gen_circle_contour_xld`。
- `Radius` 太小（<2 px）→ 离散化后变成方块，不像圆。

### 4.2 gen_ellipse

```
gen_ellipse(Region, CenterRow, CenterCol, Phi, Radius1, Radius2)
```

**是什么**：生成**填充**椭圆区域。`Phi` 是长轴方向（弧度，0=水平向右），`Radius1`/`Radius2` 是长短半轴。

**坑**：
- `Phi` 用**弧度**不用度。HALCON 角度统一是弧度；要度数用 `rad(度)` 转换，或带 `_deg` 后缀的算子（如 `angle_ll_deg`）。
- `Radius1` 是**较大的**半轴、`Radius2` 是较小的，顺序别搞反。

### 4.3 gen_circle_contour_xld

```
gen_circle_contour_xld(ContCircle, Row, Column, Radius, StartPhi, EndPhi, PointOrder, Resolution)
```

**是什么**：生成**圆或圆弧的 XLD 轮廓**（一条亚像素折线）。这是"画"一个圆/弧出来，不是检测。

**关键参数**：

| 参数 | 含义 | 取值 |
| --- | --- | --- |
| `Row, Column` | 圆心 | 浮点（像素坐标） |
| `Radius` | 半径 | 浮点，>0 |
| `StartPhi` | 起点角度 | 弧度，默认 0.0 |
| `EndPhi` | 终点角度 | 弧度，默认 6.28318（2π） |
| `PointOrder` | 方向 | `'positive'` 逆时针 / `'negative'` 顺时针 |
| `Resolution` | 相邻点间距 | 欧氏像素距离，默认 1.0，越小点越密 |

**整圆 vs 弧**：
- 整圆：`StartPhi=0, EndPhi=rad(360), PointOrder='positive'`
- 1/4 弧（0°→90°）：`StartPhi=0, EndPhi=rad(90), PointOrder='positive'`
- 任意弧段同理，靠 `StartPhi/EndPhi` 切

**怎么用**：把拟合结果可视化叠加、或生成标准弧去做比对。

**坑**：
- `EndPhi` 默认 6.28318 是 2π 的近似，想用度数就 `rad(360)`。
- `Resolution` 影响点密度，做显示 1.0 够，做高精度运算可设小（如 0.5）但更费时。

### 4.4 gen_ellipse_contour_xld

```
gen_ellipse_contour_xld(ContEllipse, Row, Column, Phi, Radius1, Radius2, StartPhi, EndPhi, PointOrder, Resolution)
```

**是什么**：生成**椭圆或椭圆弧**的 XLD 轮廓。比圆多一个 `Phi`（主轴方向）。

**关键参数**：

| 参数 | 含义 |
| --- | --- |
| `Phi` | 主轴方向 [弧度]，从正 x 轴起，逆时针为正 |
| `Radius1` | 较大半轴 |
| `Radius2` | 较小半轴 |
| `StartPhi, EndPhi` | 相对**主轴**的起止角，映射到 [0, 2π) |

**椭圆弧的角度参照系**：`StartPhi/EndPhi` 是**相对主轴**的角度，不是相对 x 轴。主极点对应 0 和 π，副极点对应 π/2 和 3π/2。整椭圆：`StartPhi=0, EndPhi=2π, PointOrder='positive'`。

**坑**：椭圆弧的起止角和圆弧的"看起来一样"但参照系不同——圆弧相对 x 轴，椭圆弧相对自身主轴。混用会偏一个 `Phi`。

### 4.5 fit_circle_contour_xld（核心测量算子）

```
fit_circle_contour_xld(Contours, Algorithm, MaxNumPoints, MaxClosureDist,
                        ClippingEndPoints, Iterations, ClippingFactor,
                        Row, Column, Radius, StartPhi, EndPhi, PointOrder)
```

**是什么**：把输入 XLD 轮廓拟合成**圆或圆弧**，返回圆心、半径、弧的起止角和方向。**这是圆形测量的事实主力**——先用 `edges_sub_pix` 提边缘，再用它拟合。

> ⚠️ 它**不做分割**：输入的每条轮廓必须只对应一个圆。一条轮廓里混了直线和圆，要先 `segment_contours_xld` 切开。

**Algorithm 选择**（决定距离度量 + 鲁棒加权）：

| 值 | 距离度量 | 鲁棒加权 | Iterations 生效？ | 适用 |
| --- | --- | --- | --- | --- |
| `'algebraic'` | 代数距离 | 无 | ✅ | 最快，噪声小 |
| `'ahuber'` | 代数 | Huber（降权离群点） | ✅ | 有离群点 |
| `'atukey'` | 代数 | Tukey（剔除离群点） | ✅ | 离群点多，**代数系推荐** |
| `'geometric'` | 几何距离（点到圆心） | 无 | ❌（忽略） | 统计最优，噪声大，慢 |
| `'geohuber'` | 几何 | Huber | ❌ | 噪声大 + 离群点 |
| `'geotukey'` | 几何 | Tukey | ❌ | 噪声大 + 离群点，**最鲁棒** |

- **代数 vs 几何**：代数最小化 `|x²+y²+Dx+Ey+F|`，快但偏；几何最小化"点到圆周的距离"，统计最优但需迭代、慢。噪声大用几何。
- **Huber vs Tukey**：Huber 只**降权**离群点（仍参与），Tukey 直接**剔除**。实践推荐 Tukey。
- `ClippingFactor`：标准差缩放因子，越小剔的离群点越多，默认 2.0。
- `Iterations`：只对 `algebraic/ahuber/atukey` 生效；几何系内部已迭代，传 0 即只检查初值。

**其他参数**：

| 参数 | 含义 | 经验值 |
| --- | --- | --- |
| `MaxNumPoints` | 拟合最多取多少点（均匀采样） | -1=全部；点太多时可限速 |
| `MaxClosureDist` | 起末点距离 ≤ 此值 → 视为**闭合整圆**，否则弧 | 0 或小值强制按弧拟 |
| `ClippingEndPoints` | 首末各丢几个点（去端点伪影） | 端点不稳时设 2~5 |
| `Iterations` | 鲁棒加权迭代次数 | 5~10 |
| `ClippingFactor` | 离群点剔除系数 | 2.0（默认） |

**输出**：`Row, Column, Radius`（圆参数）+ `StartPhi, EndPhi, PointOrder`（弧信息）。整圆时 `StartPhi=0, EndPhi=2π`。

**怎么用**（典型流程）：
```halcon
read_image(Image, 'part.png')
* 1. 提亚像素边缘
edges_sub_pix(Image, Edges, 'canny', 1.5, 20, 40)
* 2. 按长度筛掉碎片
select_contours_xld(Edges, CircContours, 'contour_length', 50, 99999, -0.5, 0.5)
* 3. 把每条轮廓拟合成圆
fit_circle_contour_xld(CircContours, 'atukey', -1, 2, 3, 5, 2,
                        Row, Col, Radius, StartPhi, EndPhi, Order)
* 4. 可视化拟合结果
gen_circle_contour_xld(Cont, Row, Col, Radius, 0, rad(360), 'positive', 1.0)
```

**坑**：
- 不先筛长度 → 一条小毛刺被拟合成一个巨大的圆（3 点就能定圆）。
- 轮廓里混了直线和圆弧 → 拟合歪。先 `segment_contours_xld(Contours, Split, 'lines_circles', ...)` 切。
- 想要整圆结果但 `MaxClosureDist` 设太大 → 断了的弧被当整圆，半径偏。

### 4.6 fit_ellipse_contour_xld

```
fit_ellipse_contour_xld(Contours, Algorithm, MaxNumPoints, MaxClosureDist,
                          ClippingEndPoints, VossTabSize, Iterations, ClippingFactor,
                          Row, Column, Phi, Radius1, Radius2, StartPhi, EndPhi, PointOrder)
```

**是什么**：把轮廓拟合为**椭圆或椭圆弧**。比圆多返回 `Phi`（主轴方向）和 `Radius1/Radius2`（长短半轴）。

**Algorithm 选择**（命名和圆不同！椭圆用 `f*` 前缀）：

| 值 | 距离度量 | 鲁棒加权 |
| --- | --- | --- |
| `'fitzgibbon'` | 代数距离（Fitzgibbon 法，约束 `4ac-b²=1` 保证是椭圆不是双曲线） | 无 |
| `'fhuber'` | 代数 | Huber |
| `'ftukey'` | 代数 | Tukey |
| `'geometric'` | 几何距离 | 无 |
| `'geohuber'` | 几何 | Huber |
| `'geotukey'` | 几何 | Tukey |

**与圆拟合的差异**：
- 圆用 `'algebraic'`，椭圆用 `'fitzgibbon'`——代数法对椭圆要加约束才能保证拟合出的是椭圆（否则可能退化成双曲线/抛物线）。
- 椭圆多一个 `VossTabSize`（Voss 方法的查表尺寸，用于几何距离计算的加速，通常传默认值如 3~10）。
- 输出 `Phi` 是主轴方向，`Radius1`≥`Radius2`。

**整椭圆判定**：`MaxClosureDist` 同理；闭合时输出 `StartPhi=0, EndPhi=2π, PointOrder='positive'`。

**坑**：
- 把 `fit_circle` 的 Algorithm 值（`'algebraic'`）直接套给 `fit_ellipse` → 报错或退化。椭圆必须用 `'fitzgibbon'` 系。
- 椭圆拟合对**部分弧**更敏感：弧太短（<90°）时椭圆参数不定，长轴方向会乱跳。圆弧只要 ≥3 点就稳。

### 4.7 gen_measure_arc（圆弧 1D 测量）

```
gen_measure_arc(CenterRow, CenterCol, Radius, AngleStart, AngleExtent,
                  AnnulusRadius, Width, Height, Interpolation, MeasureHandle)
```

**是什么**：预生成一个**环形弧测量对象**（annular arc = 圆弧 + 关联宽度），后续用 `measure_pos` / `measure_pairs` 沿这条弧提取**垂直于弧的直边**。适合圆形零件的边缘间距、环形槽宽检测。

**关键参数**：

| 参数 | 含义 | 取值 |
| --- | --- | --- |
| `CenterRow, CenterCol` | 弧的圆心 | 浮点（内部会取整到像素格） |
| `Radius` | 弧的半径 | 像素 |
| `AngleStart` | 起始角 | 弧度 |
| `AngleExtent` | 角度跨度（相对起始角） | 弧度；>0 逆时针、<0 顺时针 |
| `AnnulusRadius` | 环的**半宽** | 像素；ROI 总宽 = 2×AnnulusRadius |
| `Width, Height` | 待测图像的尺寸 | 必须与实际图像一致 |
| `Interpolation` | 灰度插值 | `'nearest_neighbor'` / `'bilinear'` / `'bicubic'` |
| `MeasureHandle` | 输出句柄 | 传给 measure_pos/measure_pairs |

**怎么用**（官方 Solution Guide 范例——测铸件长孔间距）：
```halcon
Row := 275
Column := 335
Radius := 107
AngleStart := -rad(55)
AngleExtent := rad(170)
gen_measure_arc(Row, Column, Radius, AngleStart, AngleExtent, 10,
                Width, Height, 'nearest_neighbor', MeasureHandle)
measure_pos(Image, MeasureHandle, 1, 10, 'all', 'all',
            RowEdge, ColumnEdge, Amplitude, Distance)
```

**坑**：
- `AnnulusRadius` 是**半宽**不是全宽。ROI 总宽 = 2×AnnulusRadius。
- `Width/Height` 必须和待测图一致，否则句柄建了也对不上图。
- bilinear/bicubic 插值时，ROI 外还要留 1~2 像素余量，否则边缘处的投影线取不到灰度。
- **不要用圆弧测量对象去量曲边缘**：measure 对象设计用于**近似垂直于投影线的直边**。边缘弯曲时，测到的位置不是边缘与投影线交点，会偏。曲边缘用 `edges_sub_pix` + `fit_circle_contour_xld`。
- 用完 `close_measure(MeasureHandle)` 释放句柄。

### 4.8 smallest_circle / inner_circle

```
smallest_circle(Region, Row, Column, Radius)   * 最小外接圆
inner_circle(Region, Row, Column, Radius)       * 最大内切圆
```

**是什么**：对任意 Region 算它的最小包围圆 / 最大内切圆。用于快速估算半径、或做卡规/容差判定。

**区别**：
- `smallest_circle`：圆把整个区域**包住**（圆心不一定在区域内）。
- `inner_circle`：圆在区域**内部**（最大可放下的圆，圆心是"离边界最远的点"）。

**坑**：这俩基于像素 Region，精度是像素级。要亚像素精度还是得走 XLD 拟合。

### 4.9 elliptic_axis

```
elliptic_axis(Regions, Ra, Rb, Phi)
```

**是什么**：对任意 Region，基于其二阶矩算出"等效椭圆"的长半轴 `Ra`、短半轴 `Rb`、主轴方向 `Phi`。**不是检测椭圆**，而是描述形状的"方向和胖瘦"。

**怎么用**：算区域朝向（旋转角）、长宽比筛选。常配 `select_shape` 的 `ratio` 特征。

**坑**：别把它当"椭圆检测"。一个香蕉形区域也能算出等效椭圆轴，但它不是椭圆。要真椭圆检测走 `edges_sub_pix` + `fit_ellipse_contour_xld`。

### 4.10 opening_circle / closing_circle

```
opening_circle(Region, RegionOpening, Radius)
closing_circle(Region, RegionClosing, Radius)
```

**是什么**：用圆形结构元素做形态学开/闭运算。
- `opening_circle`：先腐蚀后膨胀 → 去掉**比圆小的毛刺/突起**。
- `closing_circle`：先膨胀后腐蚀 → 填掉**比圆小的小洞/缺口**。

**怎么用**：二值化后去噪。`Radius` 是结构元素半径，比要去的毛刺大、比要保的物体小。

**坑**：`Radius` 太大会把物体本身"啃掉"。从 1 起调，看到形状开始变就停。

### 4.11 hough_circle_trans

```
hough_circle_trans(Edges, HoughImage, Region, ...)
```

**是什么**：霍夫圆变换——对一组边缘点，在参数空间（圆心 a,b + 半径 r）累加投票，峰值处即圆。适合**边缘断裂、噪声大、不确定半径**的场景。

**与 `fit_circle_contour_xld` 的分工**：

| 维度 | `fit_circle_contour_xld` | `hough_circle_trans` |
| --- | --- | --- |
| 前提 | 已知哪条轮廓是圆 | 只有点，不知分组 |
| 精度 | 亚像素 | 像素级（要 refine） |
| 速度 | 快 | 慢（3D 累加） |
| 适用 | 干净边缘、单圆 | 多圆、断裂、噪声 |

**坑**：霍夫圆对半径范围敏感，先估半径区间再投票，否则参数空间爆炸又慢。

### 4.12 segment_contours_xld（拟合前的必备预处理）

```
segment_contours_xld(Contours, ContoursSplit, Mode, SmoothCont, MaxLineDist1, MaxLineDist2)
```

**是什么**：把一条混合轮廓切成**直线段和圆弧段**。`Mode` 选 `'lines_circles'` 表示切出直线和圆。

**为什么重要**：`fit_circle_contour_xld` 要求输入轮廓**只含一个圆**。实际边缘常是"直线+圆弧+直线"（比如带圆角的矩形），不切就直接拟合 → 圆心、半径全歪。

**怎么用**：拟合前先 `segment_contours_xld(..., 'lines_circles', ...)`，再 `select_contours_xld` 挑圆弧段，最后 `fit_circle_contour_xld`。

## 5. 实战示例

### 5.1 完整流程：检测并拟合一个圆

```halcon
* === 检测零件外圆并拟合 ===
read_image(Image, 'bearing.png')

* 1. 提亚像素边缘（canny）
edges_sub_pix(Image, Edges, 'canny', 1.5, 20, 40)

* 2. 按长度筛掉碎片（假设目标圆轮廓 >100 px）
select_contours_xld(Edges, LongContours, 'contour_length', 100, 99999, -0.5, 0.5)

* 3. 切分混合轮廓（防直线混入）
segment_contours_xld(LongContours, SplitContours, 'lines_circles', 5, 4, 2)

* 4. 只挑圆弧段
select_contours_xld(SplitContours, ArcContours, 'contour_length', 30, 99999, -0.5, 0.5)

* 5. 拟合圆（Tukey 鲁棒，防离群点）
fit_circle_contour_xld(ArcContours, 'atukey', -1, 2, 3, 5, 2,
                        Row, Col, Radius, StartPhi, EndPhi, PointOrder)

* 6. 判断是整圆还是弧
if (EndPhi - StartPhi > rad(350))
    * 整圆
    gen_circle_contour_xld(ResultContour, Row, Col, Radius, 0, rad(360), 'positive', 1.0)
    dev_disp_text('整圆, 半径=' + Radius + ' px')
else
    * 弧，按拟合方向生成
    gen_circle_contour_xld(ResultContour, Row, Col, Radius, StartPhi, EndPhi, PointOrder, 1.0)
    dev_disp_text('圆弧, 跨度=' + deg(EndPhi-StartPhi) + '°')
endif

dev_display(Image)
dev_display(ResultContour)
```

### 5.2 圆弧 1D 测量（量环形槽宽）

```halcon
* === 沿圆弧测一对边的间距 ===
get_image_size(Image, Width, Height)

* 圆心放零件中心，弧覆盖槽所在角度
gen_measure_arc(280, 320, 110, -rad(30), rad(60), 8,
                Width, Height, 'bilinear', Handle)

* 提成对边（槽的内外壁）
measure_pairs(Image, Handle, 1, 10, 'all', 'all',
              RowE1, ColE1, Amp1, RowE2, ColE2, Amp2,
              RowMid, ColMid, FuzzyScore, IntraDist, InterDist)

* IntraDist = 每对边的间距（槽宽）
close_measure(Handle)
```

### 5.3 椭圆拟合（倾斜视角下的圆）

```halcon
* 透视/倾斜下，圆在像面投影成椭圆——拟合椭圆再反推圆心
edges_sub_pix(Image, Edges, 'canny', 1.5, 20, 40)
select_contours_xld(Edges, LongContours, 'contour_length', 100, 99999, -0.5, 0.5)
fit_ellipse_contour_xld(LongContours, 'ftukey', -1, 2, 3, 6, 5, 2,
                         Row, Col, Phi, R1, R2, StartPhi, EndPhi, Order)
gen_ellipse_contour_xld(ResultContour, Row, Col, Phi, R1, R2, 0, rad(360), 'positive', 1.0)
```

## 6. 常见误区与坑

- ❌ 用 `gen_circle` 拿边缘 → ✅ 它给填充区域；要边缘轮廓用 `gen_circle_contour_xld`。
- ❌ `fit_circle_contour_xld` 直接吃混合轮廓 → ✅ 先 `segment_contours_xld` 切成单圆段再拟合，否则圆心/半径全歪。
- ❌ 把 `elliptic_axis` 当椭圆检测 → ✅ 它只算区域的等效椭圆轴（方向+胖瘦），任意形状都能算，不代表区域是椭圆。
- ❌ 用圆弧测量对象（`gen_measure_arc`）量弯曲边缘 → ✅ measure 对象只适合**近似垂直投影线的直边**；曲边缘走 `edges_sub_pix`+`fit_*_contour_xld`。
- ❌ 圆和椭圆的 Algorithm 值混用 → ✅ 圆用 `'algebraic'/'ahuber'/'atukey'/'geometric'/'geohuber'/'geotukey'`；椭圆用 `'fitzgibbon'/'fhuber'/'ftukey'/'geometric'/'geohuber'/'geotukey'`，前缀不同。
- ❌ 不看 `StartPhi/EndPhi` 就当整圆用 → ✅ 拟合返回弧信息；`EndPhi-StartPhi` 接近 2π 才是整圆，否则是弧。
- ❌ `AnnulusRadius` 当全宽 → ✅ 它是**半宽**，ROI 总宽 = 2×AnnulusRadius。
- ❌ 椭圆弧太短还硬拟 → ✅ 弧 <90° 时椭圆长轴方向不定，结果乱跳；要么补全弧段，要么改用圆拟合。
- ❌ 角度用度数传参 → ✅ HALCON 角度统一弧度；要度数 `rad(度)` 转换，或用带 `_deg` 的算子。
- ❌ `MaxClosureDist` 设太大 → ✅ 断弧被当整圆，半径偏；要强制按弧拟把它设小（如 0）。

## 7. 算子速查卡

```
┌─ Region 层（像素填充，有面积）──────────────────────┐
│ gen_circle(Row,Col,Radius)        画填充圆               │
│ gen_ellipse(Center,Phi,R1,R2)     画填充椭圆             │
│ smallest_circle(Region)→R,C,Rad   最小外接圆             │
│ inner_circle(Region)→R,C,Rad      最大内切圆             │
│ elliptic_axis(Region)→Ra,Rb,Phi   等效椭圆轴             │
│ opening_circle(R,Radius)          去毛刺                 │
│ closing_circle(R,Radius)          填小洞                 │
│ select_shape(R,'circularity',…)   按圆度筛               │
└──────────────────────────────────────────────────────┘

┌─ XLD 层（亚像素轮廓，线框）─────────────────────────┐
│ gen_circle_contour_xld(R,C,Rad,Start,End,Order,Res)      │
│ gen_ellipse_contour_xld(R,C,Phi,R1,R2,Start,End,Order,Res)│
│ fit_circle_contour_xld(Cont,Algo,…)→R,C,Rad,Start,End,Order│
│ fit_ellipse_contour_xld(Cont,Algo,…)→R,C,Phi,R1,R2,…    │
│ segment_contours_xld(Cont,'lines_circles',…)  切线/弧    │
│ select_contours_xld(Cont,'contour_length',…) 筛长度     │
│ edges_sub_pix(Img,'canny',Low,High)   提边缘(前置)       │
│ hough_circle_trans(Edges,…)           霍夫圆(噪声大时)   │
└──────────────────────────────────────────────────────┘

┌─ 1D 测量层（圆弧专用）──────────────────────────────┐
│ gen_measure_arc(CR,CC,Rad,AStart,AExt,AnnR,W,H,Interp,Handle)│
│ measure_pos(Img,Handle,Sigma,Thresh,…)→边点+间距         │
│ measure_pairs(Img,Handle,Sigma,Thresh,…)→边对+间距      │
│ close_measure(Handle)              释放句柄             │
└──────────────────────────────────────────────────────┘
```

**Algorithm 速记**：
- 圆：`algebraic`（快）/`atukey`（代数+鲁棒）/`geometric`（最优）/`geotukey`（最鲁棒）
- 椭圆：`fitzgibbon`（代数）/`ftukey`（代数+鲁棒）/`geometric`/`geotukey`
- 命名规律：代数系圆用 `a*`、椭圆用 `f*`；几何系统一 `geo*`
