# 03 · 镜头与光源选型详解（成像三件套之"镜 + 光"）

> **本篇是「工业相机成像三件套」的收官篇**：
> - `01-工业相机详解` → 眼睛（传感器、触发、帧率、曝光、增益）
> - `02-曝光增益帧率与参数下发` → 眼睛的"动态参数"怎么调
> - **`03-镜头光源选型`（本篇）** → 眼镜（镜头）与灯光（光源）——**再好的相机，镜头选错、灯打歪了，拍出来也是糊的、对比度差的、测不准的**
>
> 一句话核心：**相机决定"能不能采到"，镜头决定"采得清不清、几何准不准"，光源决定"特征突不突出、噪不噪"。三件套必须一起算，单算任何一个都是耍流氓。**

## 0. 三件套的分工（先建立全局观）

```
┌─────────────────────────────────────────────────────────────┐
│                     机器视觉成像链                            │
├──────────┬──────────────────────────┬───────────────────────┤
│ 光源      │ 镜头                      │ 相机                  │
│ (Light)  │ (Lens)                   │ (Camera)             │
│          │                          │                      │
│ 把"想看   │ 把三维物体投影成二维像；  │ 把光信号变成数字；    │
│ 的特征"   │ 决定：视场、放大倍率、    │ 决定：分辨率、帧率、  │
│ 照亮/凸显 │ 清晰度、畸变、景深        │ 灵敏度、动态范围      │
│          │                          │                      │
│ ✅ 对比度 │ ✅ 几何精度（无畸变）     │ ✅ 像素精度（够细）   │
│ ✅ 信噪比 │ ✅ 边缘锐度              │ ✅ 稳定性（触发/帧率）│
└──────────┴──────────────────────────┴───────────────────────┘
        三者耦合：FOV 由镜头+相机共同定；亮度由光源+曝光+增益共同定
```

**常见误区**：买相机只看"分辨率 500 万"，不配镜头就不知道能看多大、看清多细；或者镜头选了却不匹配 sensor 靶面，结果四周黑角、有效分辨率砍半。**选型顺序应是：先定检测需求（视野/精度/节拍）→ 反推相机分辨率与镜头焦距 → 再定光源。** 本篇按这个顺序讲。

## 1. 镜头选型（Lens）

### 1.1 镜头的 6 个核心参数

| 参数 | 符号 | 含义 | 谁决定 | 你能改吗 |
| --- | --- | --- | --- | --- |
| 焦距 | f | 镜头光学中心到焦平面的距离，越长"看得越远、视野越小" | 镜头设计 | 换镜头（变焦/定焦） |
| 视场 | FOV | 相机能拍到的实物范围（宽×高） | 镜头+WD+传感器 | 间接（调 WD 或换镜头） |
| 工作距离 | WD | 镜头前端到被测物的距离 | 你摆的位置 | ✅ 可调（有范围限制） |
| 靶面/成像圈 | — | 镜头能清晰覆盖的传感器最大尺寸 | 镜头设计 | 换镜头 |
| 光圈 | F# | 焦距/通光孔径，越小进光越多、景深越浅 | 镜头（可变） | ✅ 调环 |
| 分辨率 | — | 镜头能分辨的最小线对（lp/mm） | 镜头设计 | 换镜头 |

### 1.2 三个最关键的公式（必须会算）

设：传感器芯片在某一方向的物理尺寸 = `S`（mm），视野同一方向 = `FOV`（mm），工作距离 = `WD`（mm），焦距 = `f`（mm）。

**公式①：放大倍率**
```
β = S / FOV          （传感器成像尺寸 ÷ 实物尺寸）
```
例：1/2" 传感器宽 6.4mm，要看 64mm 宽的产品 → β = 0.1（即 10:1 缩小）。

**公式②：焦距（选镜头用这条反推）**
```
f = WD × S / FOV
```
例：WD=200mm，传感器宽 6.4mm，FOV 宽 64mm → f = 200×6.4/64 = 20mm。
→ 选一支 **25mm（标准档，向上取整比算出的 20 略大，视野会略小、更保险）** 或精确 20mm 的工业镜头。

**公式③：视场随工作距离（已知镜头后求能看多大）**
```
FOV = S × WD / f
```
> 注意：三条公式本质是同一个相似三角形关系，**WD、FOV、f 三者知道任意两个+传感器尺寸，就能算出第三个**。选型时通常是：需求给了 FOV 和 WD → 算 f → 选最接近的标准焦距（工业镜头标准档：8/12/16/25/35/50/75mm）。

### 1.3 靶面匹配（最容易翻车的坑）

镜头标注"支持 2/3" "支持 1" 指的是**成像圈直径能覆盖的传感器最大尺寸**。

| 传感器规格 | 典型宽×高（mm） | 对角线 |
| --- | --- | --- |
| 1/3" | 4.8 × 3.6 | 6.0 |
| 1/2" | 6.4 × 4.8 | 8.0 |
| 2/3" | 8.8 × 6.6 | 11.0 |
| 1" | 12.8 × 9.6 | 16.0 |

**铁律**：**镜头支持的靶面 ≥ 相机传感器靶面**，否则四个角会暗（暗角/黑角），且有效分辨率只剩中间一块。
> 例：相机是 1" 传感器（对角线 16mm），却配一支只支持 1/2" 的镜头 → 四角发黑，实际可用视场被裁掉一大圈，等于白买了高分辨率。

### 1.4 分辨率匹配（镜头锐度 vs 相机像元）

相机每个像元大小 = `p`（μm）。要"对得起"相机分辨率，镜头在 sensor 面上的**奈奎斯特极限分辨率**应满足：

```
镜头需分辨的线宽 ≥ 2 × p        （采样定理：至少 2 像素/线对，实战取 3~5 像素更稳）
```

换算成镜头需要的空间频率（lp/mm）：
```
所需 lp/mm ≈ 1000 / (2 × p)      （p 单位 μm；分母取 2p 是理论下限，取 3p~5p 更稳）
```
例：相机像元 3.45μm（如 IMX 系列 500 万）→ 理论需 1000/(2×3.45)≈145 lp/mm，稳妥取 ≥100 lp/mm 的"高清镜头"。
> 反过来：一支标称 100 lp/mm 的镜头，配 1.85μm 像元相机（需 270 lp/mm）就浪费了——镜头成了瓶颈。

### 1.5 景深（DOF）—— 能容忍多大的高度差

```
DOF ∝ (F# × p × 允许模糊圈) / β²
```
**直观结论**：
- **光圈越小（F# 越大）→ 景深越深**（前后都清楚），但进光少、要补光/加曝光；
- **放大倍率 β 越小（看大视野）→ 景深越深**；
- **像元 p 越小 → 同样模糊圈下景深显得更浅**（对清晰度更挑剔）。
> 实战：检测高低不平的零件（如带螺柱的板），要么用小光圈换景深，要么用**远心镜头**（见 1.7）。

### 1.6 畸变（Distortion）—— 几何精度的杀手

- **桶形畸变**：边缘向外鼓（广角/短焦常见）；
- **枕形畸变**：边缘向内缩（长焦/变焦常见）；
- 工业测量要求低畸变镜头（< 0.1%），或用 HALCON `calibrate_cameras` + `change_radial_distortion` 做**畸变校正**（但校正不能凭空增加分辨率，只是把几何拉直）。

### 1.7 远心镜头（Telecentric）—— 精密测量的必选项

普通镜头有"近大远小"的透视误差，导致：
- 物体离镜头近一点，成像就大一点 → 测尺寸不准；
- 边缘倾斜 → 测外径偏小。

**远心镜头**让主光线平行于光轴，物体在一定景深内"无论远近，成像大小不变"。

| 维度 | 普通镜头 | 远心镜头 |
| --- | --- | --- |
| 透视误差 | 有（近大远小） | 几乎为零 |
| 测量精度 | 低 | 高（μm 级） |
| 价格 | 低（几百~几千） | 高（几千~几万） |
| 适用 | 识别、定位、有无 | **尺寸测量、外径/孔径、厚度** |
| 工作距离 | 灵活 | 固定（物方远心距） |

> 选型口诀：**"要量尺寸，必上远心；只认有无，普通够用。"**

### 1.8 镜头接口（C / CS / F）

| 接口 | 法兰距（镜头面到 sensor） | 备注 |
| --- | --- | --- |
| C 口 | 17.526 mm | 工业最主流，配 C 口相机 |
| CS 口 | 12.526 mm | 短 5mm，CS 镜头不能直上 C 口相机（要转接环反之可） |
| F 口 | 46.5 mm | 单反大口径，机器视觉少用 |

> **坑**：C 镜头拧到 CS 相机上会"顶到 sensor 或无法对焦"（法兰距差 5mm）。买前核对相机接口。

### 1.9 镜头选型决策表

| 你的需求 | 选什么镜头 |
| --- | --- |
| 大视野、低精度、识别定位 | 普通 1/2" 兼容镜头，F# 可调 |
| 小视野、高分辨率细节 | 小焦距+短 WD 或加延长管 |
| 精密尺寸测量（±μm） | **双远心镜头** |
| 长工作距离（不能靠近） | 长焦（50/75mm）或远摄 |
| 高低不平物体全清晰 | 小光圈 + 远心，或结构光/多焦点 |
| 高速运动 | 大光圈（进光多→短曝光）+ 强光频闪 |

## 2. 光源选型（Lighting）

> **光源的本质任务**：让"你想检测的特征"与"背景"在图像上**对比度最大、噪声最小、最稳定可重复**。90% 的视觉项目，问题不在算法，而在打光。

### 2.1 七大光源类型与适用场景

| 光源 | 光路特点 | 典型用途 | 擅长凸显 |
| --- | --- | --- | --- |
| **环形光 Ring** | 四周斜射向中心 | 通用、五金件、瓶盖 | 表面纹理、边缘轮廓 |
| **同轴光 Coaxial** | 光路经半反半透镜垂直打向物体再原路返回 | 镜面/反光金属、玻璃、液晶 | 平整表面的划痕、刻字 |
| **背光源 Backlight** | 从物体**背后**打，相机看剪影 | 轮廓、尺寸、透明/半透明、有无缺料 | **轮廓与尺寸测量**（最强） |
| **条形光 Bar/Strip** | 长条单向照射 | 大幅面、流水线单侧补光 | 长边、线性特征、定向纹理 |
| **穹顶光 Dome** | 内置漫射罩四面八方均匀 | 曲面、反光、凹凸不平 | 消除局部反光，均匀照明 |
| **点光 Point** | 小范围强聚光 | 小区域高亮、局部特写 | 深孔、小凹点 |
| **线性光 / 线光** | 形成一条亮线 | 大幅面扫描、圆柱面展开 | 长带缺陷、瓶身文字 |

### 2.2 明场 vs 暗场（打光方向决定你看什么）

- **明场照明（Bright Field）**：光从正面/接近正面打，反射光直接进镜头 → 看到**物体本色与表面**；
- **暗场照明（Dark Field）**：光从极低角度（掠射）打，平整处光反射走不进镜头（暗），只有**划痕/凸起/颗粒把光散射进镜头（亮）** → 专门抓表面微缺陷。

> 划痕检测经典流派：**暗场一眼看出划痕，明场反而看不见**。

### 2.3 颜色与波长（互补色增强对比）

物体呈现某种颜色，是因为它**反射**该颜色、**吸收**其互补色。利用这一点，用互补色光可**压暗背景、提亮目标**：

| 目标颜色 | 用互补光（效果） |
| --- | --- |
| 红色物体 | 青色/绿色光 → 红物变暗，背景更亮 |
| 绿色物体 | 品红/红色光 |
| 蓝色物体 | 黄色光 |
| 看不清的浅色印记 | 同色光提亮，或互补光压暗周边 |

**红外（IR）/ 紫外（UV）**：
- 红外：穿透部分材料、抑制可见纹理、看清内部/去表面干扰（如透过包装看内部）；
- 紫外+荧光：把不可见标记激发成可见光，做隐形防伪/缺陷。

### 2.4 偏振（Polarization）—— 专治反光

金属、玻璃、液体表面反光会"糊"掉特征。在光源前加**起偏器**、镜头前加**检偏器**（正交），可滤掉镜面反射、只留漫反射细节。
> 例：抛光铝件上的刻字，直接拍一片白光；加偏振后刻字清晰浮现。

### 2.5 频闪（Strobe）—— 冻结运动的关键

拍运动物体（流水线），仅靠短曝光有时还不够亮。**频闪控制器**让光源在相机曝光的极短时间内爆闪（μs 级），既冻结运动又提供巨量光。
> 这与 `02` 篇呼应：**频闪 + 短曝光 = 冻住运动物体的黄金组合**（位移 = 速度 × 曝光，曝光短到 μs，10m/s 也只拖 0.01mm）。

### 2.6 光源选型决策表

| 你的问题 | 首选光源 |
| --- | --- |
| 测外形尺寸/透明缺料 | **背光源**（最强轮廓） |
| 镜面/玻璃/液晶缺陷 | 同轴光 |
| 普通五金识别定位 | 环形光 |
| 曲面/反光/凹凸 | 穹顶光 |
| 长带/大幅面 | 条形光 / 线光 |
| 深孔/小凹点 | 点光 |
| 表面微划痕 | **暗场 + 低角度** |
| 金属反光糊特征 | 加偏振 |
| 彩色背景干扰 | 互补色光 |
| 高速运动 | 频闪 + 强光 |

## 3. 三件套协同设计（把参数一起算）

### 3.1 精度计算（最重要的一步）

**单像素精度（pixelsize on object）**：
```
单像素精度 = FOV（mm） / 相机分辨率（像素）
```
例：FOV 宽 64mm，相机 2448 像素宽 → 单像素精度 = 64/2448 ≈ **0.026 mm/像素 = 26 μm**。

**特征需要的像素数（采样定理）**：
```
可测最小特征 ≥ 3~5 像素        （保守取 5，防边缘抖动）
```
例：要测 0.1mm 的裂缝 → 单像素精度需 ≤ 0.1/5 = 0.02mm/像素 → 反推 FOV/分辨率 ≤ 0.02。

### 3.2 完整选型 7 步流程

```
1. 定需求：检测什么？精度？节拍（fps）？视野 FOV？工作距离 WD 限制？
2. 算相机分辨率：分辨率 ≥ FOV / (目标精度/5)
3. 选传感器：按分辨率+帧率+接口（GigE/USB3）定相机
4. 算镜头焦距：f = WD × S / FOV，选标准档（向上取整更稳）
5. 核靶面：镜头支持靶面 ≥ 相机传感器；核分辨率 lp/mm ≥ 1000/(3p)
6. 选光源：按"特征 vs 背景"选类型+颜色+是否偏振/频闪
7. 验证：实拍看对比度/畸变/景深，必要时调 F# 或换远心
```

### 3.3 综合案例：PCB 焊盘宽度测量

- 需求：测 0.2mm 宽焊盘，公差 ±0.02mm，节拍 30fps，WD 固定 150mm。
- 精度要求：0.02/5 = 0.004mm/像素 → FOV 若 30mm，需 30/0.004 = 7500 像素宽 → 选 900 万级相机（或缩小 FOV 到 20mm 用 500 万）。
- 镜头：f = 150 × 6.4 / 30 = 32mm → 选 35mm 高清镜头（≥120 lp/mm）。
- 光源：**背光源或低角度环形**，让焊盘边缘锐利；测尺寸用**远心镜头**消除透视。
- 结果：单像素精度 30/2448≈0.012mm，5 像素覆盖 0.06mm > 公差，稳。

## 4. 与上篇的衔接（参数铁三角 + 成像三件套）

| 维度 | 本篇（镜 + 光） | 上篇（相机参数） |
| --- | --- | --- |
| 亮度来源 | 光源强度 + 光圈 F# | 曝光时间 + 增益 |
| 清晰度来源 | 镜头分辨率 + 靶面匹配 + 对焦 | 像元大小 + 无拖影（短曝光） |
| 几何精度 | 远心 + 低畸变 + 标定校正 | — |
| 节拍 | 光源频闪配合 | 帧率 = 曝光 + 读出，ROI 提帧率 |

> **铁三角升级版**：`光源亮度 + 镜头进光(F#) + 相机曝光` 共同决定图像亮度；`镜头分辨率 + 相机像元 + 远心/畸变` 共同决定几何精度。调亮度优先加光/开光圈，**最后才加增益**（增益放大噪声，见 02 篇）。

## 5. 常见误区（十大坑）

1. **只看相机分辨率**：不配镜头就不知道 FOV 和单像素精度，分辨率数字毫无意义。
2. **镜头靶面 < 传感器**：四角黑角，高分辨率白买。
3. **镜头分辨率不够**：配小像元相机被镜头瓶颈，边角糊。
4. **普通镜头做测量**：透视误差让尺寸飘，应上远心。
5. **光圈全开求亮**：景深浅、前后糊；应先加光源而非全开光圈。
6. **光源颜色乱用**：不看互补色，背景目标同亮，对比度低。
7. **反光不偏振**：金属玻璃一片白，特征淹没。
8. **明场暗场不分**：找划痕用明场，啥也看不见。
9. **运动不频闪**：只靠短曝光仍拖影，应频闪+短曝。
10. **不实测只算数**：公式算完必须实拍验证对比度/畸变，理论≠现场。

## 6. 术语速查

| 术语 | 含义 |
| --- | --- |
| FOV | Field of View，视场（能看到的范围） |
| WD | Working Distance，工作距离 |
| F# | 光圈数，越小进光越多、景深越浅 |
| β | 放大倍率 = 传感器尺寸 / FOV |
| lp/mm | line pairs per mm，镜头分辨率单位 |
| 远心 | Telecentric，主光线平行光轴，无透视误差 |
| 背光源 | 从物体背后打光，看剪影/轮廓 |
| 同轴光 | 垂直打光，看镜面/平整缺陷 |
| 暗场 | 低角度掠射，只显微观缺陷 |
| 偏振 | 滤除镜面反射，留漫反射 |
| 频闪 | 曝光瞬间爆闪，冻结运动 |
