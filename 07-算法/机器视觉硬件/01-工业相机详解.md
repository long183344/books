# 01 · 工业相机详解：触发、帧率、曝光、亮度、增益与成像全栈

> 数据基准：2026-09（概念通用，型号参数请以厂商手册为准）
> 适用：机器视觉工程师、自动化集成、HALCON/OpenCV 采集端对接

---

## 一句话核心要义

> **工业相机 = 把"光"确定性地变成"数字图像"的确定性设备。** 它和普通相机最大的区别不是画质，而是**可控、可同步、可重复**：用触发（内/外/软/硬）决定"什么时候拍"，用曝光+增益+亮度决定"拍成什么样"，用帧率+接口带宽决定"能拍多快"，其余所有参数（分辨率、像元、靶面、快门、SNR）共同决定"拍得准不准"。

---

## 0. 工业相机 vs 民用相机（先建立坐标系）

| 维度 | 工业相机 | 消费/手机相机 |
| --- | --- | --- |
| 核心目标 | 确定性、可重复、可同步 | 好看、易用、自动 |
| 触发 | 内/外/软/硬触发，精确到 μs | 快门按钮，无外部触发 |
| 帧率 | 固定可设、可满帧连续 | 可变、有自动降帧 |
| 快门 | 多为全局快门 | 多为卷帘快门（手机也有全局） |
| 接口 | GigE/USB3/CoaXPress/Camera Link | MIPI/USB2 |
| 输出 | 原始 RAW/Bayer/Mono，无压缩 | JPEG/HEIF，重度 ISP 处理 |
| 同步 | 支持多相机硬同步、闪光同步 | 无 |
| 寿命/稳定 | 7×24 工业级，温度宽 | 消费级 |
| 价格 | 高（千元~数十万） | 低 |

**结论**：工业相机的价值在于"可控 + 可同步 + 可重复"，而不是"像素高"。选型时优先看触发与同步能力，其次才是分辨率。

## 1. 工业相机分类（3 个维度）

### 1.1 按传感器类型

| 类型 | 特点 | 现状 |
| --- | --- | --- |
| CCD | 全局曝光、低噪、一致性好 | 已基本被 CMOS 取代 |
| CMOS | 成本低、速度快、集成度高 | **绝对主流** |

### 1.2 按色彩

| 类型 | 结构 | 适用 |
| --- | --- | --- |
| 黑白 (Mono) | 单通道，每个像元 1 个亮度 | 精度测量、低光、最高信噪比 |
| 彩色 (Color) | 片上 Bayer 滤光片（RGGB） | 需要颜色信息的场景 |

### 1.3 按接口（决定带宽与距离）

| 接口 | 带宽(单线) | 最远距离 | 特点 |
| --- | --- | --- | --- |
| GigE (千兆网) | ~1 Gbps | 100 m（标准网线） | 最常用、远距离、可 PoE |
| USB3 Vision | ~3.2 Gbps | 3~5 m | 即插即用、带宽高 |
| CoaXPress | 6~12 Gbps+ | 数十米 | 超高帧率/分辨率、需采集卡 |
| Camera Link | 最高 ~7 Gbps | 10 m | 老牌高速、需采集卡 |
| 10GigE | ~10 Gbps | 100 m | 高分辨率远程 |

**结论**：中小项目首选 **GigE**（远、稳、便宜）；高帧率高分辨率选 **USB3 / CoaXPress**。

## 2. 成像原理一句话铺垫

```
物体反射光 → 镜头聚焦 → 传感器像元(光电转换) → 模拟电压 → ADC 量化
   → 数字灰度值(0~255 或 0~4095) → 像素格式封装 → 接口传主机
```

三个最关键的"旋钮"：**曝光时间**（光进来多久）、**增益**（电信号放大几倍）、**光圈/光照**（进光量）——这三者的乘积 + 物体本身亮度 ≈ **图像亮度**。

## 3. 触发方式详解（本文重点）

触发决定"**这一帧什么时候产生**"。四种触发模式的本质区别是**触发信号的来源**。

### 3.1 四模式速查表

| 模式 | 触发源 | 物理连线 | 抖动 | 速度上限 | 典型用途 |
| --- | --- | --- | --- | --- | --- |
| **内触发** (Free Run) | 相机内部时钟 | 无 | 低（内部） | 满帧 | 连续检测、流式 |
| **外触发 / 硬触发** | 外部设备硬件信号（PLC/光电/编码器） | 触发输入线 (Line In) | **极低 (μs 级)** | **最高** | 产线同步、飞拍、高速 |
| **软触发** | 主机软件指令（SDK/API） | 数据接口（网线/USB） | 中（受主机调度） | 中 | 手动、低频、调试 |
| （外部触发还有**软硬之分**） | — | — | — | — | — |

> ⚠️ **概念澄清**：很多资料把 **外触发 = 硬触发**，二者常混用，都指"通过物理信号线让外部设备控制拍照"。严格区分时：
> - **硬触发 (Hardware Trigger)**：用相机专门的 **触发输入端口**（通常是光耦隔离的 Line 0/1），信号直接进 FPGA，抖动最小、速度最快，是工业首选。
> - **软触发 (Software Trigger)**：主机通过通信接口发一条"拍一张"的指令，相机收到后启动曝光。受操作系统调度影响，抖动较大、速度受限，但接线最简单。
> - **内触发 (Internal Trigger)**：相机自己按固定频率连拍，不依赖任何外部信号。
>
> 所以你列的"外触发 + 硬触发"本质是一件事的两个叫法；标准三分类是 **内触发 / 外触发(硬) / 软触发**。下面按此讲。

### 3.2 内触发 (Internal / Free Run)

- 相机内部时钟周期性产生触发，连续出图。
- 无需任何外部连线，最省事。
- 缺点：无法与产线节拍、外部事件对齐，可能拍到工件不在视野的空帧。

```
相机时钟 ──► 每 T 秒 ──► 曝光 ──► 出图 ──► 曝光 ──► 出图 ...（自主循环）
```

### 3.3 外触发 / 硬触发 (External / Hardware Trigger)

- 外部设备（PLC、光电开关、编码器、运动控制器）拉高/拉低相机的 **Trigger Input Line**，相机收到边沿即开始曝光。
- 信号类型：上升沿 / 下降沿；电平（高/低有效）。
- 关键参数：
  - **触发源 (Trigger Source)**：Line 0 / Line 1 / 编码器通道。
  - **触发模式 (Trigger Mode)**：On（等待触发）/ Off（内触发）。
  - **触发极性 (Trigger Polarity)**：RisingEdge / FallingEdge。
  - **触发延迟 (Trigger Delay)**：收到信号后延迟 N μs 再曝光（补偿机构到位）。
  - **消抖/滤波 (Debounce)**：滤除信号毛刺。
- 优势：抖动低至微秒级，可与传送带、机械手、闪光灯严格同步 → **飞拍（运动中拍照）** 的基石。

```
[PLC/光电] 信号上升沿 ──► 相机 Trigger In ──► (可选 Delay) ──► 曝光 ──► 出图
```

### 3.4 软触发 (Software Trigger)

- 主机调用 SDK 指令（如 `camera.TriggerSoftware.Execute()` 或 HALCON 的 `grab_image` 在触发模式下）通知相机拍一张。
- 优点：无需接触发线，调试方便。
- 缺点：指令要经网络/USB 栈 + 操作系统调度，抖动大（毫秒级），不适合高速同步。

```
[主机程序] 调 API ──► 经接口传命令 ──► 相机收到 ──► 曝光 ──► 出图  (延迟与抖动较大)
```

### 3.5 触发模式进阶（采集时机）

| 组合 | 含义 |
| --- | --- |
| 连续 (Continuous) | 内触发，一直出图 |
| 触发一次 (Triggered) | 来一个触发信号 → 出一张 |
| 触发 + 采集 N 张 | 一次触发 → 连续采集多帧（高速连拍） |
| 触发后固定延迟拍 | 触发后 Delay 再曝光（等工件到位） |
| 编码触发 (Encoder) | 编码器脉冲分频触发，物体移动固定距离拍一帧（长度测量） |

### 3.6 多相机同步（硬同步要点）

- 用一台 **触发分配器 / 主控 PLC** 同时给多台相机发同一触发信号 → 多视角同帧。
- 或用 **帧触发器 (Frame Trigger)** 做主从：主相机出图同时给从相机发硬触发。
- 闪光灯（光源）需与曝光**硬同步**：触发信号同时点亮光源，避免环境光干扰。

```
            ┌──► 相机A Trigger In
主控触发 ───┼──► 相机B Trigger In  ──► 同时曝光、同时闪光
            └──► 光源控制器
```

## 4. 帧率 (Frame Rate)

### 4.1 定义

**帧率 = 每秒能输出的完整图像帧数 (fps)**。受三个瓶颈共同限制：

```
实际帧率 = min( 传感器读出速度, 1/(曝光时间 + 读出时间 + 传输时间), 接口带宽限制 )
```

### 4.2 帧率 vs 曝光的核心关系

| 情形 | 结果 |
| --- | --- |
| 曝光时间 < 帧周期 | 一帧内有"空闲"，可满帧率 |
| 曝光时间 ≈ 帧周期 | 刚好满帧 |
| 曝光时间 > 帧周期 | **帧率被迫下降**（长曝光拖慢出图） |

> 公式：`最大帧率 ≤ 1 / (曝光时间 + 帧读出时间)`。曝光 100 ms → 理论最多 10 fps，再快的传感器也白搭。

### 4.3 带宽限制

```
所需带宽 ≈ 分辨率(像素) × 像素深度(bit) × 帧率  ÷  8  (字节/秒)
例：500万像素 Mono8 @ 30fps = 5e6 × 8 × 30 / 8 ≈ 120 MB/s ≈ 1 Gbps（GigE 临界）
```

**结论**：高分辨率 + 高帧率首先撞墙的是**接口带宽**，不是传感器。

## 5. 曝光 (Exposure)

### 5.1 两种快门（决定会不会"拖影"）

| 快门 | 原理 | 运动模糊 | 适用 |
| --- | --- | --- | --- |
| **全局快门 (Global)** | 所有像元同时曝光同时读 | 无（整帧同一时刻） | **机器视觉首选**，运动物体 |
| **卷帘快门 (Rolling)** | 像元按行依次曝光 | 有（果冻效应/斜切） | 静止或慢速 |

> ⚠️ 运动物体 + 卷帘快门 = 图像扭曲（果冻效应）。视觉检测基本选**全局快门**。

### 5.2 曝光时间

- 单位：μs / ms。
- **越短** → 运动越清晰、越能"凝固"快速目标，但进光少 → 画面暗。
- **越长** → 进光多、画面亮，但运动拖影、过曝风险。
- **曝光模式**：自动曝光 (AE) / 手动固定。视觉产线一般用**手动固定曝光**，保证可重复（自动曝光会让同一工件亮度浮动，毁掉阈值分割）。

### 5.3 拖影判定经验

```
拖影量(px) ≈ 物体速度(px/ms) × 曝光时间(ms)
要求拖影 < 1~2 像元 → 曝光时间 < 2 / 物体速度
```

## 6. 亮度 (Brightness)

亮度不是独立参数，而是**最终结果**，由以下因素共同决定（乘法关系）：

```
图像亮度 ∝ 光照强度 × 光圈(进光面积) × 曝光时间 × 增益 × 量子效率 / (像元尺寸²)
```

| 调节手段 | 对画质影响 | 优先级建议 |
| --- | --- | --- |
| **加强光照** | 最佳，不加噪声 | ⭐ 第一选择 |
| **开大光圈** | 景深变浅 | 次选 |
| **加长曝光** | 可能拖影 | 物体静止时 |
| **提高增益** | **引入噪声** | 最后兜底 |

### 6.1 自动亮度闭环

相机/SDK 的"自动亮度"通常是自动调 **曝光 + 增益** 让平均灰度落到目标值（如 128）。工业产线**慎用自动**，它会让图像亮度随工件/环境浮动，破坏后续固定阈值算法。**推荐固定曝光 + 固定增益 + 稳定光源**。

## 7. 增益 (Gain)

### 7.1 模拟增益 vs 数字增益

| 类型 | 做法 | 噪声 |
| --- | --- | --- |
| 模拟增益 (Analog Gain) | 放大传感器输出电信号 | 信号+噪声一起放，**信噪比基本不变但绝对噪声抬高** |
| 数字增益 (Digital Gain) | ADC 后乘系数 | **只放大噪声、不提真实信号**，画质最差 |

### 7.2 增益与噪声的核心矛盾

```
增益 ↑  →  图像变亮（不用加曝光）  →  但噪声同步放大  →  信噪比(SNR)下降
```

> **铁律**：增益是"亮度不够时的兜底手段"，不是正常画质来源。**先加光照，后加曝光，最后才加增益**。把增益压到最低，用光照和曝光把画面提亮，是工业视觉的最佳实践。

### 7.3 信噪比 (SNR) 关联

```
SNR(dB) ≈ 10·log10(信号功率 / 噪声功率)
低光照 + 高增益 → SNR 暴跌 → 图像"雪花"、边缘发虚、阈值分割失败
```

## 8. 其他必须掌握的关键参数

| 参数 | 含义 | 影响 |
| --- | --- | --- |
| 分辨率 | 像素数 W×H | 决定能看多细；越大越吃带宽 |
| 像元尺寸 | 单个像元物理大小 (μm) | 越大越灵敏、SNR 越高 |
| 靶面/光学尺寸 | 传感器物理尺寸 (1/2"、1/1.8"…) | 决定配什么镜头、视场 |
| 动态范围 | 最亮/最暗可分辨比 (dB) | 高反差场景（明+暗细节） |
| 量子效率 QE | 光子→电子转化率 (%) | 越高越灵敏 |
| 信噪比 SNR | 信号/噪声 | 画质核心指标 |
| 快门类型 | 全局/卷帘 | 运动物体必全局 |
| 像素格式 | Mono8 / BayerRG8 / RGB8 / YCbCr | 黑白选 Mono，彩色注意 Bayer 解码 |
| 色彩空间 | RGB / YUV / Bayer | 与算法库对接要匹配 |
| 采集延迟 Latency | 触发到出图的时间 | 飞拍同步精度 |
| 触发输入/输出 | Line 数量、光耦隔离 | 多设备同步能力 |
| 防护等级 IP | 防尘防水 | 恶劣环境必备 |
| 温度范围 | 工作温度 | 车间/户外 |

## 9. 与 HALCON 的对接（采集端）

HALCON 通过 `open_framegrabber` 统一抽象各种相机接口：

```hdevelop
* 打开 GigE 相机（以 Halcon GigEVision2 为例）
open_framegrabber ('GigEVision2', 0, 0, 0, 0, 0, 0, 'default', -1, 'default', \
                   -1, 'false', 'default', 'camera_ip', 0, 0, AcqHandle)

* 设置触发：外触发（硬件线触发）
set_framegrabber_param (AcqHandle, 'TriggerMode', 'On')
set_framegrabber_param (AcqHandle, 'TriggerSource', 'Line1')   * 硬触发线
set_framegrabber_param (AcqHandle, 'TriggerActivation', 'RisingEdge')

* 手动固定曝光与增益（工业最佳实践）
set_framegrabber_param (AcqHandle, 'ExposureTime', 2000.0)     * μs
set_framegrabber_param (AcqHandle, 'Gain', 0.0)                * 最小增益

* 软触发：发一条命令让相机拍一张
set_framegrabber_param (AcqHandle, 'TriggerSoftware', '1')

* 抓取一帧
grab_image (Image, AcqHandle)
```

> 要点：HALCON 把"内/外/软/硬触发""曝光""增益"都映射成 `set_framegrabber_param` 的名字参数，**不同接口前缀不同**（GigEVision2 / USB3Vision / GenTL），具体名字以相机厂商的 HALCON 接口手册为准。

## 10. 选型决策表（一表告诉你怎么选）

| 你的场景 | 推荐配置 |
| --- | --- |
| 静止工件、高精度测量 | 黑白 + 全局快门 + 大像元 + 固定曝光/增益 + GigE |
| 产线飞拍（运动中） | 全局快门 + **硬触发** + 短曝光 + 闪光同步 |
| 多相机同帧（3D/拼图） | 多相机 **硬同步触发** + 同一触发分配器 |
| 远距离（>30m） | GigE / 10GigE（网线百米） |
| 超高帧率（千 fps+） | CoaXPress / Camera Link + 采集卡 |
| 需要颜色 | 彩色 Bayer + 注意解码与白平衡 |
| 低光照 | 大像元 + 加强光照（别先加增益） |
| 恶劣车间 | IP 防护 + 宽温 + 光耦隔离触发线 |

## 11. 常见误区（避坑清单）

1. ❌ "帧率不够就调相机参数" → 多半是**接口带宽**或**曝光时间过长**卡住，先算带宽。
2. ❌ "亮度不够就加增益" → 增益放大噪声，**先加光照/曝光**。
3. ❌ "运动物体用卷帘快门省成本" → 必拖影/果冻，视觉检测必须全局快门。
4. ❌ "自动曝光方便" → 产线会让亮度浮动，**固定曝光+增益+稳定光源**才是可重复之道。
5. ❌ "软触发够用" → 高速/同步场景软触发抖动大，**硬触发**才稳。
6. ❌ "分辨率越高越好" → 越高越吃带宽和算力，按"视野÷精度"反推即可。
7. ❌ "外触发和硬触发是两种" → 二者基本同义，都是物理线触发；标准三分法是 内/外(硬)/软。

```
工业相机
├─ 什么时候拍（触发）
│   ├─ 内触发：相机自定频连拍
│   ├─ 外触发/硬触发：PLC/光电 物理线，μs 抖动（飞拍基石）
│   └─ 软触发：主机指令，方便但抖动大
├─ 拍成什么样（亮度）
│   ├─ 光照（首选）/ 光圈 / 曝光 / 增益
│   └─ 增益是兜底，先加光后加曝最后加增益
├─ 能拍多快（帧率）
│   ├─ 受 曝光+读出+带宽 三重限制
│   └─ 撞墙先看带宽
└─ 拍得准不准（成像质量）
    ├─ 全局快门（运动必选）
    ├─ 分辨率/像元/靶面/QN/SNR
    └─ 黑白测精度、彩色取颜色
```

**终极结论**：工业相机的灵魂不是像素，而是**"可控 + 可同步 + 可重复"**。把触发、曝光、增益、亮度、帧率这五个旋钮按顺序调对（先同步、再亮度、后速度），再配全局快门与合适接口，就是一套稳得出奇的视觉采集系统。
