# 知识思维导图

> 用 **Python + Matplotlib** 维护的跨主题可视化笔记（辐射式布局，中文字体 SimHei）。
> 每个主题一份 `.py` 源脚本 + 自动生成的 `.png` / `.svg`。

## 目录约定

```
知识思维导图/
├── README.md                  ← 本说明
└── <主题名>/
    ├── <主题>.py             ← 生成脚本（源，可改数据后重跑）
    ├── <主题>.png            ← 栅格图
    ├── <主题>.svg            ← 矢量图（首选查看）
    └── <主题>.md             ← 配套说明（区别对比表 + 解析）
```

## 新增主题模板

1. 复制 `硬件知识体系.py` 为 `知识思维导图/<主题>.py`
2. 改顶部 `FAMILIES` 数据结构（族名 / 颜色 / 子标题 / 要点列表）
3. 运行脚本 → 自动产出同名的 `.png` / `.svg`
4. 写一份 `<主题>.md`：含「一句话结论」+「区别对比表」+「详细解析」+「关联」
5. 更新本 README 的「已收录」表格

> 注意：Matplotlib 默认缺部分数学符号（如 `?`），对比关系请用中文「属于 / 包含」等写法，避免豆腐块。
