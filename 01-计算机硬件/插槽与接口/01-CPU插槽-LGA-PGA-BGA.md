# CPU 插槽：LGA / PGA / BGA

> **一句话结论**：插槽的针脚数不是为了传数据，**主要是为了送电和接地**——一颗 250W 的 CPU 在 1.2V 下要吃 200 多安培，得靠几百个针脚分摊。
> **数据基准**：2026-08 ｜ **难度**：入门→进阶 ｜ **前置**：[主板结构与芯片组](../主板/01-主板结构与芯片组.md)

## 1. 三种封装形态

```
   PGA（针在 CPU 上）        LGA（针在主板上）        BGA（焊死）
   ┌───────────┐            ┌───────────┐          ┌───────────┐
   │    CPU    │            │    CPU    │          │    CPU    │
   │ ||||||||| │            │ ▪▪▪▪▪▪▪▪▪ │          │ ●●●●●●●●● │ ← 焊球
   └───────────┘            └───────────┘          └───────────┘
     ↓ 插进去                 ↓ 压上去                ↓ 回流焊
   ┌───────────┐            ┌───────────┐          ┌───────────┐
   │  主板孔位  │            │ 主板弹性针 │          │   主板    │
   └───────────┘            └───────────┘          └───────────┘
   针弯了 → 换 CPU           针弯了 → 换主板         想换 → 换整机
```

| | PGA | LGA | BGA |
| --- | --- | --- | --- |
| 全称 | Pin Grid Array | Land Grid Array | Ball Grid Array |
| 针脚位置 | CPU 底部 | **主板插槽内** | 焊球，直接焊 |
| 可更换 | ✅ | ✅ | ❌ |
| 弯针后果 | 换 CPU（贵） | 换主板（相对便宜） | — |
| 引脚密度 | 低 | **高** | 最高 |
| 高频信号 | 一般 | 好（针程短） | 最好 |
| 典型用途 | 老 Intel、AMD AM4 | 现代桌面/服务器 | 笔记本、手机、迷你主机 |

**为什么全面转向 LGA**：引脚密度更高（DDR5 和 PCIe 5.0 需要更多针）、信号路径更短（高频完整性更好）、CPU 更薄。**而且弯针的损失从「一颗 CPU」变成「一块主板」**——虽然对用户没好多少，但对厂商 RMA 成本友好。

> **实操提醒**：LGA 插槽的针极其脆弱。**装机时 CPU 要垂直放下，靠三角标记对齐，绝对不要横向拖动**。

## 2. 当前主流插槽

| 插槽 | 厂商 | 触点数 | 支持 CPU | 内存 | 状态 |
| --- | --- | --- | --- | --- | --- |
| **AM5** | AMD | **LGA 1718** | Ryzen 7000 / 8000 / 9000（Zen 4/5），Zen 6 确认沿用 | 仅 DDR5 | ⭐ 现役，承诺支持到 2027+ |
| **LGA1851** | Intel | LGA 1851 | Core Ultra 200S（Arrow Lake） | 仅 DDR5 | ⭐ 现役 |
| **LGA1700** | Intel | LGA 1700 | 12/13/14 代酷睿 | DDR4 或 DDR5 | 上一代，清仓仍有价值 |
| **AM4** | AMD | **PGA 1331** | Ryzen 1000–5000 | 仅 DDR4 | 传奇长寿，2017–2022 跨 6 代 |
| **sTR5 / SP6** | AMD | LGA 4844 / 6096 | Threadripper / EPYC | DDR5 RDIMM | HEDT / 服务器 |
| **LGA4677 / LGA7529** | Intel | — | Xeon | DDR5 RDIMM | 服务器 |

**注意 AM5 的特殊性**：AMD 从 AM4（PGA）切换到了 AM5（LGA），所以 AM4 时代「针在 CPU 上」的经验在 AM5 上不适用了。

## 3. 历代插槽对照（快速定位老机器）

### Intel

| 插槽 | 年代 | 代表 CPU | 内存 |
| --- | --- | --- | --- |
| LGA775 | 2004–2011 | Core 2 Duo/Quad | DDR2/DDR3 |
| LGA1156 | 2009 | 1 代酷睿 | DDR3 |
| LGA1155 | 2011–2013 | 2/3 代（Sandy/Ivy Bridge） | DDR3 |
| LGA1150 | 2013–2015 | 4/5 代（Haswell） | DDR3 |
| LGA1151 | 2015–2019 | 6/7 代 ‖ 8/9 代（**两版不兼容**） | DDR4 |
| LGA1200 | 2020–2021 | 10/11 代 | DDR4 |
| LGA1700 | 2021–2024 | 12/13/14 代 | DDR4 或 DDR5 |
| **LGA1851** | 2024– | Core Ultra 200S | DDR5 |

> **LGA1151 的坑**：同名插槽分两个互不兼容的版本（100/200 系芯片组 vs 300 系）。物理插得进，但供电针脚定义不同，无法工作。这是「插槽名相同不等于兼容」的经典案例。

### AMD

| 插槽 | 年代 | 代表 CPU | 内存 |
| --- | --- | --- | --- |
| AM3/AM3+ | 2009–2016 | Phenom II / FX | DDR3 |
| FM2/FM2+ | 2012–2015 | APU A 系列 | DDR3 |
| **AM4** | 2017–2022 | Ryzen 1000–5000 | DDR4 |
| **AM5** | 2022– | Ryzen 7000+ | DDR5 |

**AM4 的传奇**：一个插槽撑了 6 年、5 个大代际。2017 年买 B350 主板的人，2022 年还能刷 BIOS 装 5800X3D，性能提升接近 3 倍。这是 AMD 建立口碑的关键一战，也是 AM5「承诺支持到 2027+」这句话有分量的原因。

## 4. 针脚数为什么这么多

1718 个触点，都用来干嘛？

| 用途 | 大致占比 | 说明 |
| --- | --- | --- |
| **电源 + 地** | **约 50–60%** | 250W ÷ 1.2V ≈ 208A，单个触点只能过 0.3–0.5A，需要几百个并联 |
| 内存接口 | ~15% | DDR5 双通道 = 2 × (32 数据 + 地址 + 控制)，本身就是并行总线 |
| PCIe | ~15% | 24–28 lane × 4 线（TX±/RX±）= 上百根 |
| 其他 I/O | ~5% | DMI、USB、显示输出、SPI、SMBus |
| 保留 / 未用 | ~5–10% | 为未来功能预留 |

**这解释了为什么插槽会换代**：DDR4 → DDR5 需要不同的针脚定义和更多供电；PCIe 4.0 → 5.0 需要更好的信号完整性；功耗上升需要更多电源针。**不是厂商纯粹想卖主板**（虽然也有这个因素）。

## 5. 插槽兼容性检查清单

想给老主板换新 CPU，按顺序查：

```
① 插槽名一样吗？
   ↓ 一样
② 主板厂商的 CPU Support List 里有这颗 CPU 吗？
   ↓ 有
③ 需要哪个版本以上的 BIOS？
   ↓ 查到版本号
④ 我当前 BIOS 版本够吗？
   ├─ 够 → 直接换
   └─ 不够 → 先用老 CPU 刷 BIOS
              └─ 老 CPU 坏了/没有？
                  → 看主板有没有 BIOS Flashback（免 CPU 刷新）
                     ├─ 有 → 用 U 盘刷
                     └─ 没有 → 借一颗老 CPU，或者换主板
```

**血泪教训**：AM5 早期主板配 Ryzen 9000 系列必须刷 BIOS。买散片老主板前，**先确认有没有 Flashback 按钮**（后置 I/O 上一个标着 BIOS 的小按钮 + 专用 USB 口）。

## 6. 安装要点

| 步骤 | 要点 |
| --- | --- |
| 开盖 | LGA 插槽扳手先压后掀，取下塑料保护盖（**保护盖留着**，主板 RMA 时要用） |
| 对位 | 找 CPU 一角的**金色三角**，对准插槽同侧三角。AM5/LGA1851 还有防呆缺口 |
| 放置 | **垂直落下**，靠自重就位。**不要按压，不要横向移动** |
| 扣具 | LGA 压下扳手会有明显阻力，这是正常的（要压紧几百个弹性触点） |
| 硅脂 | 中间点黄豆大小一点即可，靠散热器压力自然摊开。涂太多会溢出，导电硅脂溢出会短路 |
| 散热器 | 对角线交叉拧紧，分 2–3 轮逐步加力，不要一次拧死一颗 |

**LGA1700 的额外坑**：这一代 CPU 较薄且扣具压力设计导致轻微弯曲（bending），可能造成散热接触不良。第三方「防弯扣具」是常见解决方案。LGA1851 已改进。

## 7. 常见误区

- ❌ **「插槽名一样就一定兼容」** → ✅ LGA1151 两版互不兼容；AM4 早期低端板受 BIOS ROM 容量限制无法支持全部 CPU。
- ❌ **「针脚越多性能越强」** → ✅ 针脚数主要反映**供电需求和 I/O 数量**，不直接对应性能。
- ❌ **「AMD 的针在 CPU 上」** → ✅ AM4 时代是（PGA），**AM5 已改为 LGA**，针在主板上。
- ❌ **「BGA 是偷工减料」** → ✅ 是移动设备的必然选择：更薄、更抗震、信号更好。代价是不可升级。近年迷你主机也大量采用。
- ❌ **「弯了几根针没关系」** → ✅ 可能弯的正好是关键供电针，导致不开机或不稳定。轻微弯曲可用镊子/美工刀小心复位，但成功率不高。
- ❌ **「硅脂涂满整个顶盖更好」** → ✅ 硅脂导热性远不如金属直接接触，只是用来填补微观缝隙的。越薄越好。
