# 05 · USB4 与雷电 4 一线连（数据 + 供电 + 显示）详解

> 本文是 [`04-USB 3.x 接口与 U 盘详解`](./04-USB3x接口与U盘详解.md) 的**直接续篇**。
> 上篇结尾提到「USB4 = 雷电 3 的开放授权版，40Gbps」，本文把这句话彻底展开：
> **为什么 USB4 不是「USB 3.2 的下一代速度」，而是一场接口架构的重构；一根 Type-C 线如何同时跑数据、显示、供电；以及一线连（Single-Cable）在显示器 / 扩展坞 / 外置显卡 / 高速硬盘盒里的真实玩法与坑。**

---

## 0. 一句话核心要义

> **USB4 与雷电 4 是同一套「基于雷电协议、强制走 Type-C、双向 40Gbps（可选 80Gbps）」的融合接口；它们的杀手锏不是单纯的速度，而是「隧道化（Tunneling）」——在一根线里把 PCIe、DisplayPort、USB3 三种协议 multiplex 到一起，从而实现「插一根线 = 接显示器 + 接一堆 USB 外设 + 给笔记本充电」的一线连体验。**

记住：**速度只是表象，隧道化才是灵魂。**

---

## 1. 先厘清：USB4、雷电 3、雷电 4 到底什么关系

这是整篇最容易混淆的地方，先画一张血缘图：

```
雷电 1/2 (2011/2013)      Mini DP 口，10/20Gbps，PCIe+DP 双协议  ← 苹果+Intel 共创
   ↓
雷电 3 (2015)             USB-C 口，40Gbps，PCIe 3.0×4 + DP 1.2 + PD  │ ← 关键转折点：转用 USB-C
   ↓  Intel 把雷电协议规范免费授权给 USB-IF
USB4 (2019 标准, 2020 落地)   基于雷电 3 协议，USB-C 口，20/40Gbps            ← 免费、人人可用
   ↓
雷电 4 (2020)             Intel 的「认证增强版 USB4」：强制 40G、强制 2×4K/1×8K、强制 PCIe 隧道  │ ← 不是更快，是更严
   ↓
雷电 5 (2023/2024)        80Gbps（对称）/ 120Gbps（单向给显示器），PCIe 4.0×4
```

**关键结论：**

| 名字 | 谁定的 | 最低速度 | 强制要求 | 本质 |
| --- | --- | --- | --- | --- |
| 雷电 3 | Intel | 40Gbps | Type-C | 协议鼻祖 |
| **USB4** | USB-IF | 20Gbps（20G 档）/ 40Gbps（40G 档） | Type-C + 雷电兼容 | 免费开放的雷电 3 协议 |
| **雷电 4** | Intel | 40Gbps（强制） | Type-C + 全部能力 | **认证版 USB4**（门槛更高） |
| 雷电 5 | Intel | 80Gbps | Type-C | 升级带宽版 |

**最容易踩的误区：**
- ❌「雷电 4 比 USB4 快一倍」——错。两者最高都是 40Gbps，雷电 4 只是**强制**了 USB4 里很多「可选」的能力（下文第 8 节展开）。
- ❌「USB4 一定比 USB 3.2 快」——**不一定**。USB4 有 20G 入门档，和 USB 3.2 Gen2×2（20G）一个水平。买之前看 logo 上的数字。
- ✅ 真结论：**USB4 / 雷电 4 的革命是「架构」不是「速率」**——它能把 PCIe 和 DP 封进同一条线，USB 3.x 做不到。

## 2. 物理层：全系 Type-C，没有例外

USB4 和雷电 4 **强制使用 USB-C 接口**，再没有 A/B/Micro 了。这是它们能「一线连」的物理前提。

Type-C 24 针里有 4 对高速差分线（TX1/RX1、TX2/RX2……），USB4/雷电用其中两对组成**双通道（2 lanes × 20G = 40G）**，另保留 CC、SBU、VBUS、GND 等用于协商与供电。

```
        USB-C 母座（俯视，24 针）
  GND VBUS CC  D+ D- SBU VBUS GND
  TX1 RX1    TX2 RX2    ...对称
   ↑高速差分对↑
```

- **可逆插拔**：Type-C 最大的体验升级（终于不分反正）。
- **CC 线（Configuration Channel）**：负责协商「我是谁、能跑多快、谁供电」。
- **SBU（Sideband Use）**：雷电/USB4 用它传辅助信号（如 DP 的 AUX 通道）。

## 3. 灵魂：隧道化（Tunneling）协议

这是 USB4/雷电 4 与上一代 USB 3.x 的**本质区别**。

传统 USB 3.x：线里只跑 USB 协议（批量/中断/等时传输）。
USB4/雷电：线里跑一个**传输层**，把下面三种协议「打包」进去，到对端再拆出来：

```
┌─────────────────────────────────────────────┐
│            USB4 / 雷电 传输层 (40G)            │
│  ┌──────────┬──────────┬──────────────────┐  │
│  │ PCIe 隧道 │ DP 隧道   │  USB3 隧道        │  │
│  │(NVMe/eGPU│(视频流)   │ (U盘/键鼠/摄像头) │  │
│  │ /网卡)   │          │                  │  │
│  └──────────┴──────────┴──────────────────┘  │
└─────────────────────────────────────────────┘
          ↓ 同一条 Type-C 线缆 ↓
   PCIe 设备  显示器(DP)  普通 USB 设备  同时工作
```

**三种隧道分别干嘛：**

| 隧道 | 承载内容 | 典型用途 |
| --- | --- | --- |
| **PCIe 隧道** | PCIe 数据包 | 外置显卡（eGPU）、NVMe 硬盘盒、10G 网卡、采集卡 |
| **DP 隧道** | DisplayPort 视频流 | 接 4K/8K 显示器、一线连显示器 |
| **USB3 隧道** | USB 3.x 数据 | 普通 U 盘、键鼠、摄像头、扩展坞上的 USB 口 |

> 注意：USB4 里**低速的 USB 2.0 不走隧道**，而是直接在 Type-C 的 D+/D- 针上独立传输（兼容性需要）。

**为什么这很重要：** 上一代 USB 3.x 接显示器得靠「DP Alt Mode」（单独切换模式），且 PCIe 设备基本无缘。USB4/雷电用隧道把三者**共存**在一条线里，才有了真正的一线连。

---

## 4. 一线连（Single-Cable）实战三件套：数据 + 显示 + 供电

所谓「一线连」，典型场景是：**笔记本只用一根 Type-C 线连显示器，显示器同时负责——**
1. **显示**：把画面送到显示器（DP 隧道）
2. **扩展外设**：显示器上的 USB 口接键鼠/摄像头/硬盘（USB3 隧道）
3. **充电**：反向给笔记本供电（USB PD，最高 100W，雷电 4/5 可达 240W）

```
            ┌──────────── 一线连显示器 ────────────┐
笔记本 ═════│ 视频(DP隧道) + 数据(USB3隧道) + 供电(PD) │════ 键鼠/硬盘/U盘
 (1根线)    └──────────────────────────────────────┘
```

**供电角色（USB PD 规定）：**
- **DFP（Downstream Facing Port）**：供电方（如显示器、扩展坞），以前的「Host」。
- **UFP（Upstream Facing Port）**：受电方（如笔记本），以前的「Device」。
- **DRP（Dual Role Port）**：两面都能当（手机既能充电也能给别的设备充电）。

一线连显示器通常是 **DFP（供电）+ 输出 DP + 提供 USB 集线器** 三合一。

---

## 5. 带宽分配：40G 怎么分？为什么插了 4K 屏 U 盘就变慢

40Gbps 是总池子，DP 隧道、PCIe 隧道、USB3 隧道**共享**它。分配规则很关键：

### 5.1 雷电 3/4 / USB4 40G 的「固定分配」模式
默认把 40G 切成两半给双向：
- 主机 → 设备：**20G 下行 + 20G 上行**（对称）
- 但 DP 视频流通常很「吃」带宽：一个 4K@60Hz 10bit 的 DP 流约 **12~16Gbps**。

### 5.2 自适应分配（雷电 3 后期 / 雷电 4 / USB4）
视频流需要多少就占多少，剩下给 PCIe/USB3：
```
总带宽 40G
  ├─ DP 隧道占用  ~16G  (4K60)
  └─ 剩余 ~24G 分给 PCIe + USB3 隧道
```
**所以：** 当你用一线连显示器跑 4K60，剩下的带宽给 USB 设备——普通 U 盘（USB3 Gen1 5G）绰绰有余；但**外置 NVMe 硬盘盒（要跑满 PCIe 隧道）就会被视频挤占，速度从 2GB/s 掉到 1GB/s 左右**。这就是「插了 4K 屏 U 盘/硬盘变慢」的真实机理。

### 5.3 雷电 5 的「不对称模式」
雷电 5 玩了个新花样：**给显示器的方向能到 120Gbps（3 通道），回主机的方向 40G**。专门照顾「高刷/8K 显示器」的单向大流量，反向数据不耽误。

> 实战经验：**要满速 NVMe 硬盘盒，就别和 4K/8K 显示器走同一条雷电；或者上雷电 5。**

## 6. Alt Mode（Alternate Mode，替代模式）

Alt Mode 是 Type-C 的一项能力：把某些针脚临时「改用途」去传别的协议。

| 模式 | 干什么 | 谁用 |
| --- | --- | --- |
| **DP Alt Mode** | Type-C 直接出 DisplayPort 视频 | 显示器直连、一线连核心 |
| **雷电 Alt Mode** | Type-C 跑雷电/USB4 全功能 | 雷电设备、扩展坞 |
| **USB4 本身** | USB4 已内建隧道，无需单独 Alt | USB4 设备 |
| 其他 | HDMI Alt、MHL 等 | 较少用 |

**关键区分：**
- 上一代「USB-C + DP Alt Mode」显示器：能传视频和 USB，但**没有 PCIe 隧道**，接不了 eGPU/满速 NVMe。
- 雷电/USB4 显示器：三种隧道全有，才是真一线连。

## 7. 设备类型与认证标识（买之前看 logo）

| 标识 | 含义 | 注意 |
| --- | --- | --- |
| ⚡（闪电） | 雷电 3/4 设备 | Intel 认证，功能最全 |
| USB4 + 40G 数字 | USB4 40G 档 | 有 PCIe 隧道能力 |
| USB4 + 20G 数字 | USB4 20G 档 | **无 PCIe 隧道（可选），慎买给 eGPU** |
| 纯「SS 20 / 40」无 4 | 可能只是 USB 3.2 | 不是 USB4 |
| PD 100W/240W | 供电能力 | 看瓦数别看「快充」字样 |

**避坑：** 很多「USB4 硬盘盒」实际是 20G 档、无 PCIe 隧道，标得花哨但跑 NVMe 跑不满——认准 **40G + PCIe 隧道** 才是真一线连满血。

---

## 8. 雷电 4 到底比 USB4 多了什么（不是速度，是门槛）

雷电 4 是 Intel 对 USB4 的**认证增强**，强制补齐了 USB4 里的「可选」项：

| 能力 | USB4（规范允许可选） | 雷电 4（强制） |
| --- | --- | --- |
| 最高速度 | 20G 或 40G | **强制 40G** |
| PCIe 隧道 | 可选 | **强制**（≥32Gbps PCIe 带宽） |
| 视频 | 可只 1×4K | **强制 2×4K 或 1×8K** |
| 菊花链 | 可选 | **强制支持 4 设备串联** |
| 唤醒/防抖 | 可选 | 强制 |

**一句话：** 雷电 4 = 不会缩水的 USB4。买扩展坞/eGPU 认准雷电 4 或 USB4 40G，最省心。

## 9. 典型应用场景

### 9.1 显示器一线连（最常见）
笔记本 →（一根线）→ 雷电/USB4 显示器。显示器反向 100W 供电 + 输出 4K 画面 + 自带 USB 集线器接外设。桌面瞬间清爽。

### 9.2 扩展坞（Dock）
Dock 一头接笔记本（雷电/USB4），另一头扩展出 DP/HDMI、多个 USB-A、2.5G 网口、SD 卡槽、PD  passthrough。本质是**所有外设汇聚到一条隧道**。

### 9.3 外置显卡（eGPU）
显卡塞进盒子，用 PCIe 隧道（≈PCIe 3.0×4）连笔记本。给轻薄本补游戏/AI 算力。**前提：笔记本支持 PCIe 隧道（雷电 4/USB4 40G）**，且注意带宽损耗（×4 约 22Gbps 实际，比内置 ×16 弱）。

### 9.4 外置 NVMe 硬盘盒
NVMe SSD 进盒子，走 PCIe 隧道，理论 40G → 实际盘速约 **2~3GB/s**（比内置 M.2 的 7GB/s 慢，但吊打 USB 3.2 Gen2 的 1GB/s）。**别和 4K 屏挤同一条线**（见第 5 节）。

## 10. 与上篇（USB 3.x）及机器视觉专题的呼应

- **速度衔接**：USB 3.2 Gen2×2 = 20G，USB4 20G 档与之持平；USB4 40G 档才是代际跨越。
- **控制器衔接**：USB4/雷电用 **xHCI**（兼容旧 USB）+ 独立的雷电控制器（如 Intel JHL/Barlow Ridge）。设备管理器里会看到「USB4 主机路由器」。
- **机器视觉呼应**：上篇 [`04`](./04-USB3x接口与U盘详解.md) 对比过「USB3 vs GigE vs CameraLink vs CoaXPress」。补充一点：**工业相机几乎不用 USB4/雷电**——因为雷电的 PCIe/DP 隧道对相机无用，反而增加成本与认证复杂度；相机要的是稳定等时带宽，GigE/CoaXPress 更合适。USB4 在视觉领域主要用于**工程师的移动工作站一线连扩展坞**，而非相机本身。

## 11. 线材与长度：一线连翻车重灾区

| 线材类型 | 支持 | 最大长度 | 备注 |
| --- | --- | --- | --- |
| 被动铜线（无芯片） | USB4 40G | ≤ 0.8m | 短但便宜 |
| 主动铜线（有 IC） | USB4 40G | ≤ 2m | 线里有信号放大 |
| 有源光纤线（AOC） | 雷电/USB4 40G | ≤ 5~15m | 长距离首选，贵 |
| 老 USB-C 线（仅 USB2/3） | 无隧道 | 任意 | **接雷电设备会降速甚至不认** |

**最大坑：线不对，一切白搭。** 用一根只支持 USB 2.0 的 Type-C 线去接雷电扩展坞，要么不识别，要么只有充电+低速 USB，PCIe/DP 全废。认准线材上印的 **40G / 雷电图标 / 100W**。

## 12. 十大坑（速记）

1. **把 USB4 20G 当 40G 买**——看 logo 数字，20G 档无 PCIe 隧道。
2. **线材不支持**——非 40G 线接雷电设备直接降速/不认。
3. **一线连显示器却不是雷电/USB4**——只有 DP Alt Mode 的老显示器接不了 eGPU。
4. **NVMe 盒和 4K 屏挤一条线**——视频挤占 PCIe 带宽，硬盘掉速。
5. **以为雷电 4 比 USB4 快一倍**——同 40G，只是认证更严。
6. **扩展坞 PD 功率不够**——标 60W 给不了游戏本满血，认准 100W/240W。
7. **菊花链超 4 级**——雷电 4 强制支持 4 设备，再串可能不稳。
8. **主板没雷电/USB4 主控**——很多台式机主板压根没雷电控制器，买了盒子也用不了 PCIe 隧道。
9. **雷电 5 设备插雷电 4 主机**——能跑但降到 40G，别惊讶。
10. **混用 DP 线和雷电线**——DP 线没有 PCIe/供电协商，接扩展坞会缺功能。

## 13. 术语速查

| 词 | 含义 |
| --- | --- |
| **Tunneling 隧道化** | 把 PCIe/DP/USB3 多协议打包进单条链路 |
| **DP Alt Mode** | Type-C 直接输出 DisplayPort 视频 |
| **PCIe 隧道** | 在 USB4/雷电里透传 PCIe 设备（eGPU/NVMe） |
| **DFP / UFP / DRP** | 供电方 / 受电方 / 双角色 |
| **PD（Power Delivery）** | USB 供电标准，最高 240W |
| **AOC 有源光纤** | 内置光模块的线，长距离不衰减 |
| **菊花链 Daisy Chain** | 设备串接，前一个的输出接后一个的输入 |
| **Barlow Ridge** | Intel 新一代雷电 4 控制器代号 |

| 你的需求 | 该买 | 别买 |
| --- | --- | --- |
| 笔记本一线连显示器+充电 | 雷电 4 / USB4 40G 显示器 + 100W 线 | 只有 DP Alt Mode 的老显示器 |

## 15. 文字版脑图（总结）

```
USB4 / 雷电 4 一线连
├─ 血缘：雷电3(Intel) → 免费授权 → USB4(USB-IF) → 雷电4(认证增强) → 雷电5(80G)
├─ 物理：全系 Type-C（24针，可逆插，CC 协商）
├─ 灵魂：隧道化
│   ├─ PCIe 隧道 → eGPU / NVMe / 网卡
│   ├─ DP 隧道   → 显示器视频
│   └─ USB3 隧道 → 键鼠/U盘/摄像头
├─ 一线连三件套：数据 + 显示 + 供电(PD 100~240W)
├─ 带宽分配：40G 总池，DP 占多少剩下给 PCIe/USB3（插4K屏NVMe掉速）
├─ Alt Mode：DP Alt / 雷电 Alt / USB4 内建
├─ 认证：⚡雷电 vs USB4 40G vs USB4 20G(无PCIe隧道)
├─ 雷电4 vs USB4：同40G，雷电4 强制门槛更高
├─ 线材：被动铜(0.8m)/主动铜(2m)/光纤(15m)；线不对全白搭
└─ 机器视觉呼应：相机不用USB4(用GigE/CoaXPress)，工程师扩展坞用
```
