# 内存插槽：DIMM 与 CAMM2

> **一句话结论**：内存是整个系统里**唯一还在用并行总线**的部分，这既是它低延迟的原因，也是它频率难以提升的枷锁；CAMM2 是三十年来第一次真正的形态革新。
> **数据基准**：2026-08 ｜ **难度**：进阶 ｜ **前置**：[总线原理与分类](../总线/01-总线原理与分类.md)

---

## 1. DIMM 家族

**DIMM**（Dual In-line Memory Module）：金手指两面独立触点。相对的 SIMM 两面是同一组信号，早已淘汰。

| 类型 | 尺寸 | 用途 |
| --- | --- | --- |
| **UDIMM** | 全长 133.35 mm | 台式机标准，无缓冲 |
| **SO-DIMM** | 半长 67.6 mm | 笔记本、迷你主机、一体机 |
| **RDIMM** | 全长 | 服务器，带寄存器缓冲，可插更多条 |
| **LRDIMM** | 全长 | 服务器，负载削减，支持超大容量 |
| **MRDIMM** | 全长 | 服务器新形态，多路复用提升带宽 |

**ECC**（Error Correcting Code）：多一颗颗粒存校验位，能纠正单比特错误、检测双比特错误。服务器标配。AMD AM5 消费级平台**支持 ECC UDIMM**（需主板配合），Intel 消费级通常锁定。

## 2. DDR 代际对比

| 代 | 年份 | 电压 | 常见速率 (MT/s) | 单条容量 | 引脚(UDIMM) | 关键变化 |
| --- | --- | --- | --- | --- | --- | --- |
| DDR3 | 2007 | 1.5 / 1.35V | 800–2133 | 1–8 GB | 240 | — |
| DDR4 | 2014 | **1.2V** | 2133–3200（超频 4000+） | 4–32 GB | **288** | 电压降低，容量翻倍 |
| **DDR5** | 2020 | **1.1V** | 4800–8400+ | 8–64 GB | **288**（缺口位置不同） | 见下 |
| DDR6 | 制定中 | 更低 | 预期 8800 起步 | — | — | 预计 2027+ |

### DDR5 相对 DDR4 的三个结构性变化

1. **单条内部拆成两个独立 32 位子通道**（DDR4 是一个 64 位通道）
   → 并行度提升，即使插一条也有「双子通道」效果。
2. **PMIC 上板**：供电管理芯片从主板挪到内存条上，供电更精准干净，也是 DDR5 条子更贵的原因之一。
3. **片上 ECC（On-die ECC）**：这是**颗粒内部的**纠错，用于保证密度提升后的良率，**不等于**服务器级的端到端 ECC。买 DDR5 不代表你有 ECC 保护。

### 防呆缺口

DDR3 / DDR4 / DDR5 的金手指缺口位置各不相同，**物理上插不进错误的槽**。这是硬件级防呆，不用担心插错。

但要注意：**LGA1700 平台有 DDR4 版和 DDR5 版两种主板**，买主板时必须和内存对应。AM5 和 LGA1851 只支持 DDR5。

## 3. 通道、Rank、Bank

### 3.1 内存通道

```
单通道:   CPU ──64bit── DIMM              带宽 ×1
双通道:   CPU ──64bit── DIMM A            带宽 ×2  ← 消费级标配
          CPU ──64bit── DIMM B
四通道:   HEDT / Threadripper              带宽 ×4
八/十二通道: EPYC / Xeon                    带宽 ×8~12
```

**双通道能带来多少提升**：内存带宽敏感的场景（核显游戏、大型编译、视频编码）**提升 20–50%**；纯 CPU 计算型任务提升较小。**核显用户尤其必须双通道**，因为核显没有独立显存，全靠系统内存。

### 3.2 插哪两个槽？

四槽主板的正确插法是 **A2 + B2**（从 CPU 数起的第 2 和第 4 个槽）：

```
CPU  [A1] [A2] [B1] [B2]
           ▲         ▲
        插这两个
```

原因是主板内存走线多为**菊花链（Daisy Chain）**拓扑，A2/B2 位于链路末端，信号反射最小，能达到最高频率。

**说明书优先**：少数主板用 T 型拓扑（Mini-ITX 两槽板常见），插法不同。**翻主板说明书是唯一可靠做法**。

### 3.3 Rank

一个 Rank = 一组能同时被访问的 64 位（DDR5 是 2×32 位）颗粒。

| | 特点 |
| --- | --- |
| **单 Rank (1R)** | 更容易超高频，兼容性好 |
| **双 Rank (2R)** | 有约 **3–5%** 的性能优势（Rank 交错访问），但对内存控制器压力大，难超高频 |

**内存控制器负载递增顺序**：2 条 1R < 2 条 2R < 4 条 1R < 4 条 2R。

**这就是「插满 4 条要降频」的原因**——DDR5 平台上插 4 条双面条，可能只能跑到 4400–5200，还不如插 2 条跑 6000。

### 3.4 容量选择（2026 基准）

| 用途 | 最低 | 舒适 | 说明 |
| --- | --- | --- | --- |
| 办公 / 网页 | 16 GB | 16 GB | Chrome 吃内存 |
| 游戏 | 16 GB | **32 GB** | 2026 年 32GB 已是主流游戏舒适线 |
| 编程 / 虚拟机 | 32 GB | 64 GB | Docker + IDE + 浏览器 |
| 视频剪辑 4K | 32 GB | 64 GB | 时间线预览吃内存 |
| 本地跑大模型 | 32 GB | **64–128 GB** | 70B 模型 Q4 量化约需 40GB+ |

**2026 年的额外考虑**：AI 需求推高了 DRAM 价格。如果预算允许，**一次插到位比以后加条更划算**，而且避免了 4 条插满的降频问题。

## 4. XMP / EXPO：不开等于白买

内存条出厂默认按 **JEDEC 标准频率**运行（DDR5 通常是 4800），你买的 DDR5-6000 不开预设就只跑 4800。

| 名称 | 阵营 | 说明 |
| --- | --- | --- |
| **XMP 3.0** | Intel（AMD 板也大多能读） | Extreme Memory Profile |
| **EXPO** | AMD | 针对 AM5 优化的预设，通常包含更好的次时序 |

**装完机第一件事**：进 BIOS → 找到 XMP/EXPO/DOCP → 选 Profile 1 → 保存重启。

### AM5 平台的频率甜点

AM5 有一个必须知道的机制：

```
FCLK (Infinity Fabric)  ──┐
UCLK (内存控制器)        ──┼── 三者同步 (1:1:1) 时延迟最低
MCLK (内存实际频率)      ──┘

DDR5-6000  → FCLK 2000 / UCLK 3000，1:1 同步 ✅ 甜点
DDR5-6400+ → 内存控制器可能掉到 1:2 异步     ❌ 延迟惩罚吃掉带宽收益
```

所以 **AM5 上 DDR5-6000 CL30 通常比 DDR5-7200 更快**。这是反直觉但被反复验证的结论。

Intel LGA1851 对分频边界不敏感，可以直接上 6400–8000，Z890 双槽板能更高。

## 5. CAMM2：三十年来第一次形态革新

### 5.1 SO-DIMM 的困境

笔记本用了三十年 SO-DIMM，现在撑不住了：

- 金手指 + 插槽引入的电气不连续，让 SO-DIMM 很难稳定跑过 DDR5-6400。
- 双槽 SO-DIMM 需要垂直堆叠空间，和超薄本冲突。
- 想要更高频率只能焊死 LPDDR5X 上板，但那样就**不可升级、不可维修**。

### 5.2 CAMM2 的解法

**CAMM2**（Compression Attached Memory Module）：**平铺贴装 + 螺丝压紧**，不是插进槽里。

```
SO-DIMM（垂直插）              CAMM2（水平压）
     ┌────┐  ┌────┐
     │    │  │    │           ┌───────────────────┐
     │条1 │  │条2 │           │   CAMM2 模块       │
     └─┬──┘  └─┬──┘           └───────────────────┘
    ═══╧═══════╧═══           ═══════════════════════
       主板                       主板（螺丝压紧触点）
    占高度，走线长              超薄，走线极短
```

| 优势 | 说明 |
| --- | --- |
| **走线极短** | 消除插槽电气不连续，频率上限大幅提高 |
| **更薄** | 厚度约 SO-DIMM 双条堆叠的一半，适合超薄本 |
| **单模块双通道** | 一块 CAMM2 就是完整双通道，不用配对 |
| **可升级** | 相比焊死的 LPDDR5X，保留了维修和升级能力 |
| 散热更好 | 平铺贴合底板 |

### 5.3 三种形态

| 名称 | 用的颗粒 | 目标市场 |
| --- | --- | --- |
| **CAMM2** | 标准 DDR5 | 台式机 / 工作站 / 笔记本 |
| **LPCAMM2** | LPDDR5X（低功耗） | 轻薄本 ⭐ 落地最快 |
| **SOCAMM / SOCAMM2** | LPDDR5X | AI 服务器（NVIDIA 在其 AI 平台上推动） |

**现状**：LPCAMM2 已在部分高端笔记本落地（如联想 ThinkPad 部分型号）。台式机 CAMM2 主板还是极少数尝鲜产品，**短期内 UDIMM 仍是绝对主流**。

## 6. 常见误区

- ❌ **「DDR5 有 On-die ECC，所以有 ECC 保护」** → ✅ 片上 ECC 只保护颗粒内部，纠正的是密度提升带来的固有错误。数据在总线上传输时的错误它管不了。真 ECC 需要 ECC 内存条 + 平台支持。
- ❌ **「频率越高越好」** → ✅ 看**真实延迟 = CL ÷ 频率 × 2000 (ns)**。DDR5-6000 CL30 = 10 ns；DDR5-7200 CL38 = 10.6 ns，后者反而更慢。AM5 上还要考虑 1:1 分频。
- ❌ **「插满 4 条更快」** → ✅ 双通道平台插 4 条不会变成四通道，只会增加内存控制器负载导致降频。想要 32GB，买 2×16 而不是 4×8。
- ❌ **「不同品牌内存不能混插」** → ✅ 能，但不同批次/时序/Rank 的条子混插会自动按最低规格运行，且稳定性下降。**尽量买套装（Kit）**，套装是配对测试过的。
- ❌ **「内存条上的散热马甲有用」** → ✅ 对 DDR5 有一点用（PMIC 会发热），但主要是外观件。真正需要散热的是超高频超压场景。
- ❌ **「XMP 会损坏内存」** → ✅ XMP 是厂商标定的预设，在质保范围内。理论上属于超频，但业界普遍认可。
