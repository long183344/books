# 04 · USB 3.x 接口与 U 盘详解（命名 / 控制器 / 带宽 / 部署避坑）

> 本篇整理自一份关于「USB 3.x 版本规范与主机控制器」的内部资料，并在其基础上**大幅扩展**：补齐连接器形态与颜色编码、编码开销与真实速率、USB 拓扑与传输类型、UASP/文件系统、USB PD 供电、USB4/雷电关系，以及**工业视觉相机**场景下 USB 与其他接口的选型对比。
>
> **一句话核心**：USB 的"乱象"几乎都来自 USB-IF 的商业改名营销——市面上 95% 标着"USB3.2"的普通 U 盘，本质还是 5Gbps 的 Gen 1（原 USB 3.0）。**最终速率 = 接口、线材、设备三者共同决定的最小值**，而工业多相机部署的最大坑是「同根集线器共享带宽」。

---

## 0. 全景速览（先建立全局观）

```
USB 世界三大问：
┌─────────────────────────────────────────────────────┐
│ 1. 这口/这根线/这设备到底是多快？  → 看 Gen 代际 + 颜色 │
│ 2. 为什么插上了却跑不满？          → 接口/线材/设备三者短板 │
│ 3. 多设备一起用为什么掉帧掉速？    → 同根集线器带宽共享    │
└─────────────────────────────────────────────────────┘
```

三个铁律（贯穿全文）：
1. **命名看 Gen，不看成名**：USB 3.2 ≠ 10Gbps，得看 Gen 1 / Gen 2 / Gen 2×2。
2. **速率取三者最小值**：接口速率、线材速率、设备速率，木桶效应。
3. **带宽按根集线器算，不按口算**：同一条根集线器下的所有设备共享总带宽。

## 1. USB 3.x 命名体系与带宽标准

### 1.1 命名乱象：USB-IF 的改名历史

USB 实施者论坛（USB-IF）为了营销，把原 `USB 3.0`、`USB 3.1` **统一并入 USB 3.2 体系**，只用"代（Gen）"区分速率。厂商宣传时往往只写"USB3.2"不标 Gen 级别，于是：
- 你以为的"USB 3.2"可能只是 5Gbps（Gen 1，原 USB 3.0）；
- 真正的 10Gbps 是 Gen 2，20Gbps 是 Gen 2×2。

### 1.2 版本规格对照表（含编码与真实速率）

| 官方正式命名 | 旧版俗称 | 理论带宽 | 编码方式 | **真实有效带宽** | 典型接口颜色 | 常见设备 |
| --- | --- | --- | --- | --- | --- | --- |
| USB 3.2 Gen 1 | USB 3.0 / 3.1 Gen 1 | 5 Gbps | 8b/10b | **≈ 400 MB/s** | 蓝色 USB-A | 普通 U 盘、入门工业相机、键鼠、读卡器 |
| USB 3.2 Gen 2 | USB 3.1 Gen 2 | 10 Gbps | 128b/132b | **≈ 900~1000 MB/s** | 红/青 USB-A、Type-C | 高速固态 U 盘、高端工业相机、移动固态盘 |
| USB 3.2 Gen 2×2 | USB 3.2 | 20 Gbps | 128b/132b | **≈ 1800~2000 MB/s** | 仅 Type-C 双通路 | 高端移动固态盘，消费级 U 盘极少 |

> **编码开销说明**：Gen 1 用 8b/10b（每 8 位数据塞 10 位线码），约 20% 损耗，所以 5Gbps 实际 ≈ 400MB/s；Gen 2/2×2 用 128b/132b（≈3% 损耗），10Gbps 实际 ≈ 1GB/s。**"约 500MB/s / 1000MB/s / 2000MB/s"是省略编码损耗后的粗略值，真实有效值略低。**

**核心结论**：市面上 95% 以上标注"USB3.2"的普通 U 盘，本质都是 **USB 3.2 Gen 1（原 USB 3.0）**，只是改名营销，并非 10Gbps 高速规格。

### 1.3 向下兼容规则

所有 USB 接口向下兼容低版本设备，但**速率以最低规格为准**：
- USB 3.2 接口插 USB 2.0 设备 → 自动降至 480 Mbps（≈ 60 MB/s）；
- USB 3.2 Gen 2 设备插 Gen 1 接口 → 自动降至 5 Gbps。

> **协议兼容 ≠ 性能不变**。接口、线材、设备三者共同决定最终速率（见第 6 节）。

## 2. USB 连接器形态与颜色编码（扩展）

### 2.1 常见连接器

| 接口形态 | 特点 | 常见场景 |
| --- | --- | --- |
| **USB-A** | 扁长方形，防呆单向，最普及 | 主机后置/前置口、U 盘、键鼠 |
| **USB-B** | 方口，打印机/老式设备 | 外设（渐淘汰） |
| **Micro-B** | 小口，老安卓/移动硬盘 | 早期移动设备 |
| **Mini-B** | 更小，老设备 | 数码相机等（淘汰） |
| **USB-C（Type-C）** | 椭圆 reversible 双面插、体积小、可承载高功率与多协议 | 笔记本、手机、 Gen 2×2 / USB4 / 雷电 |

> **USB-C 不只是形状**：它支持 Alternate Mode，可在同一口上跑 DisplayPort、雷电、USB4 等，是"万能口"的物理基础。

### 2.2 接口颜色含义（快速辨速）

| 颜色 | 通常含义 |
| --- | --- |
| 黑 / 白 | USB 2.0（480 Mbps） |
| 蓝 | USB 3.2 Gen 1（5 Gbps） |
| 红 / 青 / 黄绿 | USB 3.2 Gen 2（10 Gbps）或厂商定制高速口 |
| 黄 / 橙 | 关机充电口（Always-On，可给手机充电） |

> 颜色只是"通常"，**不是强制标准**，最终以设备规格书为准。

## 3. USB 可扩展主机控制器（xHCI）原理解析

### 3.1 什么是 xHCI

设备管理器中显示的 `Intel(R) USB 3.20 可扩展主机控制器`，全称 **eXtensible Host Controller Interface（xHCI，可扩展主机控制器接口）**，是主板上集成的 USB 硬件控制芯片的 Windows 驱动程序。

**"可扩展"的含义**：
- **统一管理全速率**：同一控制器同时支持 USB 1.1 / 2.0 / 3.2 Gen1/Gen2，无需像旧平台那样分设多个控制器；
- **支持端口扩展**：通过根集线器（Root Hub）挂载多个物理端口，也可外接 USB Hub 扩展数量。

### 3.2 与旧一代控制器的区别

| 控制器类型 | 对应 USB 版本 | 架构特点 |
| --- | --- | --- |
| UHCI / OHCI | USB 1.1 | 低速专用控制器，已淘汰 |
| EHCI | USB 2.0 | 高速专用控制器，老平台与 UHCI 并存 |
| **xHCI** | USB 2.0 / 3.x 全兼容 | 新一代统一控制器，支持电源管理、更高带宽、更多端口 |

### 3.3 设备管理器中的 USB 层级结构

设备管理器的树状结构对应真实硬件层级：
```
通用串行总线控制器
└── Intel USB 3.20 可扩展主机控制器   （主板芯片：xHCI 硬件）
    └── USB 根集线器(USB 3.0)          （Root Hub：对应一组物理 USB 端口）
        ├── USB Composite Device       （外接设备：工业相机/复合设备）
        ├── USB Composite Device
        └── ……
```

### 3.4 常见误区：控制器 ≠ 物理接口

- **1 个 xHCI 控制器可以管理 6~16 个甚至更多物理 USB 端口**，并非 1 控制器对应 1 接口；
- 控制器支持 USB 3.2 Gen 2，**不代表主板上所有物理口都支持 Gen 2**。主板厂商常按成本阉割：多数台式机仅 Type-C 口支持 Gen 2，蓝色 USB-A 普遍为 Gen 1（5Gbps）。

## 4. 电脑物理 USB 接口数量与分布

### 4.1 主流设备接口数量

| 设备类型 | 物理 USB 接口总数 | 接口分布 |
| --- | --- | --- |
| 台式机（主流主板） | 6~12 个 | 主板后置 4~8 个（为主），机箱前置面板引出 2~4 个 |
| 笔记本 | 3~6 个 | 机身两侧，含 Type-C 与 USB-A |

### 4.2 根集线器（Root Hub）与物理端口的对应关系

- 一个 xHCI 控制器下通常有 **1~2 个 USB 3.0 根集线器**，每个根集线器对应一组物理端口；
- **同一条根集线器下的所有设备共享控制器带宽**，这是工业多相机场景的核心性能瓶颈；
- 可在设备管理器右键「USB 根集线器 → 属性 → 电源」，查看该集线器支持的端口数与已连接设备。

### 4.3 不可见的端口占用

主板内置设备也会占用 USB 控制器端口，不体现在外部接口上：
- 内置蓝牙模块、无线网卡；
- 主板声卡、RGB 控制器；
- 笔记本内置摄像头、读卡器。

## 5. USB 拓扑与传输类型（扩展）

### 5.1 分层星型拓扑

```
Host (xHCI 控制器)
  └── Root Hub（根集线器，对应一组物理口）
        ├── Device A
        ├── Hub（外接扩展）
        │     ├── Device B
        │     └── Device C
        └── Device D
```

层级最多 7 层（tiered star），级联越多损耗越大（见 4.2、6.3）。

### 5.2 四种传输类型

| 类型 | 特点 | 典型用途 |
| --- | --- | --- |
| 控制传输 Control | 可靠、双向、用于枚举配置 | 设备识别、命令 |
| 批量传输 Bulk | 可靠、无带宽保证、占空闲带宽 | U 盘、打印机（数据量大且可重传） |
| 中断传输 Interrupt | 低延迟、小包轮询 | 键鼠、HID |
| 等时传输 Isochronous | 实时、不重传、允许丢包 | 摄像头、音频（流数据） |

> **工业相机走的是等时传输（Isochronous）**——要的是稳定实时带宽，宁可丢帧也不重传（重传会让整帧延迟）。这正是"带宽共享会掉帧"的底层原因。

## 6. USB 3.2 U 盘的性能生效条件与瓶颈

### 6.1 标称"USB3.2"的两种 U 盘

- **普通 USB 3.2 Gen 1 U 盘（5Gbps）**：最常见，蓝色 USB-A，价格低。闪存本身读写多为 30~200 MB/s，**远低于接口带宽上限，闪存颗粒是瓶颈**。
- **高速 USB 3.2 Gen 2 U 盘（10Gbps）**：多为 Type-C 或双接口，采用固态主控，读写 500~1000 MB/s，**接口规格是瓶颈，必须搭配 Gen 2 接口才能跑满**。

### 6.2 不同场景下的性能表现

| U 盘类型 | 插入 USB 2.0 口 | 插入 Gen 1 口 | 插入 Gen 2 口 |
| --- | --- | --- | --- |
| USB 3.2 Gen 1 U 盘 | 降速至 USB2（≈60MB/s），严重浪费 | 完全发挥，比 USB2 快 3~5 倍 | 无提升，接口过剩 |
| USB 3.2 Gen 2 U 盘 | 降速至 USB2，严重浪费 | 降至 5Gbps，仅发挥一半 | 完全发挥 10Gbps |

### 6.3 常见的"无效"场景

1. 插入黑色 USB 2.0 接口：强制降速 480Mbps，3.2 规格完全失效；
2. 劣质机箱前置面板：线材差、信号衰减，可能降为 USB2 模式或频繁丢包；
3. 多级外接 USB Hub：级联越多损耗越大，工业场景不推荐；
4. Gen 2 U 盘插 Gen 1 接口：带宽减半，高速特性无法体现。

### 6.4 如何自测实际协商速率

```
设备管理器 → 通用串行总线控制器 → USB 根集线器
右键对应根集线器 → 属性 → 高级
查看"速度"字段：
  480 Mbps  = USB 2.0
  5 Gbps    = USB 3.2 Gen 1
  10 Gbps   = USB 3.2 Gen 2
```

### 6.5 UASP 协议与文件系统（扩展）

- **UASP（USB Attached SCSI Protocol）**：让 U 盘/移动盘走 SCSI 指令集，支持命令排队与多并发，**比传统 BOT（Bulk-Only Transport）快 20%~50%**。Win10+ 默认支持，设备需固件支持。
- **文件系统限制**：
  - FAT32：兼容性最好，但**单文件 ≤ 4GB**（传大文件会失败）；
  - exFAT：突破 4GB，跨平台（Win/Mac/安卓）首选；
  - NTFS：Win 原生，Linux/Mac 读写需额外驱动。

## 7. USB 供电与 PD（扩展）

| 规范 | 最大功率 | 说明 |
| --- | --- | --- |
| USB 2.0 / 3.x 基础 | 5V / 0.5A ~ 0.9A（2.5~4.5W） | 普通口带不动大负载 |
| BC 1.2 / 充电口 | 5V / 1.5A（7.5W） | 黄色口常标 |
| **USB PD 3.0/3.1** | 最高 100W / 240W（EPR） | 通过 CC 线协商升压，笔记本/手机快充 |
| 关机充电（Always-On） | 黄/橙口 | 关机也能给手机充电 |

> USB-C + PD 让一个口既能传 10/20Gbps 数据，又能 100W 供电，是"一线连"的基础（见第 8 节 USB4）。

## 8. USB4 与雷电的关系（扩展）

- **USB4** 基于英特尔雷电 3（Thunderbolt 3）协议，带宽 **40 Gbps**，统一走 USB-C 口；
- **雷电 3/4** 也走 USB-C，雷电 4 强制要求 40Gbps + 供电 + 双 4K 显示；
- USB4 设备可兼容雷电 3，但厂商可选是否支持；**USB4/雷电都向下兼容 USB 3.x/2.0**；
- 关系一句话：**USB4 = 雷电 3 的开放版 + 兼容 USB/PCIe 隧道**，物理上都长 USB-C 的样子。

## 9. 工业视觉场景 USB 部署避坑指南

### 9.1 核心问题：同根集线器带宽共享

同一根集线器下的所有 USB 3.x 设备**共享 5Gbps/10Gbps 总带宽**，多台工业相机同时采集时会出现：
- 帧率下降、画面丢帧；
- 图像传输延迟不稳定；
- 极端情况下设备掉线。

### 9.2 多工业相机部署原则

1. **分散挂载**：多台相机分别插到不同根集线器对应的物理端口（通常主板后置上下排分属不同集线器），避免带宽争抢；
2. **优先直连后置口**：主板后置口直接焊在主板上信号最稳，尽量不用机箱前置口和外接 Hub；
3. **带宽核算**：单台 5Gbps 相机满载约占用 300~400 MB/s，同一根集线器下建议**不超过 2 台高分辨率相机**。

### 9.3 USB Composite Device 复合设备说明

设备管理器中出现的 `USB Composite Device`（USB 复合设备），指一个物理 USB 接口同时枚举多个逻辑功能，工业设备常见：
- 工业相机：图像采集 + 虚拟串口（控制云台/光源）；
- USB 转多路串口设备；
- 带声卡的 USB 摄像头。

> **注意**：禁用或卸载复合设备会导致所有功能同时失效，调试时**请勿单独删除子设备**。

### 9.4 工业相机接口选型对比（扩展，呼应机器视觉硬件专题）

| 接口 | 带宽 | 最长距离 | 抗干扰 | 成本 | 适用 |
| --- | --- | --- | --- | --- | --- |
| USB 3.2 Gen 1/2 | 5/10 Gbps | 被动线 ≤ 3m（主动线可达 10m+） | 中（易受干扰） | 低 | 近距离单/双相机、实验室 |
| **GigE** | 1 Gbps（可多口聚合） | 100m（网线） | 强 | 中 | 远距离、多相机、工厂现场 |
| 10GigE | 10 Gbps | 100m | 强 | 较高 | 高分辨率远程 |
| Camera Link | 最高 850 MB/s | ≤ 10m | 强 | 高 | 超高速、线阵相机 |
| CoaXPress | 最高 12.5 Gbps/通道 | 数十米（同轴） | 强 | 高 | 高速高分辨、医疗/航天 |

> **选型口诀**：近距省钱上 USB3，远距抗干扰上 GigE，超高速上 Camera Link / CoaXPress。USB 的优势是"免网卡、即插即用、成本低"，劣势是距离短、易干扰、多设备要算根集线器带宽。

## 10. 常见误区（十大坑）

1. **"USB3.2"=10Gbps**：错，大概率是 Gen 1（5Gbps）。
2. **插上就满速**：接口/线材/设备三者短板决定速率。
3. **控制器支持 Gen2 = 所有口都 Gen2**：主板常阉割，仅 Type-C 是 Gen2。
4. **前置面板随便用**：劣质前置线会降速/丢包，工业用直连后置。
5. **多相机插一个 Hub 扩展**：级联越多损耗越大，且共享带宽。
6. **U 盘传 4GB+ 文件失败**：FAT32 单文件 ≤4GB，换 exFAT。
7. **USB2 黑口插高速盘**：强制 480Mbps，高速特性全废。
8. **禁用复合设备的某个子设备**：会连带整个设备失效。
9. **只看理论带宽**：编码开销让真实值低 3%~20%。
10. **USB-C = 高速**：USB-C 也能跑 USB2，速率看里面走的协议。

## 12. 一页纸决策表

| 你的需求 | 怎么选 |
| --- | --- |
| 普通存文件/传小文件 | 蓝色 Gen 1 U 盘足够（便宜） |
| 传大文件/做系统盘 | Gen 2 固态 U 盘 + Type-C Gen2 口 + exFAT |
| 工业单相机近距离 | USB3 Gen1/2 直连后置口 |
| 工业多相机/远距离 | 上 GigE 或更高速接口，分散根集线器 |

| 手机/设备快充 | 支持 USB PD 的 Type-C 口 |
