# 扩展与存储接口

> **一句话结论**：**插得进去 ≠ 能用**。M.2 有键位之分、USB-C 有协议之分、同一个槽位可能只走 SATA 不走 NVMe——物理兼容和协议兼容是两件事。
> **数据基准**：2026-08 ｜ **难度**：入门→进阶 ｜ **前置**：[PCIe 演进与代际对比](../总线/02-PCIe演进与代际对比.md)

---

## 1. PCIe 插槽（物理）

| 槽位 | 长度 | 触点 | 常见用途 |
| --- | --- | --- | --- |
| x1 | 25 mm | 36 | 声卡、网卡、USB 扩展卡 |
| x4 | 39 mm | 64 | M.2 转接卡、万兆网卡、RAID 卡 |
| x8 | 56 mm | 98 | 少见于消费级 |
| **x16** | 89 mm | 164 | 显卡（也常用于电气 x4/x8 的槽） |

**关键规则**：

- **物理长度 ≠ 电气通道数**。x16 长槽可能只接了 x4 通道。看主板规格里写的 `PCIE_2 (x16 slot, x4 mode)`。
- **短卡可插长槽**，x1 卡插 x16 槽完全正常。
- **长卡插短槽**需要「开口槽」（open-ended，尾部没有挡板），否则插不进去。
- **显卡固定槽**（带金属加固）只是防止显卡下垂，和速度无关。

## 2. M.2：最容易踩坑的接口

### 2.1 尺寸命名

`2280` = 宽 22 mm × 长 80 mm。

| 规格 | 长度 | 说明 |
| --- | --- | --- |
| 2230 | 30 mm | 掌机（Steam Deck、ROG Ally）、无线网卡 |
| 2242 | 42 mm | 部分笔记本 |
| 2260 | 60 mm | 少见 |
| **2280** | 80 mm | ⭐ 台式机绝对主流 |
| 22110 | 110 mm | 企业级（多一颗掉电保护电容） |

### 2.2 键位（Key）—— 核心知识点

金手指上的缺口位置决定了走什么协议：

| 键位 | 缺口位置 | 支持协议 | 常见设备 |
| --- | --- | --- | --- |
| **M Key** | 右侧单缺口 | **PCIe ×4** | ⭐ NVMe SSD 主流 |
| **B Key** | 左侧单缺口 | PCIe ×2 / SATA / USB | 老式 SSD、4G/5G 模块 |
| **B+M Key** | **双缺口** | PCIe ×2 或 SATA | 兼容性最好，但速度受限 |
| **A / E Key** | 左侧 | PCIe ×2 / USB / I²C | **Wi-Fi 网卡**（2230 尺寸） |

```
M Key（NVMe SSD）        B+M Key（兼容型）
════════════════▌▌      ═══▌▌═════════▌▌
              缺口          缺口      缺口
最多 4 lane，最快        最多 2 lane，或走 SATA
```

### 2.3 三大陷阱

**陷阱一：SATA 版 M.2**
外形完全一样（通常是 B+M Key），但走 SATA 协议，速度上限 **550 MB/s**，比 NVMe 慢十几倍。买之前看清楚标的是 NVMe 还是 SATA。

**陷阱二：槽位协议不同**
同一块主板上：
- M.2_1 走 PCIe 5.0 ×4（CPU 直连）
- M.2_2 走 PCIe 4.0 ×4（芯片组）
- M.2_3 **只支持 SATA**

把好盘插错槽位，速度直接腰斩。

**陷阱三：共享与禁用**
插满 M.2 会自动禁用某些 SATA 口，或者让显卡从 x16 降到 x8。**看说明书的共享表**。

### 2.4 安装

- 现代主板多有**免工具卡扣**（EZ-Latch / Q-Latch），不需要找那颗容易丢的小螺丝。
- **散热片必装**。Gen4/Gen5 SSD 满载温度轻松破 70°C，触发温度墙后速度暴跌。主板自带的散热片撕掉导热垫上的保护膜再装（很多人忘了这一步）。

## 3. SATA 与企业级存储接口

| 接口 | 速率 | 现状 |
| --- | --- | --- |
| SATA III | 6 Gbps（**实际约 550 MB/s**） | 仍是 2.5" SSD 和机械硬盘标准，十几年没升级过 |
| SAS | 12/24 Gbps | 企业级，支持双端口冗余、更长线缆 |
| **U.2 / U.3** | PCIe ×4 | 2.5" 形态的 NVMe，企业级热插拔 |
| **EDSFF (E1.S/E1.L/E3)** | PCIe ×4~×8 | 数据中心新形态，散热和密度更优，**正在取代 U.2** |

**SATA 为什么不升级**：NVMe 已经全面接管高性能场景，SATA 的定位退化为「大容量冷数据」，6 Gbps 对机械硬盘（约 200 MB/s）绰绰有余。

> 2025 年底 SNIA 启动了 **EDSFF E1.A** 规范，把数据中心 SSD 形态引入车用领域（增加锁定机构应对振动环境）——这个方向值得关注。

## 4. USB 与雷电：命名灾难区

### 4.1 USB 版本对照（历经多次改名）

| 现行名称 | 曾用名 | 速率 | 俗称 |
| --- | --- | --- | --- |
| USB 2.0 | — | 480 Mbps | High-Speed |
| **USB 5Gbps** | USB 3.0 → 3.1 Gen1 → 3.2 Gen1 | 5 Gbps | SuperSpeed |
| **USB 10Gbps** | USB 3.1 Gen2 → 3.2 Gen2 | 10 Gbps | SuperSpeed+ |
| **USB 20Gbps** | USB 3.2 Gen2×2 | 20 Gbps | 双通道 |
| **USB4 40Gbps** | USB4 Gen3×2 | 40 Gbps | 基于雷电 3 协议 |
| **USB4 80Gbps** | USB4 v2 | 80 Gbps（非对称可达 120） | 最新 |

USB-IF 已经把命名统一为「直接标速率」，因为之前的 Gen 命名把所有人都绕晕了。**认速率数字，不认版本号**。

### 4.2 Type-C 接口 ≠ 协议

**Type-C 只是物理形状**。同一个 C 口可能是：

| 能力 | 说明 |
| --- | --- |
| 仅 USB 2.0（480 Mbps） | 廉价设备常见，只能充电和传小文件 |
| USB 3.x（5/10/20 Gbps） | 常规 |
| USB4 / 雷电（40/80 Gbps） | 高端 |
| **DP Alt Mode** | 能输出显示信号 |
| **PD 供电** | 最高 240W（PD 3.1 EPR） |

**这就是为什么「同样是 C 口，有的能接显示器有的不能」**。看主板/笔记本规格上这个口标注的具体能力，或看接口旁边的小图标（闪电 = 雷电，D 字母 = DisplayPort）。

### 4.3 雷电 vs USB4

| | 雷电 3 | USB4 40Gbps | 雷电 4 | 雷电 5 |
| --- | --- | --- | --- | --- |
| 带宽 | 40 Gbps | 40 Gbps | 40 Gbps | 80/120 Gbps |
| PCIe 隧道最低保证 | 无强制 | **可选** | **32 Gbps 强制** | 更高 |
| 最低显示支持 | 1× 4K | 1× 显示 | **2× 4K 或 1× 8K** | 更高 |
| 支持外接显卡坞 | 是 | **不一定** | 是 | 是 |
| 认证 | Intel | USB-IF | Intel，严格 | Intel |

**核心区别**：USB4 把很多能力设为**可选**，雷电 4/5 把它们设为**强制**。所以「USB4 接口」不保证能带外接显卡坞或双 4K 屏，「雷电 4」保证。

**2026 主板现状**：AMD X870/X870E **强制要求 USB4**；Intel Z890 不强制，靠主板厂加雷电控制器实现。

## 5. 供电接口

| 接口 | 针数 | 供给 | 备注 |
| --- | --- | --- | --- |
| **ATX 主供电** | **24 pin** | 主板 | 早期是 20pin，现在 20+4 可拆 |
| **EPS CPU 供电** | 8 pin（或 8+8 / 8+4） | CPU VRM | 高端 CPU **必须插满**，否则限功耗 |
| PCIe 显卡供电 | 6 / 8 pin | 显卡 | 8pin = 150W，6pin = 75W |
| **12VHPWR** | 16 pin (12+4) | 高端显卡 | 最高 600W，早期有过热熔毁事故 |
| **12V-2×6** | 16 pin | 高端显卡 | 12VHPWR 的**改进版**，加长导电针、缩短检测针，未完全插入时不会供电 |
| SATA 供电 | 15 pin | SSD/HDD | — |
| 大 4pin (Molex) | 4 pin | 老设备、风扇集线器 | 逐渐淘汰 |

**12VHPWR 事故的教训**：接触不良导致局部电阻升高 → 发热 → 熔毁。**务必插到底听到咔哒声，且不要在接头附近急弯线材**（建议留出至少 35 mm 直线段）。12V-2×6 通过改变针脚长度从机械上解决了这个问题——没插到底就通不上电。

## 6. 显示输出接口

| 接口 | 版本 | 带宽 | 典型能力 |
| --- | --- | --- | --- |
| **HDMI** | 2.0 | 18 Gbps | 4K@60 |
| | 2.1 | 48 Gbps | 4K@120 / 8K@60 |
| **DisplayPort** | 1.4 | 32.4 Gbps | 4K@120（DSC 下更高） |
| | **2.1** | 80 Gbps | 8K@60 无压缩 / 4K@240 |
| **USB-C (DP Alt)** | 随 DP 版本 | — | 一线传视频 + 数据 + 供电 |
| VGA / DVI | — | — | 已淘汰 |

**选择建议**：PC 显示器优先 **DisplayPort**（带宽更高、支持 DSC 压缩、可菊花链）；电视和游戏主机用 **HDMI 2.1**（支持 eARC、VRR、ALLM）。

## 7. 常见误区

- ❌ **「M.2 都是 NVMe」** → ✅ 有 SATA 版 M.2，速度只有 1/10。看键位和产品标注。
- ❌ **「Type-C 都一样」** → ✅ 形状一样，能力可能从 480 Mbps 到 120 Gbps，差 250 倍。
- ❌ **「USB4 = 雷电 4」** → ✅ USB4 的很多能力是可选的，雷电 4 是强制的。外接显卡坞认雷电。
- ❌ **「x16 槽插 x1 卡浪费」** → ✅ 完全正常，通道会自动协商。
- ❌ **「12VHPWR 一定会烧」** → ✅ 事故主因是未完全插入。规范插好 + 用 12V-2×6 版本基本无虞。
- ❌ **「SSD 不用装散热片」** → ✅ Gen4/Gen5 必装。触发温度墙后持续写入速度可能掉到 1/3。
- ❌ **「M.2 装哪个槽都行」** → ✅ 系统盘装 **CPU 直连**的那个（通常是最靠近 CPU 的 M.2_1）。

## 8. 快速自检清单

装完机之后，花五分钟确认这几项：

```
□ BIOS 里开了 XMP / EXPO 吗？
□ SSD 在设备管理器 / lspci 里显示的链路速率对吗？（应该是 Gen4 x4 或 Gen5 x4）
□ 显卡跑在 x16 还是被降到 x8 了？（GPU-Z 能看）
□ M.2 散热片的导热垫保护膜撕了吗？
□ CPU 供电 8pin 插满了吗？
□ 12VHPWR 插到底听到咔哒声了吗？
□ 内存插在 A2/B2 了吗？双通道生效了吗？（任务管理器能看）
```
