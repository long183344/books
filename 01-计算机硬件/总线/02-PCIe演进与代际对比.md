# PCIe 演进与代际对比

> **一句话结论**：PCIe 每三年带宽翻倍，规范已经跑到 7.0（2025 年定稿），但**消费级用户在 5.0 上就已经开始过剩了**；真正影响你的不是代数，而是**通道够不够分**。
> **数据基准**：2026-08 ｜ **难度**：进阶 ｜ **前置**：[总线原理与分类](./01-总线原理与分类.md)

---

## 1. PCIe 基本模型

**PCIe 不是共享总线，是点对点的交换网络。**

```
                ┌──────┐
                │ CPU  │
                └──┬───┘
          Root Complex（根复合体，在 CPU 内）
        ┌──────────┼──────────┐
        │          │          │
    ┌───▼───┐  ┌───▼───┐  ┌───▼────┐
    │ x16   │  │ x4    │  │ 芯片组  │← DMI/上行链路
    │ 显卡  │  │ M.2   │  │(Switch)│
    └───────┘  └───────┘  └──┬─────┘
                       ┌─────┼─────┐
                    M.2_2  网卡   USB控制器
                       （共享上行带宽）
```

**Lane（通道）**：一条 lane = 2 对差分线（发送一对 + 接收一对，全双工）。
`x1 / x4 / x8 / x16` 表示用了几条 lane，带宽线性叠加。

## 2. 全代际带宽对照表

| 代 | 发布 | 速率/lane | 编码 | 有效带宽 x1（单向） | x4 | x8 | **x16** |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1.0 | 2003 | 2.5 GT/s | 8b/10b | 250 MB/s | 1 GB/s | 2 GB/s | 4 GB/s |
| 2.0 | 2007 | 5 GT/s | 8b/10b | 500 MB/s | 2 GB/s | 4 GB/s | 8 GB/s |
| 3.0 | 2010 | 8 GT/s | 128b/130b | ~985 MB/s | ~3.9 GB/s | ~7.9 GB/s | ~15.8 GB/s |
| 4.0 | 2017 | 16 GT/s | 128b/130b | ~1.97 GB/s | ~7.9 GB/s | ~15.8 GB/s | ~31.5 GB/s |
| 5.0 | 2019 | 32 GT/s | 128b/130b | ~3.94 GB/s | ~15.8 GB/s | ~31.5 GB/s | **~63 GB/s** |
| 6.0 | 2022 | 64 GT/s | **PAM4** + FLIT + FEC | ~7.5 GB/s | ~30 GB/s | ~60 GB/s | ~121 GB/s |
| **7.0** | **2025 定稿** | **128 GT/s** | PAM4 + FLIT + FEC | ~15 GB/s | ~60 GB/s | ~121 GB/s | **~242 GB/s** |
| 8.0 | 计划 2028 | 256 GT/s | 待定 | — | — | — | — |

> 官方常用「双向合计」宣传：PCIe 7.0 ×16 = **512 GB/s bi-directional**，即上表单向数字 ×2。看规格时注意区分。

### 编码方式的演变

| 编码 | 开销 | 用于 |
| --- | --- | --- |
| **8b/10b** | 20%（每 8 位数据发 10 位） | Gen1/2 |
| **128b/130b** | 1.5% | Gen3/4/5 |
| **PAM4 + FLIT + FEC** | 用 4 电平幅度调制，一个符号带 2 bit | Gen6/7 |

**PAM4 的代价**：4 个电平意味着信噪容限只有 NRZ 的 1/3，必须配 **FEC（前向纠错）**，而 FEC 会引入固定延迟。所以 Gen6/7 是「带宽翻倍、延迟略增」。

### 向下兼容

**双向完全兼容**。PCIe 5.0 显卡插在 3.0 插槽上能用，按 3.0 速率跑；反之亦然。链路会自动协商到双方支持的最高代数和最宽 lane 数。

## 3. 通道分配：真正影响你的部分

### 消费级 CPU 的通道预算（2026 桌面）

```
AMD AM5（Ryzen 9000）总计 28 条：
  ├─ 16 条 → 显卡（PCIe 5.0）
  ├─  4 条 → M.2_1 主固态（PCIe 5.0）
  ├─  4 条 → M.2_2 或分给显卡（视主板）
  └─  4 条 → 芯片组上行链路

Intel LGA1851（Core Ultra 200S）总计 24 条 PCIe 5.0 + 4 条 4.0：
  ├─ 16 条 → 显卡（5.0）
  ├─  4 条 → M.2_1（5.0）
  ├─  4 条 → M.2_2（5.0）
  └─  4 条 4.0 + DMI 5.0 ×8 → 芯片组

服务器（EPYC / Xeon 6）：96–160 条，完全不是一个量级
```

### 常见的拆分陷阱

| 情况 | 结果 |
| --- | --- |
| 在第二条 x16 长槽插卡 | 显卡从 x16 降到 **x8**（通道被对半分） |
| 插满第三、第四个 M.2 | 自动**关闭 2 个 SATA 口** |
| 用 CPU 直连 M.2_2 | 某些主板会把显卡降到 **x8** |
| 芯片组下挂多个高速设备 | 共享上行链路，同时使用时**互相抢带宽** |

> **必看**：主板说明书里的「PCIe 与 M.2 通道共享表」。这张表比任何评测都重要。

### x16 降到 x8 到底掉多少性能？

现代旗舰显卡在 PCIe 4.0 ×8（≈ 5.0 ×4）下，游戏帧数损失通常在 **1–3%**，只有在显存不够需要频繁走 PCIe 换页时才会明显掉帧。所以这个陷阱**知道就好，不必焦虑**。

真正会痛的是：把显卡插到芯片组下挂的槽位（有些 M-ATX 板会这样设计），那才是灾难。

## 4. Bifurcation（通道拆分）

把一条 x16 物理槽在电气上拆成多份：

```
x16 → x8/x8         装两张卡
x16 → x8/x4/x4      一张卡 + 两块 SSD
x16 → x4/x4/x4/x4   一张四盘位 M.2 转接卡
```

**要求**：CPU 支持 + 主板 BIOS 里有 Bifurcation 选项。中低端主板经常砍掉这个功能。

**用途**：用无芯片的廉价 M.2 转接卡（¥100 级）挂 4 块 SSD。如果主板不支持拆分，就得买带 PLX/PCIe Switch 芯片的贵卡（¥1000+）。

## 5. PCIe 5.0 / 7.0 在消费端有意义吗？

### 现实检查

| 设备 | 实际需要 | 说明 |
| --- | --- | --- |
| 旗舰显卡 | PCIe 4.0 ×16 绰绰有余 | 5.0 ×16 的收益接近于 0 |
| NVMe SSD | Gen4 就够 | Gen5 顺序读 14 GB/s，但日常是随机小文件，**几乎无感** |
| 网卡 | 100G 网卡才需要 Gen4 ×8+ | 消费级 2.5G/10G 用 ×1/×4 就够 |
| 采集卡 / RAID 卡 | ×4 – ×8 | 够用 |

**Gen5 SSD 的隐藏成本**：功耗更高（需要主动散热片，有的甚至带小风扇），温度墙更容易触发，实际持续写入不一定比好的 Gen4 盘快。

### PCIe 7.0 是给谁的

明确面向 **AI 加速器、HPC、超大规模数据中心、800G 以太网**。原因很直接：现代训练集群搬运的数据量下，PCIe 5.0 都是瓶颈。

**消费级什么时候能见到**：历史规律是规范定稿后 2–3 年落地消费级（Gen4 定稿 2017 / 落地 2019，Gen5 定稿 2019 / 落地 2021）。但 Gen6/7 的信号完整性挑战大得多——PCB 材料、重定时器成本都在飙升，桌面平台没有动力也没有必要跟进。**预计 Gen6 会在桌面停留很久甚至被跳过**。

## 6. 信号完整性：为什么再快就难了

速率越高，问题从「控制器设计」转移到「物理」：

- **走线损耗**：Gen5 时代，PCB 走线超过约 7–9 英寸就需要 **Retimer（重定时器）** 中继，一颗几十美元。
- **PCB 材料**：普通 FR-4 不够，要用低损耗材料，主板成本上升。
- **层数增加**：高端主板已经到 8–10 层甚至更多。
- **连接器**：金手指和插槽本身也成为损耗源。

这就是为什么 2026 年支持完整 PCIe 5.0 的主板会明显更贵，也是 PCIe 7.0 短期内不可能下放到消费级的根本原因。

**光互连是出路**：PCI-SIG 已成立光学工作组，探索让 PCIe 走光纤，突破铜缆的「带宽 × 距离」瓶颈。

## 7. 常见误区

- ❌ **「PCIe 5.0 SSD 让游戏加载快一倍」** → ✅ 游戏加载瓶颈在 CPU 解压和随机读，不在顺序带宽。Gen3 → Gen4 → Gen5 的加载时间差异通常在 5% 以内。
- ❌ **「x16 槽位就有 x16 通道」** → ✅ 物理长度 ≠ 电气通道数。很多 x16 长槽只接了 x4 电气通道（常见于第二、第三条槽）。
- ❌ **「x1 卡不能插 x16 槽」** → ✅ 能，向下兼容。反过来，x16 卡插 x1 槽需要「开口」槽位（open-ended）。
- ❌ **「所有 M.2 都是 PCIe」** → ✅ 有的 M.2 槽只走 SATA。看键位和主板规格（见 [接口笔记](../插槽与接口/03-扩展与存储接口.md)）。
- ❌ **「买主板要看 PCIe 5.0 支持」** → ✅ 对绝大多数人，Gen4 完全够用。这条钱花在 VRM 上收益更大。
