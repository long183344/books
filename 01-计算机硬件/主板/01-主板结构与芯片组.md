# 主板结构与芯片组

> **一句话结论**：主板不提供算力，但它决定了**你的 CPU 能不能跑满、你能插多少东西、以及这些东西会不会互相抢带宽**。
> **数据基准**：2026-08 ｜ **难度**：进阶 ｜ **前置**：[CPU 参数详解](../CPU/02-CPU参数详解与分类对比.md)

## 1. 板子上都有什么

```
┌─────────────────────────────────────────────────────┐
│  ┌──────┐                            ┌───────────┐  │
│  │24pin │     ┌──────────────┐       │  DIMM A1  │  │
│  │ ATX  │     │              │       │  DIMM A2  │  │
│  └──────┘     │  CPU Socket  │       │  DIMM B1  │  │
│  ┌──────┐     │              │       │  DIMM B2  │  │
│  │8pin  │     └──────────────┘       └───────────┘  │
│  │ EPS  │   [VRM 供电模块 + 散热片]    ↑             │
│  └──────┘                          内存插槽 ×4       │
│                                                      │
│  ┌────────────────────────────────┐   ┌──────────┐  │
│  │ PCIe x16 Slot 1（直连 CPU）    │   │  芯片组  │  │
│  └────────────────────────────────┘   │ PCH/FCH  │  │
│  ▭ M.2_1 (CPU 直连, Gen5)             └────┬─────┘  │
│  ┌──────────────┐                          │        │
│  │ PCIe x16(x4) │  ← 走芯片组               │        │
│  └──────────────┘                     SATA ×4 ┄┄┄┄  │
│  ▭ M.2_2  ▭ M.2_3 （走芯片组）        USB / LAN     │
│                                                      │
│  [后置 I/O: USB / 网口 / 音频 / 视频输出 / WiFi 天线]│
│  [CMOS 电池]  [前面板针脚]  [风扇接口]  [Debug LED]  │
└─────────────────────────────────────────────────────┘
```

## 2. VRM 供电：主板最重要、最少被提及的部分

CPU 需要约 **1.0–1.4V** 的极低电压、极大电流（250W ÷ 1.2V ≈ **208A**）。而 ATX 电源给的是 12V。把 12V 降到 1.2V 还要在纳秒级响应负载突变——这就是 VRM（Voltage Regulator Module）干的活。

### 结构

```
12V 输入 ──┬─ [PWM 控制器] 发出相位控制信号
           │
           ├─ 相位1: [MOSFET/DrMOS] → [电感] → [电容] ─┐
           ├─ 相位2: ...                               ├─→ CPU (VCore)
           ├─ 相位3: ...                               │
           └─ 相位N: ...                               ┘
```

**为什么要多相**：单相扛不住 200A，会烧。多相轮流导通，每相只承担 1/N 的电流，同时纹波更小、发热更分散。

### 怎么看规格

标注形如 `14+2+1`：

| 位置 | 供给 |
| --- | --- |
| 第 1 个数 | VCore（CPU 核心）相数 |
| 第 2 个数 | SoC / iGPU / 内存控制器 |
| 第 3 个数 | Misc（MISC、VDDIO 等） |

再看每相电流能力（如 **80A DrMOS**）。`14 相 × 80A` = 理论 1120A，远超需求，属于余量充足。

**关键提醒**：有些厂商用「倍相器」把 6 相拆成 12 相标注，实际响应能力不如真 12 相。看评测拆解比看数字靠谱。

### 为什么 VRM 决定性能

CPU 撞到电流墙就降频（回顾 [参数笔记的四堵墙](../CPU/02-CPU参数详解与分类对比.md)）。廉价 B 系列主板配旗舰 CPU，跑 Cinebench 十分钟后 VRM 过热降频，多核成绩可能掉 15–20%。

**VRM 散热片比 CPU 散热器更容易被忽视**，但对长期稳定性影响更大。

## 3. 芯片组：从南北桥到 PCH/FCH

### 3.1 演进史

```
【上古时期 ~2008】三芯片架构
   CPU ──FSB── 北桥(MCH) ──── 内存
                  │
                  │        显卡 AGP/PCIe
                  │
              南桥(ICH) ──── SATA / USB / PCI / 音频 / 网卡

【现代 2009~】两芯片架构
   CPU ┬── 内存控制器（吸进 CPU）
       ├── PCIe 控制器（吸进 CPU）→ 显卡、直连 M.2
       │
       └──DMI/链路── 芯片组（PCH / FCH）
                        └── SATA / USB / 额外 PCIe / 网卡 / 音频
```

**北桥消失了**：内存控制器（IMC）和 PCIe 根复合体被集成进 CPU，延迟大幅降低（内存延迟从 ~100ns 降到 ~70ns 量级），这是过去十几年最重要的架构变化之一。

**南桥变成了「芯片组」**：Intel 叫 **PCH**（Platform Controller Hub），AMD 叫 **FCH**（Fusion Controller Hub）。

### 3.2 上行链路：整块板子的隐藏瓶颈

芯片组挂着的所有设备（SATA、USB、多余的 M.2、网卡），共用一条通往 CPU 的链路。

| 平台 | 上行链路 | 等效带宽 |
| --- | --- | --- |
| Intel Z890 | DMI 5.0 ×8 | ≈ 32 GB/s（双向合计约 64） |
| AMD X870E | 双 PCIe 5.0 ×4 | ≈ 16 GB/s 总计 |
| AMD B850 | PCIe 4.0 ×4 | ≈ 8 GB/s |

**实际后果**：如果你在芯片组挂的 M.2 上跑一块 Gen4 SSD（7 GB/s），同时用 USB4 拷贝数据（40 Gbps ≈ 5 GB/s），在 B850 上就会互相抢带宽。**显卡和第一条 M.2 通常直连 CPU，不受这个限制**——这也是「主 M.2 槽位要装系统盘」的原因。

X670E / X870E 的「双芯片组」设计就是为了缓解这个问题：把两颗 Promontory 芯片串起来，提供更多 I/O，但注意串在后面那颗的带宽仍要经过前一颗。

## 4. 板型尺寸

| 板型 | 尺寸 (mm) | PCIe 槽 | DIMM 槽 | 适用 |
| --- | --- | --- | --- | --- |
| **E-ATX** | 305 × 330（不定） | 4–7 | 4–8 | 工作站、双路 |
| **ATX** | 305 × 244 | 3–5 | 4 | ⭐ 标准之选，扩展和散热最均衡 |
| **Micro-ATX** | 244 × 244 | 2–4 | 4 | 性价比之选，够用 |
| **Mini-ITX** | 170 × 170 | **1** | **2** | 小钢炮，代价是贵 + 难散热 + 扩展极少 |
| Mini-DTX | 170 × 203 | 2 | 2 | 少见 |

**Mini-ITX 的隐藏成本**：只有 2 条内存槽（好处是更容易上高频，因为走线短）、只有 1 条 PCIe x16、VRM 空间小散热压力大、同规格价格比 ATX 贵 30–50%。

## 5. BIOS / UEFI

| | 传统 BIOS | UEFI |
| --- | --- | --- |
| 分区表 | MBR，最大 2TB，4 主分区 | **GPT**，容量几乎无限 |
| 启动方式 | 16 位实模式，读 MBR | 读 EFI 系统分区里的 `.efi` 文件 |
| 界面 | 纯文本 | 图形化、可用鼠标 |
| 启动速度 | 慢 | 快（可跳过传统硬件自检） |
| 安全 | 无 | **Secure Boot**、TPM 集成 |
| 现状 | 已淘汰，仅保留 CSM 兼容模式 | 标准 |

**实用知识**：

- **Windows 11 要求 UEFI + Secure Boot + TPM 2.0**。TPM 通常由 CPU 内置固件提供（Intel PTT / AMD fTPM），在 BIOS 里打开即可，不需要买模块。
- **BIOS Flashback**（免 CPU 刷 BIOS）：新 CPU 配老主板时的救命功能。把 BIOS 文件放 U 盘，只插电源就能刷。买 AM5 老板配新 U 时**务必确认主板有这个功能**。
- **XMP / EXPO**：内存超频预设。不开的话 DDR5-6000 的条子只会跑在 JEDEC 标准的 4800，白买。**装完机第一件事就是进 BIOS 开这个**。

## 6. 常见误区

- ❌ **「主板不影响性能」** → ✅ VRM 决定 CPU 能否维持全核频率；内存走线布局（菊花链 vs T 型）决定内存能超多高；芯片组决定 I/O 带宽是否够分。
- ❌ **「贵的主板跑分更高」** → ✅ 轻载下没差别。差别出现在**长时间满载**和**内存超频上限**上。
- ❌ **「所有 M.2 槽都一样」** → ✅ 直连 CPU 的那个最快且独占带宽；芯片组槽位共享上行链路；某些槽位插满会自动关掉 SATA 口（看说明书的「共享表」）。
- ❌ **「插上就能用新 CPU」** → ✅ 同插槽也可能需要 BIOS 更新才能识别新代 CPU。
- ❌ **「4 条内存插满更好」** → ✅ 双通道平台插 2 条（A2 + B2 槽位）比插 4 条更容易上高频。插满 4 条通常要降频。
