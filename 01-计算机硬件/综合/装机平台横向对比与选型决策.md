# 装机平台横向对比与选型决策

> **一句话结论**：先定用途 → 定 CPU → 插槽和芯片组自动确定 → 剩下的钱按「显卡 > 内存容量 > 主板 VRM > 散热 > 其他」的顺序花。
> **数据基准**：2026-08 ｜ **难度**：入门 ｜ **前置**：本分类其他笔记（可先看这篇再回头查）

---

## 1. 先回答三个问题

```
Q1. 主要干什么？
    游戏 / 内容创作 / 编程开发 / 办公 / 本地 AI / 混合

Q2. 预算多少？（整机，不含显示器外设）

Q3. 三年内会想升级 CPU 吗？
    会 → 优先 AM5（插槽承诺到 2027+）
    不会 → 两家都行，比价
```

## 2. 平台总览

| 维度 | AMD AM5 | Intel LGA1851 |
| --- | --- | --- |
| CPU | Ryzen 7000 / 9000 | Core Ultra 200S |
| 架构 | 同构大核 + SMT | 混合 P/E core，无超线程 |
| 主流芯片组 | **B850** | **B860** |
| 旗舰芯片组 | X870 / X870E | Z890 |
| 内存 | 仅 DDR5，甜点 **6000 (1:1)** | 仅 DDR5，甜点 **6400+** |
| 超频门槛 | 全系可 PBO | 仅 Z890 + K |
| USB4 | X870/E 强制 | 需主板加控制器 |
| 游戏 | **X3D 断层领先** | 落后约 15–20% |
| 多核生产力 | 强 | E-core 堆料，部分负载领先 |
| 桌面 NPU | 弱 | **~48 TOPS** |
| 散热压力 | 温和 | 高负载需 360 水冷 |
| 插槽寿命 | ⭐⭐⭐ | ⭐ |

## 3. 按用途给结论

### 3.1 纯游戏

**结论：AMD X3D，没有悬念。**

理由：游戏的工作集能装进 96MB L3，3D V-Cache 带来 15–20% 的帧数提升，个别大地图/模拟类游戏 30%+。而且功耗低（游戏时约 80W vs Intel 140W），散热和电源都能省钱。

```
CPU     Ryzen 7 9800X3D（8C/16T，96MB L3）
主板    B850（¥1000–1600 档，14 相 VRM）
内存    DDR5-6000 CL30 × 2 条（32GB），开 EXPO
SSD     Gen4 1–2TB（Gen5 没必要）
散热    240 水冷或高端风冷即可
显卡    ← 剩下的钱全砸这里
```

> **关键**：游戏是显卡瓶颈。CPU 从 ¥2000 升到 ¥4000 可能只涨 5% 帧数，显卡同样加钱能涨 30%。**别在 CPU 上超支**。

### 3.2 内容创作（视频剪辑 / 3D 渲染）

**结论：看软件。**

| 软件类型 | 倾向 |
| --- | --- |
| Premiere / DaVinci（吃硬件编解码 + GPU） | Intel 核显的 QuickSync 编解码支持格式更全 |
| Blender / C4D（纯 CPU 渲染） | 核心数为王，AMD 多核性价比更高 |
| Photoshop / Lightroom（吃单核） | 两家差不多 |

```
CPU     Ryzen 9 9950X（16C/32T）或 Core Ultra 9 285K（24C）
主板    X870 / Z890（需要多 M.2 和 USB4 接外置存储）
内存    64GB（2×32），别插 4 条
SSD     系统 Gen4 1TB + 素材盘 2–4TB
散热    360 水冷（尤其 Intel）
```

### 3.3 编程 / 开发

**结论：核心数 + 内存容量，CPU 型号不敏感。**

编译是近乎完美的并行任务，核心数几乎线性加速。Docker、虚拟机、多个 IDE 同时开，内存是第一瓶颈。

```
CPU     12–16 核（9900X / 9950X / Ultra 7 265K）
内存    ⭐ 64GB 起（这是最重要的一项）
SSD     Gen4 2TB（node_modules 和构建缓存很吃空间）
主板    B850 / B860 够用
显卡    核显够用（除非做 GPU 相关开发）
```

### 3.4 办公 / 轻度使用

**结论：别超支，核显够用。**

```
CPU     Ryzen 5 8600G（强核显）或 Core Ultra 5 245
主板    B650 / B760 / B860 入门款
内存    ⭐ 16GB 双通道（核显必须双通道！）
SSD     Gen3/Gen4 512GB–1TB
显卡    核显
散热    原装散热器够用
```

### 3.5 本地跑 AI 大模型

**结论：内存容量 > 一切，NPU 是加分项。**

| 需求 | 配置 |
| --- | --- |
| 主要靠 GPU 推理 | 显存优先，CPU 随意，内存 ≥ 显存 × 1.5 |
| 主要靠 CPU/内存推理 | **内存容量 + 带宽是唯一瓶颈**，64–128GB |
| 想用 Windows Copilot+ 功能 | 需要 **NPU ≥ 40 TOPS** → Intel Arrow Lake 或 Ryzen AI 系列 |

参考：70B 模型 Q4 量化约需 40GB+；想跑 32K 上下文还要额外的 KV Cache 空间。

## 5. 不该省钱的地方

| 部件 | 为什么 |
| --- | --- |
| **电源** | 劣质电源纹波大，长期损伤所有部件，炸机时可能带走全套。认 80+ 金牌及以上，认一线品牌 |
| **内存容量** | 不够就是卡，加不了。而且 2026 年 DRAM 在涨价 |
| **主板 VRM** | 直接决定 CPU 能不能维持全核频率 |
| **机箱风道** | 便宜机箱风道差，所有部件都降频 |

## 6. 可以省钱的地方

| 部件 | 为什么 |
| --- | --- |
| **PCIe 5.0 SSD** | 日常几乎无感，还更热更贵。Gen4 是甜点 |
| **RGB 灯效** | 不影响性能 |
| **Wi-Fi 版主板** | 用网线的话省 ¥150–250 |
| **超高频内存** | AM5 上超过 6000 反而可能变慢 |
| **旗舰芯片组** | B850/B860 有旗舰 80% 的实际体验 |
| **CPU 超频** | 现代 CPU 出厂已接近极限，超频收益 3–5% |

## 7. 装机后必做检查

```
□ BIOS 开启 XMP / EXPO
□ 确认双通道生效（任务管理器 → 性能 → 内存 → "已使用插槽 2/4"）
□ 确认显卡跑在 PCIe x16（GPU-Z）
□ 确认 SSD 链路速率正确（CrystalDiskInfo / nvme list）
□ 撕掉 M.2 散热片的导热垫保护膜
□ 跑 30 分钟烤机，看 CPU 是否因 VRM 过热降频（HWiNFO）
□ MemTest86 跑一轮，排除内存问题
□ 更新芯片组驱动（AMD 芯片组驱动含调度器优化，必装）
```

## 8. 常见误区

- ❌ **「加钱升级 CPU 能提升游戏帧数」** → ✅ 1080p 高刷下 CPU 才是瓶颈；1440p/4K 下基本都是显卡瓶颈。先看自己的分辨率。
- ❌ **「电源功率越大越好」** → ✅ 电源在 50–80% 负载时效率最高。整机峰值 400W 配 850W 电源就够，买 1200W 是浪费。
- ❌ **「水冷一定比风冷强」** → ✅ 240 水冷和顶级风冷（NH-D15 级）性能接近。水冷的优势在于把热量直接排出机箱、以及内存槽附近空间更宽裕。
- ❌ **「一次装到位十年不换」** → ✅ 显卡和 SSD 通常 3–5 年就想换，CPU 和主板能撑 5–8 年，电源和机箱可以跨 2–3 台机器。**按不同折旧周期分配预算**。
- ❌ **「跑分高就是好配置」** → ✅ 按自己真实负载选。Cinebench 分数和你打游戏的体验关系不大。
