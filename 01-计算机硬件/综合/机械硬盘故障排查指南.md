# 机械硬盘（SATA 机械盘）间歇性消失 & 坏道故障排查指南

> 整理自 CSDN 博客《机械硬盘时有时无消失故障排查》
> 原文：https://blog.csdn.net/u013579988/article/details/164219030

## 一、故障现象

内置 SATA 机械硬盘出现以下表现：

- 部分文件读不出来
- 图片等文件写不进去（写入失败）
- `chkdsk` 磁盘检查无法运行 / 跑不下去
- 硬盘时不时整机消失（脱机、在系统中看不见）

## ⚠️ 首要警告（重中之重）

**不要再往这块盘存任何新文件！** 能读出来的资料尽快复制到别的盘。

- 如果机械盘磁头有问题，通电次数越多，彻底报废的概率越高。
- 优先抢救数据：**只做读取，不要写入**。

## 二、硬件排查（关机断电操作！先拔掉主机电源线）

1. 打开机箱，找到这块机械硬盘。
2. 拔下 2 根线：
   - **SATA 数据线**（细扁）
   - **SATA 供电线**（大供电口）
3. 重新插拔 / 更换：
   - SATA 数据线：换主板另外一个 SATA 接口，最好直接换一根**全新 SATA 数据线**。
   - 供电线：从电源换另外一个供电插头，**不要用同一根分叉出来的供电口**。
4. 硬盘本身：
   - 用橡皮轻轻擦拭硬盘电路板金手指（接口触点）。
   - 拧紧硬盘螺丝，避免震动导致松动。
5. 开机进 BIOS 查看，看 BIOS 里是否也偶尔看不到这块硬盘：
   - **BIOS 也时不时消失** → 供电 / 硬盘本体硬件故障，不是 Windows 系统问题。
   - **BIOS 一直能看到，进 Windows 才消失** → 偏向系统驱动问题，或硬盘坏道。

## 三、Windows 下确认健康状态

用 **CrystalDiskInfo** 查看这块盘的 **S.M.A.R.T** 信息，重点看以下几项：

- 重新映射扇区计数（Reallocated Sectors Count）
- 待映射扇区计数（Current Pending Sector Count）
- 无法校正扇区计数（Uncorrectable Sector Count）

> 只要以上任意一项数值 **不是 0**，就说明**已经出现物理坏道**。

出现坏道后就会表现为：部分图片文件读不出来、写入文件失败、`chkdsk` 磁盘检查直接跑不下去，严重时硬盘直接脱机消失。

### 为什么 chkdsk 检测不了？

机械盘存在大量坏扇区时，系统读取磁盘底层扇区持续 I/O 报错，`chkdsk` 无法读取磁盘元数据，直接终止运行。

> 🚫 **千万不要执行 `chkdsk X: /f /r`！**
> `/r` 会强制扫描坏扇区，加重磁头损耗，很可能直接把盘彻底搞挂。

## 四、两种情况判断

### 情况 1：S.M.A.R.T 警告 / 不良，有重映射扇区；BIOS 偶尔识别不到硬盘

→ **硬盘硬件损坏（坏道 / 磁头老化）**

1. 优先抢救数据：只做读取，不要写入；大块文件复制容易中断，建议**小批量复制**。
2. 复制不动的文件**不要反复重试**，继续通电只会恶化；重要资料复制失败，考虑数据恢复服务。
3. **这块机械硬盘不要再继续长期使用，尽快更换。**

### 情况 2：S.M.A.R.T 全部正常，BIOS 每次都识别硬盘，仅 Windows 内消失报错

→ 大概率线缆、供电不稳，或系统驱动问题：

1. `Win+X` → 设备管理器 → 磁盘驱动器，右键卸载这块故障硬盘，重启电脑自动重装驱动。
2. 关闭 Windows 快速启动：控制面板 → 电源选项 → 选择电源按钮功能 → 取消勾选「启用快速启动」，保存重启。
3. 确认电源功率足够、12V 供电稳定；老旧电源供电不稳也会导致机械盘随机脱机。

## 五、典型故障现象对应表

| 现象 | 可能原因 |
|------|----------|
| 图片 / 部分文件打不开 | 文件刚好存放在坏扇区位置 |
| 无法写入图片 | 要写入的簇已经损坏 |
| 硬盘整机消失（掉盘） | 坏道严重或磁头异常，硬盘直接掉盘复位 |
