# 硬件术语速查表

> 缩写地狱急救包。按主题分组，每条一句话说清。
> **数据基准**：2026-08

---

## CPU / 微架构

| 缩写 | 全称 | 一句话 |
| --- | --- | --- |
| **IPC** | Instructions Per Cycle | 每周期指令数，微架构效率的核心指标 |
| **ILP / DLP / TLP** | Instruction/Data/Thread Level Parallelism | 指令级 / 数据级 / 线程级并行 |
| **OoO** | Out-of-Order Execution | 乱序执行，不按程序顺序执行以填满执行单元 |
| **ROB** | Re-Order Buffer | 重排序缓冲，保证乱序执行后按序提交结果 |
| **μop** | Micro-operation | 微操作，x86 指令被拆解成的内部原语 |
| **SMT** | Simultaneous Multi-Threading | 同时多线程，Intel 叫超线程（HT） |
| **P-core / E-core** | Performance / Efficient core | 大核 / 小核 |
| **SIMD** | Single Instruction Multiple Data | 单指令多数据，一条指令处理多个数据 |
| **AVX / NEON / SVE** | — | x86 / ARM 的向量指令集 |
| **MESI / MOESI / MESIF** | — | 缓存一致性协议的三种变体 |
| **NUMA** | Non-Uniform Memory Access | 非一致内存访问，访问本地内存比远端快 |
| **TDP** | Thermal Design Power | 散热设计功耗，**不是实际功耗** |
| **PPT / PL1 / PL2** | Package Power Tracking / Power Limit | AMD / Intel 的真实功耗上限 |
| **PBO** | Precision Boost Overdrive | AMD 的自动超频框架 |
| **Tjmax** | Junction Temperature Max | 结温上限，通常 95–100°C |

## 制造工艺

| 缩写 | 全称 | 一句话 |
| --- | --- | --- |
| **FinFET** | Fin Field-Effect Transistor | 鳍式晶体管，栅极三面包裹，2011–2024 主流 |
| **GAA** | Gate-All-Around | 环栅晶体管，栅极 360° 包裹，2nm 世代主流 |
| **纳米片 / RibbonFET** | Nanosheet | GAA 的具体实现，Intel 叫 RibbonFET |
| **CFET** | Complementary FET | N/P 型晶体管垂直堆叠，GAA 之后的下一步 |
| **BSPDN / BPDN** | Backside Power Delivery Network | 背面供电，Intel 实现叫 **PowerVia** |
| **nanoTSV** | Nano Through-Silicon Via | 纳米硅通孔，背面供电的电流通路 |
| **IR Drop** | — | 电流经电阻造成的电压损失 |
| **DTCO** | Design Technology Co-Optimization | 设计与工艺协同优化 |
| **BEOL / MOL / FEOL** | Back/Middle/Front End of Line | 后段/中段/前段制程 |
| **Reticle Limit** | 光罩极限 | 单颗芯片最大面积约 858 mm² |

## 封装

| 缩写 | 全称 | 一句话 |
| --- | --- | --- |
| **Chiplet** | 芯粒 | 把大芯片拆成多个小芯片再封装到一起 |
| **CCD / IOD** | Core Complex Die / IO Die | AMD 的计算芯粒 / IO 芯粒 |
| **Foveros / EMIB** | — | Intel 的 3D 堆叠 / 嵌入式桥接封装 |
| **CoWoS** | Chip on Wafer on Substrate | 台积电的 2.5D 封装，AI 芯片必备 |
| **3D V-Cache** | — | AMD 把 SRAM 垂直堆在 CCD 上 |
| **TSV** | Through-Silicon Via | 硅通孔，垂直堆叠的电气连接 |
| **HBM** | High Bandwidth Memory | 高带宽内存，垂直堆叠的 DRAM |
| **CPO** | Co-Packaged Optics | 共封装光学，光引擎和 ASIC 封在一起 |
| **LGA / PGA / BGA** | Land/Pin/Ball Grid Array | 触点式 / 针脚式 / 焊球式封装 |

## 总线与互连

| 缩写 | 全称 | 一句话 |
| --- | --- | --- |
| **PCIe** | PCI Express | 现代最重要的系统总线，点对点交换式 |
| **GT/s** | Giga-Transfers per second | 每秒传输次数，**含编码开销，≠ Gbps** |
| **Lane** | 通道 | 一对差分收发线，PCIe 的带宽单位 |
| **Bifurcation** | 通道拆分 | 把 x16 拆成 x8/x8 或 x4×4 |
| **Root Complex** | 根复合体 | PCIe 树的根，在 CPU 内 |
| **DMI / UPI** | Direct Media Interface / Ultra Path Interconnect | Intel 的芯片组链路 / 多路 CPU 互连 |
| **IF / xGMI** | Infinity Fabric | AMD 的片内与片间统一互连 |
| **FCLK / UCLK / MCLK** | Fabric/Unified Memory Controller/Memory Clock | AM5 上要 1:1 同步才有最低延迟 |
| **CXL** | Compute Express Link | 跑在 PCIe 上的缓存一致性协议，用于内存池化 |
| **UCIe** | Universal Chiplet Interconnect Express | 芯粒互连开放标准 |
| **NVLink / UALink** | — | GPU 专用高带宽互连（私有 / 开放） |
| **PAM4** | Pulse Amplitude Modulation 4-level | 4 电平调制，PCIe 6.0+ 使用 |
| **FEC** | Forward Error Correction | 前向纠错，PAM4 的必需品，会引入延迟 |
| **FLIT** | Flow Control Unit | 流控单元，PCIe 6.0 起的固定长度包 |
| **Retimer** | 重定时器 | 高速信号中继器，长走线必需 |
| **SerDes** | Serializer/Deserializer | 串并转换电路，所有高速串行接口的基础 |
| **CDR** | Clock Data Recovery | 从数据流中恢复时钟 |

## 单位换算备忘

```
1 GT/s ≈ 1 Gbps × 编码效率
   8b/10b   → ×0.8      (PCIe 1.0/2.0)
   128b/130b → ×0.985   (PCIe 3.0/4.0/5.0)

bit → byte：÷ 8
   PCIe 5.0 x16 = 32 GT/s × 16 × 0.985 ÷ 8 ≈ 63 GB/s（单向）

内存真实延迟 (ns) = CL ÷ 频率(MT/s) × 2000
   DDR5-6000 CL30 = 30 ÷ 6000 × 2000 = 10.0 ns
   DDR5-7200 CL38 = 38 ÷ 7200 × 2000 = 10.6 ns  ← 更慢

内存理论带宽 (GB/s) = 频率(MT/s) × 位宽(64) ÷ 8 ÷ 1000 × 通道数
   DDR5-6000 双通道 = 6000 × 64 ÷ 8 ÷ 1000 × 2 = 96 GB/s
```
