# CPU 参数详解与分类对比

> **一句话结论**：参数表上只有三个数字真正重要——**微架构代号、核心构成、缓存容量**；主频和 TDP 都是被营销污染过的数字。
> **数据基准**：2026-08 ｜ **难度**：入门→进阶 ｜ **前置**：[CPU 架构与工作原理](./01-CPU架构与工作原理.md)

---

## 1. 参数逐项拆解

### 1.1 频率：三个数字，只有一个有用

| 参数 | 含义 | 可信度 |
| --- | --- | --- |
| **基础频率** Base Clock | 在标称 TDP 下保证的最低频率 | 几乎没用，实际很少跑这么低 |
| **加速频率** Boost / Turbo | 单核短时可达的峰值 | 营销数字，只在轻载瞬间出现 |
| **全核持续频率** | 所有核心满载时的稳定频率 | ⭐ **真正决定多线程性能**，但厂商基本不标 |

想知道全核频率，只能查评测的实测数据，或者自己跑 Prime95 看 HWiNFO。

**决定实际频率的四堵墙**（谁先撞上谁说了算）：

```
温度墙 ── 到 95–100°C 降频（Tjmax）
功耗墙 ── PL1/PL2（Intel）、PPT/TDC/EDC（AMD）
电流墙 ── 主板 VRM 供电能力
硅质墙 ── 这颗芯片的体质上限（Silicon Lottery）
```

同一颗 CPU，配 B 系列小板 + 风冷 vs Z 系列大板 + 360 水冷，多核性能可以差 20%。**CPU 只是给了上限，能不能跑满取决于主板和散热**——这是理解「主板不影响性能」这个谣言为什么错的关键。

### 1.2 核心与线程

现代表示法要看清楚构成：

```
Core Ultra 9 285K:  24C / 24T  = 8 P-core + 16 E-core，无超线程
Ryzen 9 9950X:      16C / 32T  = 16 个同构 Zen 5 核，带 SMT
Ryzen 7 9800X3D:     8C / 16T  = 8 核 + 3D V-Cache
```

**多少核够用**（2026 年基准）：

| 用途 | 够用 | 舒适 | 过剩 |
| --- | --- | --- | --- |
| 办公 / 网页 | 4C | 6C | 8C+ |
| 游戏 | 6C | 8C | 12C+（游戏吃不满） |
| 编程 / 编译 | 8C | 12–16C | — （编译几乎线性吃满） |
| 视频剪辑 4K | 8C | 16C | — |
| 3D 渲染 / 科学计算 | 16C | 32C+ | — |
| 本地跑大模型 | 看内存和 NPU/GPU，CPU 核数不是瓶颈 | | |

### 1.3 缓存：看 L3，更要看「每核分到多少」

```
Ryzen 7 9800X3D:  96 MB L3 /  8 核 = 12 MB/核   ← 游戏之王的秘密
Core Ultra 9 285K: 36 MB L3 / 24 核 = 1.5 MB/核
```

游戏的工作集（场景数据、物理状态）通常在几十 MB 量级。塞得进 L3 → 不用去内存 → 帧数暴涨。这就是 3D V-Cache 在游戏里能赢 15–20% 而在渲染里毫无优势的原因（渲染的工作集是 GB 级，多大 L3 都装不下）。

### 1.4 TDP：一个被彻底玩坏的数字

**TDP 不是功耗，是散热器设计目标**。

| 厂商 | 标称 | 实际峰值 |
| --- | --- | --- |
| Intel | PL1（长期功耗）常被标为 TDP | PL2 短时可达 2 倍以上，且主板默认经常「解锁」 |
| AMD | TDP 是散热设计值 | 真实上限是 **PPT ≈ TDP × 1.35** |

举例：AMD 标 105W TDP → PPT 142W；Intel 标 125W → PL2 250W。

**选散热器要按峰值功耗选，不是按 TDP**。

### 1.5 后缀含义速查

**Intel**

| 后缀 | 含义 |
| --- | --- |
| K | 倍频解锁，可超频（需 Z 系列主板） |
| F | 无核显 |
| KF | 解锁 + 无核显 |
| T | 低功耗版（35W 级） |
| X / XE | 发烧级 |
| H / HX / U / P | 移动端：HX 最强、H 高性能、P 轻薄本、U 低功耗 |

**AMD**

| 后缀 | 含义 |
| --- | --- |
| X | 高频版 |
| X3D | 带 3D V-Cache 堆叠缓存 |
| G | 强核显 APU |
| F | 无核显 |
| XT | 中期小改款提频 |
| HX / HS / U | 移动端，同 Intel 逻辑 |

## 2. 分类对比

### 2.1 按应用场景分类

| 维度 | 桌面 Desktop | 移动 Mobile | 服务器 Server | 嵌入式 |
| --- | --- | --- | --- | --- |
| 代表 | Ryzen 9000 / Core Ultra 200S | Ryzen AI 300 / Core Ultra 200H | EPYC / Xeon 6 | ARM Cortex / RISC-V |
| 功耗 | 65–250 W | 15–55 W | 200–500 W | 0.1–15 W |
| 核心数 | 6–24 | 8–16 | 64–192+ | 1–8 |
| 优化目标 | 单核峰值 + 性价比 | 每瓦性能 | 每机架吞吐 + 可靠性 | 极致低功耗 |
| 内存 | 双通道 UDIMM | 板载 / LPCAMM2 | 8–12 通道 RDIMM + ECC | 片上 |
| PCIe 通道 | 20–28 | 12–20 | 96–160 | 极少 |
| 封装 | LGA / PGA 可换 | BGA 焊死 | LGA 大尺寸 | BGA |
| 特有功能 | 超频 | 深度节能状态 | ECC、RAS、多路互连、CXL | 实时性 |

### 2.2 Intel vs AMD 平台对比（2026 桌面）

| 维度 | AMD AM5 | Intel LGA1851 |
| --- | --- | --- |
| 当前主力 | Ryzen 7000 / 9000（Zen 4/5） | Core Ultra 200S（Arrow Lake） |
| 架构 | 同构大核 + SMT | 混合 P/E core，**无超线程** |
| 插槽寿命 | 官方承诺支持到 **2027+**，Zen 6 确认沿用 AM5 | 单代为主，历史上 2 代换代 |
| 内存甜点 | **DDR5-6000**（FCLK 1:1 同步点） | **DDR5-6400+**（对分频不敏感，Z890 可上 8000+） |
| 超频 | **全芯片组支持 PBO**，A620 都能调 | 仅 Z 系列可超倍频 |
| USB4 | X870/X870E **强制标配** | Z890 不强制，靠主板加雷电控制器 |
| 游戏 | X3D 型号断层领先 | 略逊 15–20%（对比 9800X3D） |
| 生产力 | 多核强 | 多核心 E-core 堆料，部分负载领先 |
| 功耗/发热 | 相对温和 | 高负载需 360 水冷 |
| NPU | Zen 5 桌面 NPU 弱 | Arrow Lake 内置 NPU 约 48 TOPS |
| 核显 | RDNA 系列，较强 | Xe 架构 |

**结论**：
- **游戏优先** → AMD X3D，没有悬念。
- **混合创作 / 需要 Windows AI 功能 / 预算敏感的入门** → Intel。
- **想少换主板** → AM5。

### 2.3 X86 vs ARM vs RISC-V

| | x86-64 | ARM (AArch64) | RISC-V |
| --- | --- | --- | --- |
| 指令集类型 | CISC（内部转 RISC 式 μop） | RISC | RISC |
| 指令长度 | 可变 1–15 字节 | 定长 4 字节（含 16 位压缩） | 定长 + 压缩扩展 |
| 授权模式 | 封闭（Intel/AMD 交叉授权） | IP 授权，可买架构许可自研 | **开放、免费** |
| 桌面/服务器生态 | 极成熟 | 成长中（苹果 M 系列、AWS Graviton、Ampere） | 早期 |
| 移动/嵌入式 | 弱 | 统治级 | 快速增长 |
| 软件兼容 | 30 年二进制兼容 | 需重编译，转译层已成熟（Rosetta 2、Prism） | 生态建设中 |
| 典型优势 | 兼容性、单核绝对性能 | 每瓦性能、可定制 | 无授权费、可深度改 |

**2026 年的现状**：ARM 在服务器端已站稳（AWS Graviton 系列、Ampere），在 PC 端靠苹果 M 系列和高通骁龙 X 系列建立了存在感。RISC-V 主要在 IoT、存储控制器、AI 加速器的控制核里大量出货，通用计算仍在爬坡。

## 3. 怎么读一份 CPU 规格表

拿到一颗陌生的 CPU，按这个顺序看：

```
1. 微架构代号        → 决定 IPC 基线（Zen 5? Lion Cove? 差一代 = 10–15% IPC）
2. 核心构成          → 8P+16E 还是 16 个同构核，影响调度和多线程表现
3. L3 缓存 / 核心数  → 判断游戏和低延迟负载表现
4. 全核持续频率      → 查评测，不看官标
5. PPT / PL2         → 决定散热和主板供电需求
6. 插槽 + 芯片组要求 → 别买回来插不上（见插槽笔记）
7. 内存支持          → 通道数、官方频率、是否支持 ECC
8. PCIe 版本与通道数 → 决定能挂几张卡几块盘
```

## 4. 常见误区

- ❌ **「i7 一定比 i5 强」** → ✅ 跨代无效。12 代 i7 在很多负载上不如 14 代 i5。**先看代号，再看等级**。
- ❌ **「TDP 65W 所以整机功耗低」** → ✅ 65W TDP 的 AMD 实际 PPT 88W；Intel 65W 型号 PL2 可达 150W+。
- ❌ **「买 CPU 送的散热器够用」** → ✅ 只对 65W 级别成立，且是「不降频烧坏」的够用，不是「跑满频」的够用。
- ❌ **「核显没用，一定买 F 版」** → ✅ 核显是显卡坏了时唯一的救命稻草，还能做视频硬件编解码卸载。省的那 100 块不值。
- ❌ **「跑分高 = 用起来快」** → ✅ Cinebench 测的是全核渲染，和你打游戏、开 IDE 的体验关系不大。**按自己的负载选基准**。
- ❌ **「超频能明显提升游戏帧数」** → ✅ 现代 CPU 出厂已接近极限，超频收益通常 3–5%，还不如把钱花在内存时序上。
