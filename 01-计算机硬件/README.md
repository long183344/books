**如果你是想装机 / 选购** → 直接看 [综合/装机平台横向对比与选型决策](./综合/装机平台横向对比与选型决策.md)，看不懂的名词查 [术语速查表](./综合/硬件术语速查表.md)。

**如果你是想搞懂原理** → 按下面顺序：

```
CPU 01 架构原理
   ↓ 知道了 CPU 内部怎么跑
CPU 02 参数对比        ← 参数表上的数字终于有意义了
   ↓
主板 01 结构与芯片组    ← CPU 外面那一圈是什么
   ↓
总线 01 原理与分类      ← 它们之间怎么通信
   ↓
总线 02 PCIe 代际       ← 最重要的那条总线
   ↓
插槽 01/02/03          ← 物理层：怎么插上去
   ↓
CPU 03 + 总线 03       ← 前沿：接下来会变成什么样
```

## 这个分类的三条铁律

1. **看瓶颈，不看单项**。CPU 再快，PCIe 通道被拆成 x8 也白搭。系统性能等于最慢那一环。
2. **带宽和延迟是两回事**。总线升级通常只涨带宽，延迟基本不变甚至变差（FEC、重定时器都要加延迟）。
3. **兼容性由物理层和协议层共同决定**。插得进去 ≠ 能用（同一 M.2 槽位可能只走 SATA 不走 NVMe）。
